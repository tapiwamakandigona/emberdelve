# Original Assets: replicating a style without copying anyone

**Question (owner, 2026-07-25):** can we make our own audio, music, and
graphics that closely replicate the originals (Apple-Knight-style presentation
and third-party packs we currently ship) without violating copyright, so that
we never *need* to credit anyone?

**Answer: yes — with clear rules.** This doc records the research, the audit
of what we ship today, and the replacement plan. Phase 1 shipped with this
document (see §5).

> This is engineering research with sources, not legal advice.

---

## 1. What the law lets us replicate freely

| Element | Protected? | Practical rule |
|---|---|---|
| Game mechanics, rules, controls, "feel" | **No** — copyright never covers ideas, procedures, systems (17 U.S.C. §102(b)) | Replicate AK's jump/dash/combat loop outright. This is what the AK-parity plan does. |
| Genre, art *style*, palette vibe, "pixel knight platformer" | **No** — style is not protectable | Same style is fine; same *pixels* are not. |
| Specific sprites, tilesets, animations | **Yes** | Never trace, recolor, or derive from theirs. Draw ours from scratch. |
| Characters (a distinctive protagonist design) | **Yes**, if distinctive (the Ninth Circuit's *Towle* character test) | Our hero must have its own identity — not a 1:1 lookalike of AK's knight. Same proportions/genre is fine. |
| Music *style* (genre, instrumentation, tempo, energy) | **No** | Compose original tracks in the same genre. |
| Melodies / compositions / recordings | **Yes** | No note-for-note recreation, no sampling, no "sound-alike" of a specific melody. |
| Sound effect *ideas* (a jump blip, a coin chime) | **No** — but the specific recording is protected | Synthesize our own from first principles. |
| Name & logo ("Apple Knight", Limitless LLC branding) | **Trademark** | Never use their name/logo/store art; avoid confusingly similar branding. |

**The two cautionary cases** (both about platform/puzzle clones):

- *Tetris Holding v. Xio Interactive*, 863 F. Supp. 2d 394 (D.N.J. 2012):
  mechanics are free, but Xio lost because it copied Tetris's *visual
  expression* nearly pixel-for-pixel. Cloning look-and-feel wholesale is
  infringement even when every asset is technically redrawn.
- *Spry Fox v. LOLApps* (W.D. Wash. 2012, the *Triple Town / Yeti Town*
  case): a cosmetic reskin (bears→yetis, meadow→snowfield) with the same
  expressive arrangement still plausibly infringed.

**Operating rule derived from both:** copy the *system*, never the *scene*.
Same verbs, physics, loop structure = safe. Same character silhouette, same
level art composition, same melody = risk. Emberdelve already passes this
test: ember/ash dungeon fantasy vs AK's bright castle/forest look, different
hero, different enemies, different music.

## 2. Why "no credit needed" requires replacement, not relabeling

- **CC-BY** (3.0/4.0): attribution is a *condition of the license*. It cannot
  be waived by us, only by the author. Ship the asset → ship the credit.
  The only way to drop the credit is to stop shipping the asset.
- **CC0**: no legal attribution requirement at all (credits are courtesy).
- **OFL fonts** (Cinzel, Inter): no in-app credit required; the license text
  just has to stay with the font files in the repo.

So "zero required attributions" = replace every **CC-BY** asset with original
work. CC0 assets are already legally credit-free (we keep courtesy thanks).

## 3. Ownership rules for the replacements

- **Procedural, script-authored assets are ours.** Everything is generated by
  code we wrote (`tool/build_original_music.py`, `tool/build_original_art.py`)
  from parameters and note data we authored. No third-party samples,
  soundfonts, fonts, or images are read by these scripts.
- **No generative-AI assets.** The US Copyright Office's 2023 registration
  guidance and its January 2025 *Copyrightability* report both conclude that
  purely AI-generated material is not copyrightable (insufficient human
  authorship). Since the point of this exercise is that *we own the assets*,
  the repo's existing no-AI-asset rule stays: script-drawn, hand-authored,
  or human-composed only.
- **Tool licenses checked:** sfxr is MIT, jsfxr is Unlicense, ChipTone output
  is explicitly CC0 — generator *outputs* belong to the user. We synthesize
  in-repo anyway, which is even cleaner (fully reproducible provenance).
- **Sound-design chain of custody:** a recreated SFX must start from silence
  (oscillators/noise), never from another game's audio, and never from a
  "royalty-free" library whose license forbids redistribution in a public
  repo (that's why Sonniss/GDC packs were already rejected in PROVENANCE.md).

## 5. Plan

### Phase 1 — zero required attributions (SHIPPED in this PR)

All CC-BY assets replaced with 100% original, in-repo-generated work:

- **5 music tracks + defeat sting** — original compositions (chord data +
  melodies written for Emberdelve), synthesized from numpy oscillators.
  Same *genres* as before (dark-mystery title, light overworld, driving
  combat, relentless boss, somber defeat); no melodic material borrowed.
  Seamless loops (rendered 2× and the steady-state pass exported).
  `tool/build_original_music.py`.
- **Fire ambience loop** — procedural crackle synthesis (filtered noise
  bursts + rumble bed, wrap-around seam). Same script.
- **Chest sprite** (3×48×48) — original design: dark-oak, ash-iron banding,
  ember-rune lock, spark-throwing gold. Deliberately distinct from both the
  old dustdfg chest and AK's chests. `tool/build_original_art.py`.
- **App icon + Android mipmaps** — original "ember in the delve" mark
  (flame rising from a cave mouth). Replaces the dice-era icon that both
  carried a CC-BY glyph and no longer matched the platformer.
- CREDITS.md / PROVENANCE.md / credits-screen test updated accordingly.

Result: **every legally-required attribution is gone.** Remaining
third-party material is CC0 (+ OFL fonts), credited as courtesy only.

### Phase 2 — full ownership (optional, not started)

Replace the remaining CC0 packs so 100% of shipped art/audio is
studio-owned (stronger position for store branding, merch, ports):

| Workstream | Scope | Effort |
|---|---|---|
| Player knight (4 skins × 9 anims) | hardest art in the game | L |
| Tileset + cave tileset + props | 2 sheets + ~11 props | L |
| Enemies (9 sheets) | idle/run frames each | M-L |
| Parallax backgrounds (9 layers) | painted layers | M |
| Items/HUD/shop icons (~20) | small pieces | M |
| Remaining CC0 SFX (~24) | extend synth toolkit | M |
| Victory fanfare + stings | compose | S |
| Fonts | license-free bitmap font or keep OFL | S |

Recommendation: do Phase 2 only if/when the game gets traction; CC0 assets
carry zero legal obligation meanwhile.
