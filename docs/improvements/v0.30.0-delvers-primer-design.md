# v0.30.0 — The Delver's Primer (design)

## Why

Our first outside review (logged 2026-08-23, progress.md USER-REPORTED):

> "I still don't understand what's a delve but it doesn't matter I enjoyed
> the gameplay"

The word is the game's name and its core loop, and nothing in the game ever
defines it. Retention research (docs/research/retention-hooks-2026-08-23.md,
hook #4): players who can name what they're doing retain the loop better and
explain the game to friends in the store's own words.

## What ships

One definition, delivered at first contact and re-readable forever:

1. **New contextual tip `whats_a_delve`** (lib/game/tips.dart) — fires the
   first time the run map (the delve itself) comes on screen, via a new
   `TipDirector.onMapArrival()` trigger. Same charter as every tip since
   v0.10.0: once ever, one at a time, tap-anywhere dismiss, persisted in
   `MetaState.tipsSeen`.
2. **Map screen renders the shared `_ContextTip` card** — the definition is
   given while the player is literally standing inside a delve, with the
   start flag and glowing paths visible under the card.
3. **Manual overlay deck gains a first card "WHAT'S A DELVE?"** (same copy)
   — re-readable any time from combat's How-to-play button. `cardCount` is
   derived, so the paging footer follows automatically.

Copy (fact-checked against the sim):
- "every ember you gathered comes home" — controller `_bankRun` banks
  `run['embers']` in full on a win.
- "the ledger still keeps half" — run_layer.dart loss path: `kept = embers
  ~/ 2` with floor `5 + layer`.
- "the next one starts fresh" — runs are seed-fresh roguelike descents.

## Who sees it

- New players: once, on their first map.
- Post-v0.10.0 existing players: once, on their next map arrival — their
  `tipsSeen` set predates the id. Intended: the reviewer who asked IS an
  existing player. One tap dismisses it forever.
- Pre-v0.10.0 veterans (old `tutorialSeen` saves without a `tipsSeen` key):
  never — migration pre-seeds `ContextTips.all` at load, which now includes
  the new id. They can read the manual deck card.

## Ethics check (docs/spec.md §5)

Pure teaching card. No purchase path, no urgency, no lock. Banned-word sweep
clean. Tap-anywhere dismiss, never traps.
