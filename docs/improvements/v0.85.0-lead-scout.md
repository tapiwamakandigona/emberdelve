# v0.85.0 lead scout — The Narrow Climb

## Finding

The game already knows exactly how close a win ran — the low-HP danger rule
(`_inDanger`, HP ≤ 30% of max) has darkened the combat music since v0.23.0 —
but the summary never says it. A won run reads identically whether the delver
walked out untouched or crawled out at 1 HP. Near-miss memory is the stuff
players retell ("I won on ONE hp"), and the honest moment to state it is the
summary, in the same breath as the result. Losses already get their obituary
(killed_by); narrow wins get nothing.

## The improvement (one)

A quiet dim line on WON summaries whose final HP satisfies the existing
danger rule: 'A narrow climb home — 3 HP standing.' (1 HP: 'A narrow climb
home — 1 HP standing.') Same threshold as the danger music, so the line and
the low-HP bed can never disagree about what "close" means. Dim micro (not
gold — maybe a fifth of wins qualify; gold stays rare), placed after the
insight panel with the other run reflections. Echoes the victory track's
name, "The Climb Home".

## Rejected

- Showing final HP on every win — flat stat, no story; the line earns its
  place only when the fact is remarkable.
- A new threshold (10% / 1 HP only) — inventing a second definition of
  "close" when the danger rule already owns it.
- Persisting narrowness into _runRecord/ledger — schema growth for a
  transient reflection; the summary is the moment.
