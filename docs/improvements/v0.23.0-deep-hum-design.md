# v0.23.0 "The Deep Hum" — depth-scaled map ambience (design)

One improvement: the delve map gains an ambience bed that deepens as you
descend. Combat-feel backlog #7 (map ambience per layer depth), the last
genuinely unshipped item on that list besides the tiny reroll retumble.

## Why

- The map is where a run breathes between fights, but it sounds identical on
  layer 1 and layer 9; the descent is visual only. Competitor scan (retention
  doc): the genre's strongest atmosphere plays (Slay the Spire's act beds,
  Hades' biome layers) tie *sound* to *progress*.
- Zero payload cost and zero new permissions: reuses the shipped
  `ember_ambience_loop.ogg` at a depth-scaled volume. No new assets, so the
  <30 MB download demand is untouched.

## Design

- On the `map` phase, the existing ambience bed starts (today it runs only on
  title/rest) at `volume = music * lerp(0.12, 0.45, depth)` where
  `depth = currentLayer / maxLayer` from the sim map. Shallow floors whisper;
  the last approach hums.
- Volume updates when the player moves a node (no restart — live setVolume on
  the running player, audioplayers supports it).
- Reduce-motion/still-flame setting does NOT gate audio (it never has);
  the music volume slider gates everything, and music==0 keeps the bed off
  (existing effectiveMusic behavior).
- Same lifecycle rules as the title bed: failed start must clear the slot;
  app pause stops it (main.dart lifecycle handler already covers `_ambience`).

## Tests (service-level, no plugin)

- Fake/injectable player recording setSource/setVolume calls (pattern:
  update_service fetcher injection).
- Pins: bed starts on map phase; volume monotonic in layer (layer 2 < layer
  5 < layer 9); no restart on move (same player instance, setVolume only);
  music slider at 0 ⇒ no bed; leaving map phase releases per existing rules.
