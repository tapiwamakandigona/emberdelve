# v0.122.0 lead scout — The Spoken Delve

Trail: studio-practice research (the v0.51.0+ improvement survey)
put accessibility in the standard release train (CoD/Fortnite ship
a11y notes every patch); the queued 'reward-die label gap' was
rated thin, but a grep audit (`grep -rL Semantics lib/ui/screens`)
showed it was actually the whole choice layer: reward, boon, shop,
temper — 0 Semantics among them, vs combat's tray which has spoken
since v0.44.0. A player using TalkBack could fight but never pick.

Choices:
- Labels from the same defs the paint reads (dieDef/boonDef/
  runeName) — the spoken layer can never drift from the drawn one.
- 'not enough gold' spoken on the shop button instead of a silent
  disabled state: an unactionable button with no reason is the
  a11y equivalent of the counted-heal bug.
- Scope cut: map medallions and codex browsing already read
  acceptably (text-based); the CHOICE surfaces were the blocker.
