# v0.61.0 lead scout — The Deepest Mark

## Research pass (2026-08-25, during GitHub-auth wait)

- Post-run screen conventions (Template Foundry "Post-Run Stats Screen UI",
  itch): "personal best / new record cards" are a standard expectation of
  the genre's end screen — the moment a record moves is the one honest
  moment to say so.
- Balatro stats culture (wiki Stats page, CozyStats mod, balatro-analytics):
  players actively seek their own high-water marks; a Steam discussion
  thread asks for MORE record detail on the stats screen.
- Antihero Studios loss-retention data (v0.60.0 scout): losses drive
  retries harder than wins — a record that a LOSS can set gives the loss
  screen a dignity beat that is also a retention beat.

## Gap found

meta.bestFloor (deepest 1-based layer ever stood on, won or lost) has
existed since v0.5.0 — banked in _bankRun, surfaced ONLY as an achievement
statValue. The summary screen announces rank-ups, opened rungs, firsts and
codex growth, but the moment bestFloor itself moves says nothing. The
player's deepest delve is the genre's most primal record and we bank it
silently.

## Ship: v0.61.0 The Deepest Mark

- controller: transient `pendingDeepestFloor` (pendingRankUp lifecycle —
  set in _bankRun, cleared by startRun) when THIS run moved bestFloor AND
  a previous record existed (bestFloor > 0 gate: a profile's first-ever
  run has nothing to compare against; announcing a trivial "record" would
  be noise).
- summary: one quiet gold line, key `deepest-line`:
  "Floor N — the deepest you have delved." Shown on wins and losses alike.
- Naturally self-silencing: once bestFloor reaches the map's final layer
  the line retires on its own — it lives exactly in a profile's early
  weeks, the retention window where depth progress IS the story.
- Zero sim movement. Zero save-format movement (bestFloor already
  persists + cloud-merges MAX; the pending field is transient).
