# v0.83.0 lead scout — The Depth Gauge

## Finding

Mid-run, the current floor is stated NOWHERE. The lantern (v0.82.0) marks
the record on the map, the Ledger states it, the summary banks it — but a
player standing in the delve has to count node rows by hand to know their
own depth. The map hint line already carries pool/relic counts; depth is
the one navigation fact it omits. Surveying arc completes: Sounding Line
(the chart), Plumb Line (the record), Depth Gauge (the live reading).

## The improvement (one)

The map hint line opens with the live depth: 'Floor N of M · Tap a glowing
node to descend · Pool: X dice · Y relics'. Pure read of the current node's
layer and the map's layer count — the same numbers the run record and the
lantern already use. Micro caption, wraps gracefully at 320.

## Rejected

- 'new depth' suffix when past the banked record — the lantern already says
  it spatially (you are above the line); words would duplicate the map.
- A TopBar floor chip visible in combat/shop/event — shared chrome touched
  for a fact that matters at navigation time; larger blast radius, separate
  release if ever.
- Replacing the descend hint to keep one line — the hint is the only text
  instruction a first delve gets; wrapping micro text is the cheaper cost.
