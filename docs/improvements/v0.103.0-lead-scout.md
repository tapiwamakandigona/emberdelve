# v0.103.0 lead scout — The Marked Week

Lead: fresh audit of run records against every surface that rebuilds
from them. Found the weekly banked nothing — invisible in history —
and that its row's code/retrace would silently drop the mutator. The
second is the real bug: the Ledger already refuses seed-0 codes "that
would lie", and a mutator-less rebuild lies identically.

Choices:
- Bank mutators generically (any declared rule, not a weekly flag
  alone) so trial-day mutator records are honest too, for free.
- Refuse rather than extend the code format: delve codes are 9 chars
  and shared aloud; encoding open-ended mutator sets would break
  every existing code reader. Refusal + stated rule is honest and
  cheap. Revisit only if shared weekly codes become a real ask.
- Card stays on modded rows: DelverCardFacts states what happened;
  it never rebuilds a run.

Queued leads: per-delver win tallies on the Delver's Page if it
proves used; weekly recap line could someday name last week's rule.
