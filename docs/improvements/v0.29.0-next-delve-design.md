# v0.29.0 — The Next Delve (post-Easy-win Normal invitation)

## Why (retention hook #3, docs/research/retention-hooks-2026-08-23.md)

The first outside review (2026-08-23): "I have finished easy mode … the game
is good and fun." An Easy finisher who is enjoying the game has no in-game
signpost that the intended experience continues on Normal — the difficulty
selector sits back on the title screen, easy to never revisit. The 2026
retention research pass calls this the "next-action session ending": every
session end should name a concrete next step, because "what do I do now?"
is where players quietly churn.

## What

One quiet panel on the run summary, shown ONLY when the run was WON on EASY:

> The easy delve is tamed. The same halls wait on Normal — sharper teeth,
> a fuller ember pouch.

with a `Delve Normal` button that starts a fresh run on Normal with the same
delver (boons included), and records Normal as the explicit sticky
difficulty preference — the same semantic as tapping the title selector.

Facts, verified: easy banks embers at 0.75x (`lib/sim/run_layer.dart` L768),
so "a fuller ember pouch" on Normal is literally true.

## Ethics (spec §5 endorsement test)

- Shown only at a WIN — never a "do better" prod after a death.
- Never a popup; never blocks Delve again / share / Back to the fire.
- Nothing expires, nothing is lost by ignoring it, no reward promised
  beyond the factual ember-rate difference.
- Would the player endorse it if we explained it? "After you beat Easy we
  point out Normal exists, once per summary, one tap to take it." Yes.

## How

- `GameController.delveNormal()` (controller.dart, beside `delveAgain`):
  `setPreferredDifficulty('normal')` + `startRun(character: same,
  ascension: same, boons: true, difficulty: 'normal')`.
- `summary_screen.dart`: panel keyed `normal-nudge`, CTA keyed
  `delve-normal-cta`, gated on `won && run['difficulty'] == 'easy'`.
  Column layout (text row above, button below) — the plate critique showed
  a trailing button starves the copy to one word per line on 360dp phones.
- No sim changes; simVersion 7 untouched.

## Tests
