# v0.76.0 lead scout — The New Song

## Evidence
- Overbaked Studio (2026-07): deckbuilders hook because "losing stays
  cheap" and each run leaves something behind. Emberdelve announces every
  other run-earn at the summary (achievements, rank, epithets, vistas,
  deepest mark, enemy firsts, codex growth) — **newly heard music was the
  one earn that still happened silently.**
- The reviewer's best-loved craft is the soundtrack ("the music is 9/10"),
  and v0.75.0 made heard tracks pinnable — but nothing ever told the
  player a track had just been earned. The Gramophone's earn-hints point
  forward; nothing pointed back at the moment of earning.

## Design
- Run-scoped `GameController.runNewTracks`: keys added exactly when the
  lifetime `heardTracks` record grows mid-run ('title_menu' never — it is
  seeded, not earned). Persisted beside the snapshot ('run_new_tracks',
  absent when empty) so a resumed run keeps its line; cleared by startRun
  and endToTitle.
- Summary: ONE quiet line (key 'new-song-line', micro/dim beside the
  firsts-line): one name quoted; two names joined; three-or-more collapse
  to '"first" and N more join the Gramophone.' Names resolve through
  tracks.dart in shelf order (a rename can never leave the line lying).

## Rejected
- **A line per track** — a first delve hears up to five; five lines shout
  down the run result.
- **Mid-run toast** — interrupts combat for an ambient fact.
- **"Go pin it" call-to-action** — naming the Gramophone is enough; the
  shelf teaches itself (§Ethics: no nudges).
- **Gold styling** — gold is for capability unlocks announced as
  headlines (names, vistas); a song joining a shelf is a firsts-grade
  fact.
