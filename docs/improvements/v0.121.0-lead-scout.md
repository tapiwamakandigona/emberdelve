# v0.121.0 lead scout — The Waymark Line

Trail: session-intent research (the hook literature the 2026-08-23
review pass gathered): players who name a goal before playing return
at much higher rates, and every big roguelite fronts one (Hades'
prophecies list, Slay the Spire's climb counter). Emberdelve had the
resolver built and tested since v0.5.0 (nearestAchievements) but
only spoke AFTER runs, on the summary — the title screen, where
intent actually forms, said nothing.

Choices:
- One line, limit 1, not a panel: the title already carries the
  weekly card + provings count; a second panel would shout. The
  quiet TextButton row is the established register for facts.
- runsPlayed gate discovered by test: the 'fresh profile shows
  nothing' pin failed honestly (Full Hearth 1 of 4 — the default
  theme counts). Kept the failing expectation, added the gate to
  the resolver rather than special-casing owned-by-default stats:
  before the first delve, NO goal should show, not just no
  cosmetic-purchase goal.
- Tap goes to the Ledger (where the full waymark list lives), not
  to a new screen: navigation reuse, zero new surface.
