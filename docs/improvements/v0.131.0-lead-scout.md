# v0.131.0 lead scout — The Written Rules

Trail: the rotation arc audit. The weekly rules were playable
(v0.111), collectible (v0.127) and wearable (v0.129) but not
READABLE — every other named thing in the game has a codex page;
the calendar didn't. Lore-completeness is a retention hook the
review noted ('what's a delve?' — answered v0.104; 'what's Flint
Week?' had no in-game answer).

Choices:
- 10 embers, place-priced: the calendar is world. Cheap pages
  keep the codex an early ember sink for new players.
- Mirror-assertion over copied names: the test pins ruleNames to
  mutatorDef(id).name so a future rename cannot fork the book.
- Rejected: per-rule win records on the page (weekly_rules_won is
  a Set of labels, not per-rule counts — a records line would
  need new banked state for marginal value; the Ledger already
  shows 'Rules taken: N of 6').
