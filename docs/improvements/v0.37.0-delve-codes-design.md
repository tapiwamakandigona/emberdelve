# v0.37.0 — Delve Codes (design)

**One improvement:** a compact, human-shareable **Delve Code** that packs the
whole challenge — seed, delver, difficulty, ascension — so a friend plays
*your run*, not one like it.

## Why (research, 2026-08-24)

- Deckalypse (2026) closes every run with a "DKLP code that packs the whole
  run (seed, region and mutators) so a friend plays your run, not one like
  it" — the code sits under the recap share card, exactly our Delver's Card
  position. Community-praised as its acquisition loop.
- Purrogue and other 2026 web roguelikes use import/export codes on the main
  menu for the same reason: a code is platform-neutral virality (WhatsApp,
  SMS, Discord) — no deep-link infra, works offline, zimbabwe-friendly.
- Our gap today: "Delve a seed" (v0.3.4) replays the seed only. The friend
  must manually match delver/difficulty/ascension or they get a different
  challenge — the card says "The Kindler · Hard · Ascension 12" but the seed
  field alone can't reproduce it.

## Shape

- Code format: `DELVE-XXXXXXXX` (base32 Crockford, no vowels confusion;
  uppercase; hyphen optional on input). Packs:
  - seed (31 bits)
  - delver index (4 bits — kindler/warden/gambler/ascetic + headroom)
  - difficulty (2 bits — easy/normal/hard)
  - ascension (7 bits, 0–99 clamped to unlocked at redeem time)
  - 4-bit checksum (domain-hashed) so typos fail politely, not weirdly.
- Pure codec in `lib/game/delve_code.dart` (encode/decode, no Flutter
  imports, mirrors seed_input.dart's style). NO sim change; simVersion 7
  untouched — the code only feeds existing startRun params.
- Emit: the run summary (win AND loss) shows the code under the existing
  share row; the Delver's Card (v0.34.0) footer gains the code line
  ("DELVE-3F9K2M7Q — delve it yourself." replacing the bare seed line when
  facts carry a full challenge). Clipboard fallback includes it.
- Redeem: "Delve a seed" dialog accepts codes too — parseSeedInput stays
  for bare seeds/words; a `DELVE-` prefix (or any valid 8-char code) routes
  through the codec and starts the full challenge. Ember Forge clamp stays
  the guarantee: locked difficulty/ascension clamps down with the existing
  quiet line, never a paywall prompt (spec §Ethics).

## Deliberately NOT included

- No deep links / app_links dep — codes work everywhere text works; a link
  needs Play install flow decisions that are parked with Tapiwa.
- No server, no tracking of whose code it was — a code is just params.
- No leaderboard on codes — same fairness stance as daily/weekly.

## Test plan

- Codec: round-trip property over full param space; checksum rejects all
  1-char mutations of a valid code; case/hyphen tolerance; decode of
  garbage returns null.
- Redeem flow: valid code starts run with exact params; locked ascension
  clamps; bare seed input unchanged (regression).
- Card/summary: code renders on summary and card fallback text; ethics
  sweep on all new copy.
