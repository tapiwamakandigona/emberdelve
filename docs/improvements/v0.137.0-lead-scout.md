# v0.137.0 lead scout — The Fourth Cycle

Trail: the tales audit. Since cycle three (v0.120) the game grew
two whole arcs (temper: v0.124-0.134; rotation: v0.127-0.131) plus
a delver — none of it in the fire's telling. The tales are the
game's only ambient teacher, and the review data says ambient
beats one-shot cards.

Choices:
- Feature-tour theme over pure lore: each tale doubles as a hint
  for a system a player may not have touched (the v0.120 recipe).
- Facts proved by test, not proofread: the 'two a delve' tale is
  pinned to the sim's actual refusal — if the cap ever moves, the
  test forces the tale to move with it (the mirror-assert idiom
  extended from names to PROSE CLAIMS).
- Ten, not more: the cycle length is the vista gate's unit; odd
  cycle sizes would complicate the modulo story for no gain.
