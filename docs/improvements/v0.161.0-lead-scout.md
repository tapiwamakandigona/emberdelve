  snapshot; adding one is a sim-layer change for one goal day. Deferred.

  week's rule across app versions mid-cycle; a shared challenge should not
  disagree between binaries. Rejected.
- **Record-book screen** — the Ledger already surfaces the banked stats
  (rank, marks, per-delver runs/wins, exact-kill counters). No gap.
