# v0.101.0 lead scout — The Delver's Page

Lead (queued): Ledger filter by delver. Shaped as PAGES of one book
rather than a filter control — the Ledger fiction stays intact and
'All delvers' reads as the whole book, not as clearing a filter.

Choices:
- Chips only exist for delvers with real records; a rosterful of
  empty filter options would be teaser UI.
- Ephemeral by design: which page lies open is not progress, so
  nothing touches MetaState or the save (test pins toJson).
- The sounding line follows the page. Alternative (line always shows
  all) rejected: a page where the line contradicts the rows reads as
  a bug.
- Name-only chips. Per-chip delve counts drafted and cut (restraint
  rule: the rows below already count themselves).

Queued leads: share-card trace-grid glyph weight; a delver's page
could later state per-delver win tallies (charWins exists) if the
page proves used.
