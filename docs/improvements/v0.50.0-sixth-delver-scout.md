# v0.50.0 scout — The Sixth Delver (WIP, not committed to)

## Gap

Roster archetypes: balanced (Kindler), tank (Warden), risk (Gambler),
glass-cannon (Ascetic), economy (Peddler). Missing: a **dice-manipulator /
control** archetype — the skill-expressive "fix your rolls" fantasy. The
sim already carries the machinery (`rerolls_left`, relic `rerolls=N`,
mid-combat reroll grants), so the delver is data + tuning, not new verbs.

## Candidate: The Tinker

- Fantasy: a fixer of dice — never the biggest pips, always the right ones.
- Kit sketch: 28 HP, startDice `['d6_steady', 'd6', 'd4']` (weaker pips than
  Kindler's 18), startRelic = a NEW relic `bent_pliers` `{rerolls: 2}`-class
  effect but tinker-flavored (exact effect TBD — plain rerolls may be too
  close to existing relics; consider `rerolls: 1` + `min_roll`-adjacent or a
  once-per-turn nudge ±1, which WOULD be a new sim verb → bigger job).
- Unlock: 600 embers (above Peddler's 450 — later roster, later price).
- Append LAST in charactersOrder (delve-code bits 31..34 stability), same as
  Peddler precedent.

## Cost estimate (the reason this is a scout, not a start)

- If kit uses ONLY existing verbs (rerolls + steady dice): sim-light, but
  still needs 400-seed bands ×3 difficulties, A20 hard-win pin, short-format
  spot-check, plates, codex/epithet/dye rows.
- If kit adds a nudge verb: sim change → full re-anchor risk. Avoid for a
  first cut.

## Sweep-validity finding (2026-08-25, during v0.49.0 CI wait)

The autoplay bot spends `reroll_risky` and `free_reroll` but NEVER the
relic-granted `rerolls_left` pool (no reference in lib/sim/autoplay.dart).
Consequences for the Tinker:

1. A start-relic built on `rerolls=N` would sweep artificially weak — bands
   would force overbuffing HP/dice to compensate, and human play (which does
   use rerolls) would then find the kit overtuned. Bad loop.
2. Teaching the bot to spend `rerolls_left` re-anchors EVERY playOut-pinned
   seed (loss floors, A20 pins, proving seeds) — the most expensive kind of
   change. Not worth it for one kit.
3. Therefore: build the kit from bot-legible verbs — `free_reroll` grants
   (bot widens its risky-reroll net when free_reroll is set), `min_roll`,
   steady dice, combo bonuses. Candidate start relic: one that grants
   `free_reroll` every turn ("the Tinker never rolls scared") — check how
   free_reroll is currently earned (straights?) and whether a standing grant
   is sane before drafting.

## Draft kit v1 (2026-08-25) — bot-legible, zero-new-verbs

Second re-anchor landmine found: shop relic offers draw
`loot.range(1, relicPicks.length)` over ALL of `relicsOrder`
(run_layer.dart ~L528) — adding ANY new relic resizes the pool and shifts
every default-run offer draw => full golden re-anchor. Same reason peddler
and ascetic reuse existing relics (kiln_key / whetstone) as start relics.
So: NO `bent_pliers`. The Tinker starts with an existing relic.

**The Tinker** — control/consistency archetype ("never rolls scared,
never rolls wild").
- HP **28** (fragile-mid: between ascetic 26 and kindler 30)
- startDice `['d6_steady','d6','d4']` — d6_steady has min_value 3;
  the d4 caps ceilings and is the forge-project die
- Start relic **`loaded_pips`** (min_roll 2, existing relic => pool
  untouched). Stacks under d6_steady's own min_value 3; floor profile
  becomes 3/2/2 — tiny top-end, best floor in the roster. Mirror of the
  gambler's variance identity.
- Unlock **600 embers**; append LAST in charactersOrder (delve-code bit
  rule); simVersion untouched (no sim change at all — data-only character)
- Bot legibility: min_roll is applied inside the roll helper (combat.dart
  ~L416), fully invisible to autoplay policy; no bot change, no playOut
  re-pins from behavior. Sweeps measure the kit fairly.

Open tuning questions for the build phase:
1. 28 HP with 3/2/2 floors may over-perform easy band (80-90) — probe
   first with 400-seed sweep before touching bands.
2. If overtuned: drop to 27 HP or swap d6_steady -> plain d6 before ever
   considering touching loaded_pips.
3. Codex entry + character blurb: consistency fantasy, "the delve is a
   machine; oil it."
