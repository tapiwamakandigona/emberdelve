# Colorblind (CVD) audit — 2026-08-16 — VERDICT: no release needed

Candidate "colorblind pass" (progress.md 2026-08-14 note) was evaluated with
evidence before building it. Result: **the game already survives CVD**; a
dedicated release would be cosmetic, so the candidate is retired.

## Method

`tool/cvd_plates_test.dart` captures the surfaces where red/green carries
meaning (combat intent + HP bars, map medallions, ledger stats) at 360×640.
Machado et al. (2009) severity-1.0 protanopia / deuteranopia / tritanopia
matrices applied in linear RGB (Python + numpy). Simulated plates reviewed
side-by-side with the originals.

## Findings per surface

| Surface | Under CVD | Meaning survives? |
|---|---|---|
| Enemy intent badges | attack red → gold, but the crosshair/shield ICONS + numbers carry the meaning | YES — dual-coded since the badges were built |
| HP bars (enemy + player) | red → khaki, but bars are positional + labeled ("ENEMY HP", "YOUR HP") and never compared by hue | YES |
| Map medallions | reachable = bright ring + glow + orange dashed edges; unreachable = dim. Brightness contrast survives all three CVD types; since v0.19 TalkBack also speaks reachability | YES |
| Combat notes/toasts | color varies, but every note has icon + words | YES |
| Ledger stat icons | success-green "Exact kills" merges into the gold of neighbors under protan/deutan | Cosmetic only — the icon differs and color never encodes a decision |
| Shop heal card | icon + "Heal N HP" text | YES (not plate-verified this pass; dual-coding is in the code) |

## Why this is already true

The visual language was built on icon+text dual-coding from the start
(§design-system), and v0.19.0 added full spoken semantics — the two
strongest CVD mitigations exist for other reasons.

## What would still be worth doing (folded into future work, not a release)

- If a future surface ever encodes a decision in hue alone, dual-code it at
  birth — this audit is the precedent.
- Plates + matrices are reusable: `flutter test tool/cvd_plates_test.dart`,
  then the numpy snippet in this doc's history (progress.md 2026-08-16).
