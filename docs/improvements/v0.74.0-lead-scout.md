# v0.74.0 lead scout — The Full Roster

## Question
The ledger's stats page lists the delvers as a lock icon and a win/delve
tally — the thinnest surface in the game for what is now its richest
object. Since v0.65–v0.72 a delver carries a charted depth, a worn title,
a worn dye, and a given name; the ledger row shows none of it. Balatro's
stats culture (and the Template Foundry evidence) says players re-read
their own record for pleasure — the roster page should be worth re-reading.

## Lead — the ledger roster speaks the whole identity
- Each unlocked row: the delver's SPRITE (dyed, 28dp, static) instead of
  the generic person icon; the given name with the worn title beneath in
  gold micro (exactly the picker's arrangement); tally gains the charted
  depth — `'15 wins · 30 delves · floor 9'` (floor omitted when 0, the
  charted-depth honesty rule).
- Locked rows unchanged: lock icon, roster name, 'locked'. The page
  teases nothing it doesn't already.
- Pure read-surface work: no save movement, no sim movement, no new state.

## Rejected
- **Tap-through to the picker** — the ledger is a reading room, not a
  navigation hub; every other stats row is inert.
- **Per-delver loss/best-streak stats** — chronicle-stats territory,
  rejected in v0.61 scouting; the row states what other surfaces already
  bank, invents no new counters.
- **Animated/bobbing sprites** — eight delvers bobbing in a list is a
  carnival; static like the summary's fallen-delver pose.
- **Showing the worn dye name in text** — the dyed sprite IS the dye;
  naming it twice is noise.
