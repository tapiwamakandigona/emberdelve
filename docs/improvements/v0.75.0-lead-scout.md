# v0.75.0 lead scout — The Hearth Song

## Question
The soundtrack is the game's best-reviewed craft ("the music is 9/10"),
and v0.33.0's Gramophone made it a collection — but a collected track can
only be previewed inside the ledger. The hearth itself always plays
Hearthside. Every other earned thing (dye, title, name, theme, skin) can
be WORN; the music cannot.

## Lead — pin a heard track as the hearth's song
- `MetaState.hearthTrack` ('' = default Hearthside), persisted, cloud-merged
  fresher-wholesale like other worn choices.
- `GameController.setHearthSong(key)` — heard tracks only; '' gives the
  song back. `hearthSongKey` resolver falls back to `title_menu` whenever
  the stored key is unheard/unknown (a cloud merge can never smuggle an
  unearned song onto the hearth).
- `AudioService.musicKeyForPhase` default (title) case gains an optional
  `hearthSong` param; the controller passes the resolved key. Gramophone
  stop/dispose returns to the chosen song, not hardcoded Hearthside.
- Gramophone rows: heard rows gain a trailing hearth toggle
  (`hearth-song-<key>`); the current song's marker burns gold. Locked
  rows unchanged.

## Rejected
- **Per-phase playlists** (choose combat music too) — combat/boss themes
  are authored tension, not wallpaper; the hearth is the one ambient room.
- **Ember price on pinning** — it's already earned by hearing it; selling
  it back is paywall-shaped.
- **Random/shuffle option** — settings surface for a coin-flip; the point
  is a chosen song.
- **New track content** — user has flagged APK size growth; this release
  adds zero assets.
