# v0.78.0 lead scout — The Old Foe

## Finding

`meta.enemyFellTo` banks every death per enemy id (controller L1180) and the
codex reads it per-entry, but NOTHING aggregates it: the game never names the
enemy that has ended more of the player's delves than any other. Roguelike
players carry a nemesis in their head ("that lantern thing again") — naming
it is a recognized retention hook (Hades' Theseus taunts, StS death stats):
a standing, personal score to settle that regenerates naturally as deaths
accumulate. Emberdelve's version states the record flatly and stops.

## The improvement (one)

Ledger LIFETIME panel gains one row: "The old foe" — the enemy with the most
recorded falls, named with its tally (`<Name> ×N`). Gate: count >= 2 (one
fall is bad luck, two is a foe). Tie → enemies authoring order (stable).
Unknown/retired enemy ids skipped, never crash. Key `old-foe`.

## Rejected

- Taunt copy or "go get revenge" CTA — ethics; the Ledger states, never goads.
- Summary "score settled" line when the old foe is felled — a second surface;
  scouted as its own v0.79.0 lead (needs per-run felled-set plumbing).
- Showing the full fell-to leaderboard — the codex already carries per-enemy
  deaths; one name is a fact, a ranked list is a shame table.
- Threshold 3+ — too shy; most players would never see the row in week one.
