# v0.112.0 lead scout — The Frostvein

Trail: v0.111.0 shipped the doubled week as pure challenge; studios
pair their hardest rotations with an exclusive earnable so the sit
means something afterward (the "trophy for the peak" pattern). Our
trophy shelf is the vista list — review-loved, zero balance risk,
zero APK growth (hue/sat/val matrix, no PNGs).

Choices:
- A persisted monotonic counter over deriving from runHistory:
  runHistory is capped at 30 — a derived gate would re-lock after 30
  more runs (exactly the hearthgold v0.100.0 bug, worse).
- Banking keys off the label containing '+' rather than re-deriving
  the week's rule from the index: the label is what the run actually
  ran under; re-derivation would lie if the rotation ever changes.
- Grade tuned by plate critique: first pass (sat 0.8, wash 0x2E) was
  too timid next to the emberlight control — a vista that needs a
  side-by-side to notice isn't a reward. Landed sat 0.62, val 1.08,
  wash 0x47.
- Bonus find: marked_week_test's bot passed the raw '+'-joined label
  as a single mutator id — harmless until the first real doubled
  week, which is THIS coming Monday. Fixed with the feature.
