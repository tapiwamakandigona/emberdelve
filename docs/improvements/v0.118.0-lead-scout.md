# v0.118.0 lead scout — The Flintwright

Trail: a new playable character is the highest-visibility content a
roguelite can ship (every store changelog leads with it), and the
roster had an unexplored axis: POOL SIZE. Six delvers all start
with three dice; the design space of "more, smaller" was empty.

Choices:
- Kit from existing pieces only (dice catalog, no relic): the
  tinker precedent — a new relic would resize the shop offer pool
  and re-anchor every golden. This release re-anchors NOTHING.
- 400-seed sweeps as the gate, HP as the only tuning knob: the kit
  is the identity, so balance lives in the one number that doesn't
  change what the delver IS. 28→24 in one iteration.
- Warden sheet as sprite source (not kindler): the tinker already
  wears the kindler silhouette; variety in silhouette matters more
  than variety in palette.
- Unlock 750 (above tinker's 600): the roster ladder stays
  monotone, and the swarm is the most build-warping kit so far.
