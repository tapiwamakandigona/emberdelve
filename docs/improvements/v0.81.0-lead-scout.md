# v0.81.0 lead scout — The Retraced Page

## Finding

Any remembered delve can already be SHARED (tap-to-copy its Delve Code,
v0.43; Delver's Card, v0.56) — but replaying one on your own device means
copy → back out → title dialog → paste. The player who wants to walk the
same halls again ("the one that killed me") faces three screens of friction
for a run the Ledger already remembers completely. Post-loss replay is a
proven retention loop (delveAgain/retraceDelve exist on the summary), but
it dies with the summary screen; the Ledger page never offers the road back.

## The improvement (one)

Each rememberable row gains a small replay affordance (Icons.replay, key
`history-retrace-<seed>-<date>`, tooltip 'Delve this again'): tap → pop to
root → startRun with the RECORD's seed, delver, difficulty, ascension, and
short-road flag. Gated exactly like the code (seed-0 legacy rows stay
quiet). Honors `short` from the record — same six-layer map, never one
like it.

## Honesty & safety

- No live run can exist while the Ledger is open (mid-run saves resume at
  boot; title means no run), so starting is as safe as the title dialog.
- Ascension and difficulty ride startRun's clampRunParams guarantee, same
  as pasted codes: a hard/A2 record on a profile that no longer holds the
  Forge starts at the highest the profile may choose today. The record is
  a memory, not a key — retrace never bypasses the paid gate.
- Retracing a DAILY record replays the seed as a free run — no daily badge,
  no trial bonus, and the row's copy never claims otherwise.
- A replayed win pays embers again only because it is a real run played
  again — same as pasting the code today; no new economy.

## Rejected

- Bottom-sheet action menu per row — changes the v0.43 tap-to-copy contract
  and buries both actions one tap deeper.
- Confirm dialog before starting — nothing is lost by starting a run from
  the title path; a dialog would be friction theater.
- 'Retrace' on abandoned rows — they banked a seed, so they CAN retrace;
  keep them (only legacy seed-0 stays quiet).
