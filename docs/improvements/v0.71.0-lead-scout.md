# v0.71.0 lead scout — The First Words (the premise, told once)

Date: 2026-08-26. Scout ran after v0.70.0 (The Pictured Card) closed.

## The lead

A player review (2026-08-23, verbatim): "I still don't understand what's a
delve but it doesn't matter I enjoyed the gameplay." The tour teaches the
MECHANICS (roll, pick, spend, intent, reroll) and the subtitle is a genre
tag ('A dice-builder delve into the dark') — nothing anywhere states the
PREMISE. A player finished easy mode without knowing what the word on the
logo means. FTUE research (Playio) says the first session must answer
"what am I doing and why" — we answer "how" only.

## Shape

- One quiet premise inscription on the TITLE screen, shown only while the
  profile has no ended run (`runHistory.isEmpty && runsPlayed == 0`), in
  the kept-fire slot (the two can never collide — kept-fire needs a
  remembered run). Key `first-words`.
- Copy (three short clauses, the game's voice, no instruction-manual tone):
  'The delve is the dark below the hearth — floor under floor of it.
  Go down with your dice, come back with the Ember.'
- Vanishes forever the moment the first run banks (pure derived state,
  same self-clearing pattern as keptFireLine — no new save field).
- Pure function `firstWordsLine(MetaState m)` beside keptFireLine, so the
  gate is unit-pinned.

## Rejected alternatives

- Bumping tourVersion to add a premise beat: re-shows the whole tour to
  every veteran to fix one line — rude, rejected.
- A codex entry: fresh players don't open the codex; the answer must sit
  where the question is asked (the title, before the first PLAY).
- Keeping it forever: the title is already dense (logotype, subtitle,
  pips, hearth, selectors); a permanent third line is clutter. Veterans
  know what a delve is — the review's author would never have seen it
  gone missing, but a NEW player reads it exactly when it matters.

## Risk

Zero sim/save movement. UI-only → overflow sweep (320 width — the line
must wrap, micro style) + plate critique. Fresh-profile title plates must
suppress tour/tips/news (quietTitle pattern).
