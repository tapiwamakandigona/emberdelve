# v0.72.0 lead scout — The Given Name

## The lead

Player review (2026-08-23): *"You could add character customisation …"*
The identity arc so far dresses (epithets), dyes (coats), and pictures
(sprites on summary/card) the delvers — but every Kindler in the world is
still called Kindler. The one customisation people actually mean first is
**naming**. v0.72.0: name your delver.

## Design

- `Map<String, String> charName` in MetaState + resolver
  `nameFor(charId)` → given name when set, else `characters[id].name`.
  Same contract as `epithetFor`/`dyeFor`: absent key = default; the
  built-in name is never overwritten.
- Sanitizer (pure, testable): trim, collapse inner whitespace, strip
  control chars, clamp to 16 chars. Empty after sanitizing = remove the
  key (revert to the delver's true name).
- `setDelverName(charId, raw)` on GameController: only for unlocked
  delvers; save + notify.
- Cloud merge: fresher-wholesale, exactly like `charEpithet`.
- UI: in the picker detail pane, the delver's name (h2) gets a quiet
  edit affordance for UNLOCKED delvers — tap the name row (key
  `name-edit-<id>`) → dialog with TextField (key `name-field`),
  Save / restore. Locked delvers show nothing.
- Read surfaces switch to `nameFor`: picker card h2, summary delver line,
  ledger history rows, DelverCardFacts banking (fromController and
  fromRecord — card stays a pure function of facts; facts.delverName
  already exists so the card widget itself doesn't change), obituary /
  epitaph delverName banking in controller.

## Rejected

- **Free-text on the share card only** — naming is identity, not a card
  gimmick; it must show everywhere the delver is spoken of.
- **Name unlock gated behind embers** — paywall-shaped; naming is the
  cheapest self-expression there is, it stays free.
- **Global single "player name"** — delvers are the characters here;
  the arc is per-delver (charted, dressed, dyed, named).
- **Profanity blocklist** — names render only on the player's own
  device and their own share cards; a blocklist censors self-expression
  and is unmaintainable. Sanitizer handles the technical risks.

## Ethics

Free, local, reversible (clear restores the true name). No prompts, no
teasers — the affordance sits quietly where the delver already lives.
