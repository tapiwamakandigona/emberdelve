# v0.49.0 — The Shorter Road

## One improvement

A condensed run format: **the Short Delve** — six layers instead of nine,
playable in roughly half a session. Implemented as a 4th mutator
(`short_road`) so it rides every rail mutators already have (shared-seed
runs, Trials, save/restore, autoplay sweeps), plus a standing title-screen
toggle so it isn't lost in rotation, and a Delve Code bit so a shared short
delve is the same short delve.

## Why this hook

- StS2's announced modes (2026-04, PC Gamer / PCGamesN): one is explicitly
  "for people who want the experience but don't have the time." Session-length
  fit is THE mobile retention lever our format research keeps surfacing.
- Our sessions are ~20–30 min per run; bus-ride players bounce. A 6-layer
  delve is a true run (shop, rest, elite, boss) in ~10–12 min.
- Mutator-challenge angles were already covered (Trials, Weekly); the gap was
  session length.

## What shipped

### Sim (sealed; default runs byte-identical — goldens prove it)

- `map_gen.shortRoadCfg`: layers 6, minNodes 2, maxNodes 4, **eliteFromLayer
  4**, **restGuaranteeLayer 5**, shopFromLayer 2, shopGuaranteeLayer 2,
  eventFromLayer 2. `startRun` selects it iff `short_road` is in
  `cmd['mutators']`.
- map_gen guarantee hardening (both provably inert on 9-layer maps):
  - elite guarantee falls back from plain fights to any non-rest node in the
    window (short maps can sprinkle away every fight in layers 4–5);
  - rest guarantee relaxes its layer floor one layer at a time (a
    single-layer window can have every node touching a sprinkled rest).
- `combat.dart`: on `short_road`, the boss fights at **HP ×0.58, −3
  attack/block** and elites at **HP ×0.80, −2** (min 1 as ever) — they stand
  floors earlier than the long delve tuned them for. Regulars untouched.
- `run_layer.dart`: offer/shop tier ceiling reads `layer + 3` on the short
  format (`_offerCeiling`) — the full tier-1→3 arc fits before the boss; and
  fight gold pays **×1.5** (in-run gold only, ember payouts untouched —
  fewer fights already pay fewer embers, stated plainly, spec §Ethics).

### Tuning record (400 seeds × 3 difficulties per step; bands easy 80–90 /
normal 55–70 / hard 30–45)

| Step | easy | normal | hard |
|---|---|---|---|
| Draft cfg (eliteFrom 3, restG 4), no shave | 61.5 | 27.75 | 14.25 |
| Boss ×0.75 −2; eliteFrom 4 | 74.5 | 41.5 | 21.5 |
| + elites ×0.85 −1 | 80.0 | 45.0 | 23.25 |
| + offer ceiling layer+3 | 81.25 | 48.0 | 27.25 |
| Boss ×0.62 −3 | 83.25 | 52.0 | 29.25 |
| Elites ×0.80 −2 | 85.5 | 53.5 | 31.0 |
| Boss ×0.58 | 86.0 | 53.5 | 31.5 |
| restGuaranteeLayer 5 (death-kind probe: 71/400 normal losses were
  boss-at-the-door with the only rest back on floor 4) | 86.75 | 54.25 | 31.5 |
| + fight gold ×1.5 | **87.5** | **56.0** | **32.75** |

All three in band. Death-location probes (`tool/short_death_probe_test.dart`,
deleted after use) drove each knob: first the floor-3 elite spike
(eliteFrom 3→4), then boss-door deaths (shave + rest guarantee), then broad
build poverty (offer ceiling + gold).

### App layer

- `MetaState.preferShortRoad` (sticky, cloud-merge: fresh device wins, like
  difficulty) + `_ShortRoadToggle` on the title screen under the difficulty
  selector; plain words, no pressure.
- `GameController.startRun(shortRoad:)` — a FORMAT flag, deliberately not the
  `mutators` param, so it composes with easy/normal/hard instead of tripping
  the shared-run normal pin. Retrace passes it through (same seed, same
  six-layer map). Run records stamp `'short': true` so the Ledger rebuilds
  honest codes.
- Delve Codes: bit 44 (the one spare bit in the 9-char payload) carries the
  format. Old codes carry 0 by construction and round-trip unchanged; an old
  build handed a short code ignores the bit gracefully (classic delve, same
  seed) — same forward-compat charter as unknown trial ids.
- Catalog: `short_road` appended to `mutatorsOrder` (the Weekly can now be a
  Short Week; append-don't-reorder is the sanctioned move) and a new trial
  `short_day` appended to `trialsOrder` (the daily picker hashes the date, so
  appending only re-deals dates, no weekday lock).
