# v0.10.0 "The First Delve" — staged contextual tutorials

**One improvement:** kill the up-front 4-card tutorial wall. Teach each rule at
the moment of first contact, one card at a time, once ever.

## Why (studio research, docs/improvements/studio-priorities-2026-08-16.md §3)

Front-loaded tutorial walls are the single most-cited first-minute drop-off in
mobile roguelites. Players retain a rule taught *at the moment it matters* far
better than four cards read before the first die is rolled. Our current wall
shows all four concepts before the player has acted once.

## What ships

Four one-shot contextual tips (`lib/game/tips.dart`, pure logic — testable
without widgets), directed by `TipDirector`:

| id | card (reuses existing copy) | fires at first contact |
|---|---|---|
| `roll_spend` | ROLL, THEN SPEND | first-ever fight starts (the only up-front card) |
| `intent_fair` | THE DARK FIGHTS FAIR | the enemy's first action resolves (`enemy_attacked`/`enemy_blocked`) — the receipt moment: what just happened was exactly what the badge announced |
| `combos_pay` | MATCHING FACES PAY | first `combo_pair` / `combo_triple` / `combo_straight` event — the pair just paid |
| `block_fades` | BLOCK FADES FAST | first turn whose telegraphed intent is an attack ≥ 4 — the moment block is the right answer |

### Rules

- **One tip at a time.** A trigger that fires while another tip is showing is
  simply *not shown* — and NOT marked seen. Every trigger recurs naturally
  (combos, enemy actions, big telegraphs), so the tip surfaces at the next
  first-contact moment instead. No queue, no wall.
- **Once ever.** Dismissing a tip (tap anywhere / GOT IT) persists it in
  `MetaState.tipsSeen`. Cloud merge = set union (sticky, like tutorialSeen).
- **Migration:** a save with `tutorialSeen == true` and no `tipsSeen` key is a
  veteran — all four tips are pre-seeded as seen. New profiles start empty.
- When the fourth tip is dismissed, `tutorialSeen` is set too (older builds
  sharing a cloud save must not replay their wall).
- The **manual "how to play" replay button keeps the full 4-card overlay**
  (v0.3.10 — a tester considered reinstalling to re-see it). Only the
  automatic first-fight wall dies. The manual overlay suppresses tips while
  open.
- §Ethics unchanged: no forced taps, tap-anywhere dismisses, nothing gated.

### Out of scope (deliberate)

"First-run quick-win tuning" from the backlog note would touch the sealed sim
(§Sacred sim) — not worth it: the easy on-ramp (title steers new profiles to
EASY) already covers the quick win. Not shipping balance changes.
