# v0.155.0 lead scout — The Deep Mark

Trail: the v0.154 scout flagged rune tiers as "save-format risk, needs its
own dedicated release". This is that release, kept to exactly one axis:
depth two, nothing else.

Choices:
- Deepen-in-place over a new custom id: recorded streams keep their die
  identities, and the pool never churns. The temper command shape is
  unchanged — the sim recognises "same die, same face, same rune" and
  deepens instead of re-writing (the old behaviour for that input was a
  strictly wasteful no-op re-mint, so no rational recorded stream changes
  meaning; the golden bot never tempers at all).
- OPTIONAL 'tier' save key over a simVersion bump: absent key = tier 1, so
  every pre-v0.155 save resolves byte-identically. Present key must be
  exactly 1 or 2 — anything else is corrupt data and throws, like every
  other custom-die field.
- +1-step payoffs across all six runes over per-rune bespoke effects: one
  sentence explains the whole system ("deep marks pay one step more"), and
  surge generalises contains() to a per-turn count capped at the tier —
  tier 1 byte-identical.
- 'already_deep' rejects over silently allowing a wasted temper: honesty
  doctrine; the sheet also disables the button and says why.
- Rejected this pass: tier 3 (two tiers already double the rest-fire
  decision space; a third adds numbers, not decisions) and deepening as a
  shop purchase (the forge belongs to the rest fire).
