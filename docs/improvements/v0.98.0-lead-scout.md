# v0.98.0 lead scout — The Hearthgold

Lead: every recent system feeds a visible reward except the newest —
hearthTalesHeard (v0.96.0) was the only counter with no unlock reading
it. Vistas are the established counter-to-color channel (provings →
Duskquartz, depth → Deepshale); tales → Hearthgold completes the set
and gives the rest fire a long-arc reason to matter.

Design choices:
- First brightening grade (val ×1.08): the fire gilds where the deep
  drained — visually distinct family from all six predecessors.
  Verified against a same-seed Emberlight control plate, not by eye
  on one image alone.
- Gate follows hearthTales.length rather than a literal 10, so the
  append-only tales charter can grow without the unlock line lying.
- Movement transient runTalesHeard added so the Coming Vista tease
  stays honest (only when THIS run moved the counter — §Ethics).

Rejected: an eighth vista from embers-spent (economy counters make
poor milestones — spending is not an achievement); share-card polish
(queued, needs its own critique pass).
