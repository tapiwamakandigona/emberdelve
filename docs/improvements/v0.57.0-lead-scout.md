## 1. The Fuller Record — bank what the remembered card had to omit (LEADING)

v0.56.0 shipped honesty by omission: a remembered Delver's Card drops the
fights line, floor trace, and worn epithet because run records never
banked them. That was the right call for OLD records — but every record
banked from today onward can simply remember those three facts, and the
omission stops being necessary. The card's degradation path stays (30
records deep, players will hold pre-v0.57 rows for weeks), but new
memories are whole.

- `_runRecord` banks three additive keys (old records and cloud copies
  simply lack them; cloud_merge carries runHistory wholesale, so no
  migration):
  - `fights`: `run['fights_won']` — an int the sim already counts.
  - `trace`: the floor trace as a compact `c`/`h` string ('cchch…'), one
    char per closed floor. Outcome is NOT stored — it is derivable from
    `result`, and storing it twice invites disagreement. Max 9 floors →
    ≤9 bytes per record, ≤270 bytes across the whole 30-record ledger.
  - `epithet`: `meta.selectedEpithet`, only when one is worn — the id,
    not the title, so a future rename follows through.
- `RunTrace` grows a compact codec (`toCompact()` / `fromCompact(s,
  outcome:)`) — pure Dart, roundtrip-tested. `fromCompact` rebuilds a
  closed trace, so `traceGrid` paints the terminal cell (🟥/🔥) from the
  record's own result.
- `DelverCardFacts.fromRecord` reads all three back: `fights` present →
  `fightsKnown: true` and the figure returns; `trace` present → the grid
  block returns; `epithet` present → the title returns to the name line
  AND the epitaph (worn-at-the-time is now knowable, so it is stated).
- Honesty budget unchanged: every stated field is a banked fact; absent
  keys degrade exactly as v0.56.0 shipped.
- Risk LOW-MEDIUM: zero sim changes (the record is presentation-side
  banking, same as killed_by in v0.51.0). Card worst case grows — longest
  name+epithet ("Gambler, the Well-Oiled") + 2-row trace + fights line +
  two-clause epitaph on the fixed 340×480 canvas needs its own worst-case
  widget test + plate critique.
