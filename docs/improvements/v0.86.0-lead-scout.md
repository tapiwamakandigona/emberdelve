# v0.86.0 lead scout — The Foe's Last Thread

## Finding

v0.85.0 gave narrow WINS their line; narrow LOSSES stay mute. The terminal
sim of a lost run still holds the killer (that fact already powers the
obituary's killed_by), including its hp and max_hp — so the game knows when
a delver fell one good turn short of felling the foe, and never says so.
"I almost had it" is the strongest one-more-run motive there is, and it is
a fact, not a nudge: the loss loop (Delve Again / Retrace) already waits on
the same screen.

## The improvement (one)

A quiet dim line on LOST summaries when the killer itself stood inside the
same 30% rule (hp*10 <= max*3) that defines "close" everywhere else:
'The Soot Hound hung by a thread — 3 HP standing.' Exact mirror of the
Narrow Climb's grammar. Name resolves through enemies.dart (never name a
ghost); absent when the foe was healthy — most losses stay a plain
obituary, and the line keeps its meaning.

## Rejected

- Showing the killer's remaining HP on every loss — usually a large,
  deflating number; the line earns its place only when the fact motivates.
- "One blow from falling" wording — overpromises; 30% of a boss is not one
  blow. "Hung by a thread — N HP standing" states rule and number honestly.
- A separate threshold for bosses — second definition of "close"; the 30%
  rule owns the word (danger music, Narrow Climb, and now this).
