# v0.15.0 — "The Hearthside Post" (design)

One improvement (DEMAND): a version-keyed in-game "what's new" note, so an
update is a visible return-moment instead of a silent version bump.

## Why (studio lesson 5 — updates are return-moments)

- Dead Cells' 34 free updates worked because players *saw* the game change.
  Our GitHub release notes are good devlog artifacts, but a sideloader who
  taps the icon after updating sees... the same title screen. The change is
  invisible at the exact moment it should feel like a gift.
- We now ship improvements at a steady cadence (v0.8.0→v0.14.0 in days).
  Cadence without in-game visibility wastes the return-moment.
- Trust framing: the note is a *thank-you*, never a nag. No badge pestering,
  no "NEW!" that won't clear, no links to spend money.

## Shape

1. `lib/data/news.dart` — CONTENT AS DATA, ZERO LOGIC:
   `NewsEntryDef { version, title, lines }`, newest-first authored list.
   One entry per release, 2–4 short player-voiced lines (distilled from
   docs/releases/vX.md, same campfire voice). Backfill v0.13.0/v0.14.0.
2. `MetaState.lastSeenNewsVersion` (String, default '' = never shown).
   Cloud merge: keep the LARGER version (compareVersions helper) — merging
   can never re-show old news. Persisted like other meta fields.
3. Title screen: when `lastSeenNewsVersion != currentAppVersion` AND the
   news table has an entry for currentAppVersion, show a small Panel
   ("The Hearthside Post", key `'news-panel'`) under the title menu with
   the entry + a single "Noted" button (key `'news-dismiss'`) that writes
   lastSeenNewsVersion = currentAppVersion and saves. Fresh installs: boot
   writes currentAppVersion silently on first-ever launch (no note on a
   brand-new install — nothing "changed" for that player).
4. Re-readable: Settings gains a "Past posts" tile listing all entries
   (no unread state, just an archive).

## Ethics check (§Ethics banned words)

Copy contains none of: streak/expire/hurry/miss out/last chance/beat me/
bet you/only today/can't/loser. Dismiss is one tap, permanent per version.

## Non-goals

- No remote fetch — the note ships in the binary (offline-first, no server).
- No unread badges anywhere outside the one title-screen panel.
- No sim contact, no goldens.

## Test plan

- Unit: version-compare helper; merge keeps max; fresh-install suppression.
- Widget: panel shows once for a stale lastSeenNewsVersion, "Noted"
  dismisses and persists; no panel when current; archive tile lists all.
- Plates: title screen with panel at 320×568@1.3x + 412×915 (no overflow,
  menu still fully reachable); overflow sweep.
