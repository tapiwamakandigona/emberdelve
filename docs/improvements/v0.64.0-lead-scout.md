# v0.64.0 lead scout — The Deepshale

## Candidate space considered

- Sixth vista fed by the depth record (CHOSEN)
- Eleventh proving (HELD — moves the_proven goalpost, needs epithet re-think)
- Per-character depth records (HELD — new save keys, bigger surface)
- Rumor whisper pointing at the provings shelf (HELD — no demand signal)

## Why this one

- The vista wardrobe is the game's proven cosmetic hook (v0.39.0), and every
  vista so far keys off a *counter* (wins, kills, provings). None keys off the
  depth record — yet bestFloor is the stat the game now celebrates hardest
  (Delver's Card, The Deepest Mark, ledger). A depth-earned vista closes that
  loop: the number the summary praises becomes something you can *wear*.
- Player review (2026-08-23) asked for "change backgrounds in the update" —
  vistas are exactly that, and a new unlock gives existing players a fresh
  target without touching the sim.
- bestFloor counts won-or-lost floors, so the unlock rewards pushing deep even
  on a death — consistent with the retry-after-loss research (Antihero 80.5%).

## Design

- id `deepshale`, appended LAST to `vistasOrder` (append-only rule).
- Name **Deepshale**, unlock line "Stand on the ninth floor.", gate
  `bestFloor >= 9` (ninth 1-based layer; maps have 9 layers, so it means
  touching the final floor, win or loss).
- First *desaturating* vista: hueDeg -10, satMul 0.72, valMul 0.9, wash
  `0x40232830` — cold grey slate, reads as "deep rock" against the five
  warmer/brighter vistas.
- `vistaUnlockedFor` gains `required int bestFloor`; controller passes
  `meta.bestFloor`. Pure data + resolver change, zero sim movement.

## Risks / checks

- All existing `vistaUnlockedFor` call sites patched (compile-enforced by the
  required param).
- Truth-table tests: floor 8 locked / floor 9 unlocked, blind to wins, kills,
  provings; controller-gate cases.
- Wardrobe plate re-rendered with deepshale selected (visual critique pass).
