# v0.46.0 "The Delvers Before" — content drop 4 (events + relics)

One improvement, shipped on its own (GitHub-only release per owner directive
2026-08-16). Studio lesson 5: updates are return-moments. The last pure
content drop was v0.25.0 "The Unquiet Deep"; since then every release grew
systems (codes, provings, waymarks, peddler, hearth, retrace, deep song) but
the event deck and relic roster have not moved. Drop 4 follows the documented
drop-3 procedure exactly (see v0.25.0-unquiet-deep-design.md).

## Theme

**The delvers who came before you.** v0.43 remembered *your* runs and v0.44
retraced them; this drop plants the same memory in the world itself — cold
camps, cairns, a rival's ledger, a lantern left burning for whoever comes
next. The delve remembers everyone.

## Scope — CONTENT AS DATA, ZERO LOGIC

- **+6 events** (39 → 45, appended at deck END in `lib/data/events.dart`), existing
  effect vocabulary only.
- **+4 relics** (32 → 36, appended at END in `lib/data/relics.dart`), existing hook
  vocabulary only, multi-hook combos per siege_hook/drowned_bell precedent;
  no min_roll or rerolls combos (compound too hard with loaded_pips/twin_eye).
- **+4 codex entries** (relic lore, 20 embers each — ember_sink invariant:
  the Codex covers every enemy and relic exactly once).
- NO sim logic change, NO simVersion bump (content-as-data keeps snapshots
  structurally valid). NO new assets or permissions.
