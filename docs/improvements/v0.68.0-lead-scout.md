# v0.68.0 lead scout — The Earned Name (epithet unlocks announced)

Date: 2026-08-26. Scout ran after v0.67.0 (The Dyed Delver) closed.

## The lead

Epithets unlock SILENTLY. Every other milestone the Ledger banks announces
itself on the summary in one quiet line — achievements, rank-ups
(`pendingRankUp`), opened rungs, depth records (`pendingDeepestFloor`) — but
a run that earns a NAME says nothing. The player discovers "the Unburnt"
only if they happen to reopen the wardrobe. Two releases just made epithets
per-delver and more visible; the moment of EARNING one is the hook that
gives the wardrobe its pull, and it's currently dropped on the floor.

## Shape (mirror pendingRankUp exactly — pattern proven since v0.13.0)

- Controller: snapshot `epithetsBefore` next to `rankBefore` in `_bankRun`
  (set of ids passing `epithetUnlocked`); after all counters bank, diff →
  `List<String> pendingEpithets` (transient, cleared where the other
  pendings clear). Multiple in one run is possible (a first hard win can
  earn the_unburnt AND the_delver on a fresh profile) — announce each.
- Summary: one quiet gold line per earned name, key `earned-name-line`:
  '"the Unburnt" is yours to wear.' No button, no navigation push, no
  "equip now?" — the wardrobe holds the detail (same restraint as
  rank-up-line). Shown on wins and losses alike (statValue moves on losses
  too — runs_played, best_ascension).
- Ethics check: this is a FACT about something already earned, not a
  next-goal teaser — the deepest-line precedent ("pure fact, no next-goal
  teaser") is satisfied. The banned-word list is respected in the copy.

## Rejected alternatives

- "Nearest mark" progress teaser on the summary (closest unearned epithet):
  REJECTED — the v0.61.0 deepest-line comment pins the ethics stance: "no
  next-goal teaser (§Ethics)". A dangling almost-there counter is FOMO
  shaped.
- Toast/celebration overlay: rejected — the summary's quiet-line inventory
  is the established voice; badge rain is against the studio charter.
- Persisting "seen" state for epithets (like achievements' markSeen):
  unnecessary — the diff is computed inside one bank pass; nothing persists,
  nothing can double-fire.

## Risk

Zero sim movement, zero save-format movement (transient field only).
Summary quiet-line inventory grows by one key: `earned-name-line`.
