# v0.27.0 — The Delver's Wardrobe (design)

Player ask (first outside review, Aug 23): "You could add character
customisation". Retention hook #1 (identity/expression — see
docs/research/retention-hooks-2026-08-23.md).

## What ships

**Delver dyes**: ember-priced color washes applied to the *player character
sprite* wherever the delver is drawn (title hearth, character screen, map
badge, combat stage). Same charter as hearth colors and dice skins: pure
cosmetics, price shown up front, no gameplay effect, no timers. Zero new
assets, zero payload delta — a dye is a single ARGB modulate tint over the
existing pixel-art sheet, exactly the technique dice skins use over the cream
die art.

## Data (content as data, zero logic)

`lib/data/attire.dart` — `DelverDyeDef { id, name, text, costEmbers,
tintArgb }`. Default `undyed` = identity tint 0xFFFFFFFF, cost 0: a profile
that never buys anything renders pixel-for-pixel as today. Dye tints are
high-luminance washes (≥ 0xC0 per channel) so they read as cloth dye/lighting
on the sprite, never as a solid-color ghost; verified by eye via plates before
release.

## Meta

- `ownedDyes: Set<String>` (default {undyed}), `activeDye: String`.
- JSON round-trip with unknown-id fallback to default (same as themes/skins).
- Cloud merge: owned = union, active = local (fresh) — mirrors dice skins.
- `tryBuyDye(id)` mirrors tryBuyDieSkin.

## UI

- `SpriteView` gains optional `tint` (default white = no-op ColorFilter
  skipped). Painter applies `ColorFilter.mode(tint, BlendMode.modulate)`.
- Dye applies ONLY to character sprites (enemy sprites never tinted).
- Character screen ("Choose a delver") gains a **Wardrobe** rack under the
  delver list: swatch row, tap = buy (if affordable) + equip, or equip if
  owned — same interaction grammar as the Ledger's hearth colors / dice skins
  rows. Live preview: the delver portraits on this screen render with the
  active dye.
- Title-screen delver sprite + map badge + combat hero render the active dye.

## Tests / gates

- Data test: ids unique, order covers map, default free + identity, all tints
  high-luminance (≥0xC0/channel), banned-word sweep over names+text.
- Meta: buy/equip, insufficient embers, persistence round-trip, cloud merge
  union + forge-style non-revocation N/A (cosmetic), unknown active falls back.
- Widget: character screen rack buy+equip flips swatch state; combat hero
  carries tint; enemy sprite does NOT.
- Overflow sweep (all sizes incl. tablet) green; plates of character screen +
  combat with a dye, critiqued by eye. Sim untouched → anchors byte-identical.
