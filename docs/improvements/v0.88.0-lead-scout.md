# v0.88.0 lead scout — The Coming Vista

## Finding

Vistas are the game's best-behaved unlock system — real milestones, honest
unlock lines, no prices (§Ethics) — but the progress toward them is only
visible inside the picker, a screen players visit rarely. The moment the
counter actually MOVES (a new foe felled, a new deepest floor) is spent on
the summary screen, which says nothing about it. The proximal-goal hook —
"you are 12 of 15 toward a thing you can see" — is the single most
documented honest retention device in the genre, and we own all the data
to state it truthfully. We just never say it.

## The improvement (one)

When a run moves a counter that feeds a still-locked vista, the summary
shows one dim line naming the nearest such vista with the real numbers:
'The Verdigris vista waits — 12 of 15 different foes felled.' /
'The Deepshale vista waits — deepest floor 7 of 9.' Shown ONLY when this
run moved the counter (movement detected via existing transients —
runFirstFelled, pendingDeepestFloor); silent on every other summary.
Nearest = highest fraction, ties by vista order. Zero persistence — pure
read of counters that already exist, so the line can never lie.

## Rejected

- Showing it on every summary — a static line stops being news and starts
  being a nag; movement is the only honest occasion.
- Including binary gates (Moonveil 'win a delve', Bloodstone 'win on
  Hard') — 0-of-1 is not progress, it reads as a demand; their picker
  unlock lines already serve them.
- A progress bar — over-weight for a micro line, and the summary already
  carries a grid.
- Title-screen placement — permanent presence is pressure; the summary
  moment is earned.
