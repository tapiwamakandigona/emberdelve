# v0.34.0 — The Delver's Card (shareable image summary)

## Why (research grounding)

- Directive (2026-08-16): "Research most improvements game studios work on,
  how to capture users." Acquisition is the one loop we have barely touched:
  every install so far came from direct links. Word-of-mouth artifacts are the
  cheapest honest acquisition channel a paid-nothing indie has.
- v0.8.0 already learned the Wordle lesson (the share artifact IS the
  display) — but our artifact is plain text via clipboard. Our actual player
  base lives on WhatsApp (both reviews arrived there), where an IMAGE card
  travels: it renders inline, carries the brand, and survives forwarding.
  Text grids get mangled by proportional fonts.
- Industry pass (2026-08): share-card generators are standard in roguelites
  (Slay the Spire run history screenshots, Balatro's "collection" shots,
  Vampire Survivors' stage-clear cards). None of it needs server
  infrastructure — render on device, hand to the OS share sheet.

## What

One quiet **"Share this delve"** button on the run summary (win AND loss —
records are honest both ways). Tapping opens a bottom-sheet **preview** of a
branded card, with a Share button under it. The preview IS the artifact:
what you see is exactly the PNG that leaves the device.

Card contents (all facts, nothing invented):
- EMBERDELVE wordmark + result line ("The Ember is yours" / "The dark claims
  you") in the summary's own voice.
- Delver name + difficulty (+ "Ascension N" when > 0).
- The floor trace grid (run_trace.dart) — spoiler-free, recognizable.
- Embers banked + fights won.
- Seed line: "Seed 12345 — delve it yourself." (factual invitation; an
  Emberdelve player can replay the exact delve via 'Delve a seed').
- Footer: tsorostudios.itch.io/emberdelve — where a curious friend can get it.

## How

- `lib/ui/share_card.dart`: `DelverCard` widget — fixed 340×420 logical
  canvas, hearth palette, no external assets beyond bundled fonts. Pure
  function of `(state facts)` so widget tests can pin every line.
- Summary button → `showModalBottomSheet` with the card wrapped in a
  `RepaintBoundary`. Share taps `toImage(pixelRatio: 3)` → PNG bytes →
  `share_plus` `Share.shareXFiles` (new dep, first plugin-channel feature).
- Plugin-channel failure (tests, headless, denied): caught; falls back to
  copying the v0.8.0 text summary to the clipboard + announce — the feature
  degrades to exactly what shipped before, never a crash.
- No sim change. No meta change. Pure UI + one dep.

## Ethics check (spec §5)

- Sharing is player-initiated, never prompted, never rewarded (no "share for
  embers" — that buys inauthentic reach and violates the endorsement test).
- Card copy sweep against the banned-word list is pinned in tests.
- Loss cards are equally supported: honesty is the brand.
- "delve it yourself" invites; it does not challenge ("beat me" stays banned).
