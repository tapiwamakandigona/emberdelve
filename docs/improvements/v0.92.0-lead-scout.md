# v0.92.0 lead scout — The Counted Draught

## Field survey
Third station of the counted arc. Event options price HP costs exactly
('-6 hp, +30 gold') but heals are still percentages: 'Bathe (heal 40%)'
asks for the same mental arithmetic v0.89/v0.90 removed at the rest fire
and the shop — and hides the overheal cap (at 28/30, 'heal 40%' delivers
2). 17 option labels across the 45 events carry a 'heal N%' token.

## Decision
Render-time label rewrite, single pure helper `countedOptionLabel(c, o)`
in event_screen.dart: replaces the literal 'heal N%' token with
'heal N HP' where N = healPreview(sim, max*pct~/100) — the sim's own
formula from runEventChoose. Full HP → 'heals nothing'. Data files
untouched; a label without the token passes through unchanged.

## Rejected
- '(17 to 24)' destination ranges — combined labels become soup:
  '(-12 gold, heal 9 HP, 17 to 24)'. Amount-only keeps every label one
  breath; the fixed stations (rest, shop) carry the range.
- Rewriting events.dart labels — the data is difficulty-agnostic prose;
  the count is a live read and belongs at render time.
- Disabling wasted heals at full HP — informed choice, not removed choice
  (v0.90 precedent).

## Parity path
sim.phase/event force to 'ember_shrine' (option 2 = heal_pct 25) from a
live mid-run sim (pinned shop seed 7, hp 17/30) — promise equals the
healed delta the real event_choose performs.
