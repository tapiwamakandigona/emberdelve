# v0.82.0 lead scout — The Farthest Lantern

## Finding

The lifetime deepest floor now has a number in the Ledger (v0.80.0) and a
one-time gold line at the summary (v0.61.0) — but IN the delve, where the
record is actually broken, nothing marks it. The map already paints fog,
trails, and a descent tint; the one line that would make a player lean
forward — "past here I have never been" — is absent. Racing games solved
this decades ago with the ghost/PB marker: the record made visible at the
exact moment it matters.

## The improvement (one)

The map paints one thin gold dashed rule across the boundary between the
lifetime deepest floor and the floor beyond, captioned 'YOUR DEEPEST ·
FLOOR N' — a lantern left where you last turned back. Pure meta read
(`meta.bestFloor`), gated `bestFloor > 0 && bestFloor < layers` (a fresh
profile has no lantern; a nine-floor record on a six-floor short road has
no line to draw — the whole map is charted ground). bestFloor banks at run
end, so the line holds still all run; passing it means walking beyond it.

## Rejected

- Announce/toast on crossing — transient, missable, and the summary's
  deepest-line already celebrates; the map mark is standing information.
- Painting into _MapScenePainter — separate keyed CustomPaint keeps it
  testable and repaint-isolated (scene repaints on position; this never).
- Per-run "current depth vs record" HUD chip — clutter; the map says it.
