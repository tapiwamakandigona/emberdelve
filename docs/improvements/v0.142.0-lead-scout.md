# v0.142.0 lead scout — The Written Marks

Trail: the codex coverage audit after v0.131. Every named system
had pages — world, delvers, enemies, relics, rules, dice — except
the runes, which by v0.134 anchor a whole reward arc (badge,
vista, epithet) yet existed in prose nowhere but one tip card and
the sheet's one-line blurbs.

Choices:
- A new 'rune' kind over stuffing THE DICE: kinds are the book's
  chapters, and the marks are not dice — the sheet teaches the
  mechanic, the book keeps the voice.
- 15 embers (dice price), not 10 (place price): the calendar is
  world, the marks are tools — the pricing rule from v0.131 holds.
- Lore that carries strategy: each page answers 'why would I pick
  this rune', the question the Shown Anvil card (v0.139) opens.
