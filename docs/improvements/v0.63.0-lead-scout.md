# v0.63.0 lead scout — The Fitted Name

## Origin

Not a research lead — a defect caught by our own gate. The v0.62.0
restraint plate (kept_fire_320x568) showed the EMBERDELVE wordmark
hard-clipping both screen edges at 320dp width. EmberLogotype painted at
its requested fontSize (42 at the title) without ever consulting the width
it was given; 'EMBERDELVE' in Cinzel w900 with fontSize-relative
letterSpacing simply does not fit 320dp at 42px. Every 320dp-class phone
has shown a clipped brand mark since the logotype shipped.

## Ship: v0.63.0 The Fitted Name

- `fittedLogoFontSize(text, requested, maxWidth)` (lib/ui/logo.dart, pure,
  exposed for tests): largest size ≤ requested that fits, computed in ONE
  proportional step — glyph advance and letterSpacing both scale linearly
  with fontSize, so the linear model is exact.
- EmberLogotype.build wraps the CustomPaint in a LayoutBuilder and paints
  at the fitted size. The RESERVED height stays `requested * 1.5` — the
  title's vertical rhythm is untouched on every screen that already fit.
- Unbounded/degenerate widths keep the requested size (never scale UP).
- Probe layout runs per BUILD (rare), not per frame; the painter's
  per-frame TextPainter cache keys on fontSize and works unchanged.

## Test note

The test environment's Ahem font draws every glyph 1em wide, making the
narrow case trigger reliably without real fonts; the effective painted
size is read off the CustomPaint's painter. Visual verification with real
Cinzel via the kept_fire plates re-render (320x568 now shows the full
wordmark).
