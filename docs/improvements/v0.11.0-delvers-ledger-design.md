# v0.11.0 "The Delver's Ledger" — the game remembers your fights

**One improvement:** visible learning. Every enemy you meet builds an honest,
per-enemy record — shown free in the Codex — and the run summary names the
firsts the run just produced.

## Why (backlog §4 — "the loop changes the player")

Roguelites retain when the player can SEE themselves getting better. We
already bank real counters (exact kills, streaks, bosses beaten); none of
them are per-enemy, and nothing on the summary says what THIS run added to
the record. Slay the Spire's bestiary familiarity and Hades' per-foe kill
tallies are the genre reference: knowledge of the dark, earned and displayed.

## What ships

### 1. Per-enemy record (MetaState)

- `enemyMet`, `enemyFelled`, `enemyFellTo` — `Map<String, int>` keyed by
  enemy id. Banked in `recordCombatStats` from events the controller already
  observes (`encounter_started` carries the enemy id → `_lastEnemyId`;
  `encounter_won` / `encounter_lost` close it). Sim untouched.
- Cloud merge: `_maxMap` per key (same convention as charRuns/charWins).
- No migration needed — absent maps read as empty; records start accruing.

### 2. Codex shows the record, free

Each enemy entry in the Codex gets one record line under the name:
`Met 12 · Felled 9 · Has claimed you twice` (grammar-aware, zero-count
parts omitted; never-met enemies show `Not yet met` and remain listed).
**Free for everyone** — §Ethics: mechanical/record knowledge is never
paywalled; the purchasable part stays the lore text only.

### 3. Summary names the firsts

One quiet line on the run summary (near the trace grid), only when true:
- `First sighting: <name>` — enemies whose `enemyMet` went 0→1 this run.
- `First felling: <name>` — enemies whose `enemyFelled` went 0→1 this run.
Multiple names join with `·`; nothing shows when there are no firsts.
Computed by diffing a start-of-run snapshot of the two maps (controller
keeps it beside the other run-scoped fields; rides `run_labels` on the
autosave so kill+resume keeps it honest).

## §Ethics check

All counters real and event-derived; no streak language, no pressure copy;
record line free; banned-words list respected in all new strings.

## Verification

- Unit: banking from event fixtures (met/felled/fellTo, multi-fight run,
  loss run), snapshot-diff firsts, resume-preserves-firsts, cloud merge.
- Widget: codex record line renders (met/never-met variants); summary
  firsts line shows on a first-sighting run and is absent on a repeat run.
- Overflow sweep on touched screens; banned-words test covers new copy.
- Full suite green; goldens unchanged (sim untouched).
