# v0.35.0 — The Vistas (design)

## Why

A real player asked for exactly this (reviews, 2026-08-23): *"You could add character
customisation and change backgrounds in the update."* Customisation shipped as dyes
(v0.27.0); backgrounds are the unshipped half. Vistas are also an expression/collection
hook (same family as dyes + gramophone): earned, visible identity with zero power.

## What

A **vista** is a named color-grade applied on top of the existing painted backgrounds —
the same `ColorFilter` + translucent-wash machinery the Shifting Strata (v0.28.0) proved
in production. No new PNGs → **zero APK size growth** (a standing user concern), no new
render passes beyond the one `ColorFiltered` wrapper strata already pays for.

Planned set (final matrices tuned against plates; VISUAL LESSONS apply — near-black
grading needs saturation UP + translucent wash, never plain multiply over dark art):

| id | name | feel | unlock (derived, no new unlock state) |
|---|---|---|---|
| `emberlight` | Emberlight | the default warm hearth | always |
| `moonveil` | Moonveil | cool moonlit blues | win a run on Normal (`runsWon` on normal in runHistory / difficulty stats) |
| `verdigris` | Verdigris | mossy green hollow | 15 codex entries felled (`enemyFelled`) |
| `bloodstone` | Bloodstone | deep red stone | beat a boss on Hard (`bossesBeaten` + forge unlocked path) |

## Rules

- **Selection is the only persisted state**: `MetaState.selectedVista` (String,
  default `emberlight`), compact JSON, cloud merge = most-recently-written wins is NOT
  available here — use simple local-wins-if-set like other cosmetic prefs (match dyes'
  merge rule exactly; read cloud_merge.dart before coding).
- Unlocks are **derived** from existing MetaState stats at read time — no new unlock
  bitmask to persist, migrate, or merge.
- Vista composes UNDER the strata grade: vista grade first (identity for emberlight),
  then strata depth grade/wash on top, so depth 0 + emberlight is byte-identical to
  today (golden-safe).
- Picker lives with the dyes (the wardrobe on the character screen) — one "Vista" row;
  locked entries show the honest unlock line, never a price. §Ethics: no purchase path,
  no nag, no FOMO copy.
- Title screen renders the selected vista too (that's where players will notice it).

## Gates

- UI change → overflow sweep + plate critique (all four vistas × title/map/combat plates).
- No sim change → simVersion stays 7; strata goldens must stay byte-identical for
  emberlight at depth 0.
- Ethics sweep on all player-facing copy.
- Tests: selection persistence + merge pin, derived-unlock truth table vs seeded
  MetaState, identity pin (emberlight = no wrapper), picker lock/unlock rendering.
