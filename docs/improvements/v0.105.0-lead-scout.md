# v0.105.0 lead scout — The Delver's Line

Lead: queued since v0.101.0 as 'per-delver win tallies on the
Delver's Page if it proves used'. No telemetry exists to prove use
(by charter), so the deciding question became: can the tally be
honest? A tally computed FROM the page would lie once a delver's
records fall off the 30-cap. MetaState already keeps uncapped
charRuns/charWins/charBestFloor (cloud-merged per-key MAX), so an
honest line costs one pure function — took the lead on those terms.

Choices:
- Lifetime line ONLY on a single delver's page. 'All delvers' keeps
  no line: the LIFETIME panel above already owns aggregate truth,
  and a duplicate would be noise.
- Micro style, textDim — it is a caption on the page, not a stat
  panel; the Ledger already has a stat panel.
- best floor omitted at 0 rather than 'best floor 0' (a delver who
  never delved has no floor, and 0 would read as a floor).
- Pure top-level helper (soundingBars precedent) so tests pin the
  string raw.

Queued leads: a place entry for The Gramophone if tracks grow again;
fresh audit pass for v0.106.0.
