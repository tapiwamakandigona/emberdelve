# v0.108.0 lead scout — The Proven Rules

Trail: v0.106.0 made a fifth weekly rule; the obvious next question
was 'what happens to a rule when its week ends?' Answer: it
vanishes for a month. Provings already exist as the place where
curated exact runs stand still — and they had a mutator-shaped hole
(daily trials ride the mutator seam since short_day; provings never
did).

The find of the release: the clear-match honesty bug. provings
matched on seed/delver/difficulty/rung and IGNORED mutators —
harmless while no proving had rules and dailies/weeklies were
excluded, but a player running DELVE codes couldn't trip it only
because codes can't carry rules either. Adding mutator provings
made it load-bearing; fixed with setEquals before adding content.

Choices:
- Two rules kept (all_d4, no_rests), not all five: elites_only is
  a 3%-winrate wall (bot), no_shops is close to plain, short_road
  already has its own surfaces. Start with the two most
  characterful; grow if taken.
- Seeds hunted WITH the rule applied — a seed proven winnable
  unmodded proves nothing about the modded run.
- boons: true in the clear tests (the screen starts provings with
  boons; the hunt's playRun does too).
- Modded cards suppress the Delve Code rather than showing one that
  lies (v0.103.0 precedent, third application).
- ash_summit keeps the last seat ('the last name on the list' is a
  blurb promise) — new provings insert before the rung section.

Queued leads: Gramophone place entry if tracks grow; more proving
rules if the two get taken; 'double week' composed rules.
