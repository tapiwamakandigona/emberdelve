# v0.25.0 "The Unquiet Deep" — content drop 3 (events + relics)

One improvement, shipped on its own (GitHub-only release per owner directive
2026-08-16). Studio lesson 5 (studio-priorities-2026-08-16.md): **updates are
return-moments** — Dead Cells' 34 free updates work because the game
meaningfully changed. The last pure content drop was v0.22.0 (bosses); the
event deck and relic roster have not grown since. This drop is the
"return-moment" batch that ranked-backlog item 5 called for, sized by what
drops 1–2 taught us.

## Scope — CONTENT AS DATA, ZERO LOGIC

- **+6 events** (33 → 39), appended at deck END in `lib/data/events.dart`,
  using ONLY the existing effect vocabulary. Deck size drives how long a run
  stays surprising (pick is uniform over unseen events).
- **+4 relics** (28 → 32), appended at END in `lib/data/relics.dart`, using
  ONLY the existing hook vocabulary — combo relics like v0.22's siege_hook,
  no new stat lines to teach.
- Theme: the aftermath of the Hearthless King (v0.22). The deep is unsettled —
  toppled thrones, hermits, choirs in the soot, new lodes cracked open.
- NO sim logic change, NO simVersion bump (same as drops 1–2; content-as-data
  additions keep snapshots structurally valid). NO new assets, permissions,
  or payload beyond strings.
