# v0.114.0 lead scout — The Cold Tales

Trail: after three system releases (rule/vista/honors), the cadence
called for player-felt CONTENT — the deck is the cheapest surface
where new writing changes actual runs, and the v0.46.0 precedent
("The Delvers Before", 6 events) showed themed batches read as a
statement rather than filler.

Choices:
- Theme continuity: the cold quarter's winter, told in marginalia —
  the arc that started as a weekly rule becomes world truth every
  run can trip over. Live-ops lesson applied honestly: events
  referencing the rotation make the rotation feel canonical, without
  any timer or FOMO (the events are always in the deck).
- Three, not six: deck is 50→53; the no-repeat window is already
  deep, and each event carries full effect-parity tests — quality
  bar over count.
- Amount bands copied from the v0.46.0 batch (gold 12–28, hp -4..-8,
  embers 8–14, heal 15–30%) so the new rooms are neither the best
  nor worst picks in the deck.
- LESSON (pool key): the dice pool lives on sim.player['dice'], NOT
  sim.run!['dice'] — run holds gold/embers/relics/map.

Post-build note: the deck growth tripped the golden re-anchor
procedure (7th) — 15 tests, all re-measured honestly via
tool/reanchor_v1140_probe_test.dart. Budget reality: a 3-event
content drop costs ~an extra hour of re-anchoring; fold that into
any future deck/pool growth estimate.
