# v0.18.0 "The Trimmed Wick" — payload diet, measured

Owner directive: keep improving, GitHub releases only. DEMAND perf pillar:
small download, honest presentation. The owner has also asked directly why
the game kept growing — this release is the second structural answer
(v0.14.0 per-ABI splits was the first).

## Where the weight was (measured, v0.17.0 arm64 APK = 34.9 MB)

| Payload | Size | Verdict |
| --- | --- | --- |
| `assets/audio/music` (4 loops + 2 stings) | 14.1 MB | **Target.** Vorbis stereo ~121 kbps is over-provisioned for phone BGM. |
| Engine + AOT code (`lib/`) | ~13 MB | Partially target: `--split-debug-info` strips residual symbols. |
| `assets/audio/sfx` | 0.3 MB | Leave. Gated by tool/sfx_headroom.py. |
| Fonts (Cinzel var + Inter) | 1.0 MB | **Rejected.** Subsetting Inter saves only ~460 KB and the seed
field accepts free text ("type any word") — a non-Latin seed word would render tofu. Not worth it. |
| Images | 0.5 MB | Leave. |

## Changes

1. **Music re-encode to Vorbis q2 (~96 kbps nominal).** combat, map,
   title_menu, boss_combat: 14.1 MB → 9.4 MB (−4.8 MB). Verified:
   - Loop seams: `duration_ts` sample-exact vs originals (ffprobe), same
     44.1 kHz stereo — gapless loops unaffected.
   - Spectrogram A/B (combat): q2 lowpasses at ~16.5 kHz; content below is
     intact. Honest trade, disclosed in release notes.
   - victory/defeat stings (0.3 MB) left alone — negligible savings.
   - sfx untouched; tool/sfx_headroom.py scope is sfx only, still green.
2. **`--split-debug-info=build/symbols` on all three CI builds.** Strips
   residual Dart AOT debug symbols from libapp.so. Symbols uploaded as a
   90-day CI artifact (`emberdelve-debug-symbols`) so crash stacks from
   testers can still be symbolicated with `flutter symbolize`.
3. No gameplay, sim, save, or price changes. simVersion unchanged.

## Rejected

- **Inter subsetting** — see table; free-text seed input makes it a
  correctness risk for a 1.3% saving.
- **`--obfuscate`** — complicates every future crash report and stack
  trace for a marginal size win; not worth it at this team size.
- **q1 audio (−6.3 MB)** — cutoff drops toward ~14 kHz; audible on decent
  earphones. q2 is the honest floor.

## Expected result

arm64 APK ≈ 30 MB (from 34.9). Exact sizes measured from CI and published
in the release-notes checksum table, as always.
