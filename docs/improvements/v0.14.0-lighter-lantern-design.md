# v0.14.0 — "The Lighter Lantern" (design)

One improvement (DEMAND): per-ABI release APKs, so a sideloader downloads
the ~25 MB their phone actually needs instead of the 72 MB universal APK.

## Why

- The universal APK carries THREE copies of every native library
  (arm64-v8a 18.3 MB, armeabi-v7a 15.7 MB, x86_64 19.7 MB — measured on
  v0.12.0). Any given phone uses exactly one.
- DEMAND perf pillar says <30 MB download. Play already meets it (the AAB
  is split by Google), but our GitHub releases — the ONLY current channel
  (owner directive 2026-08-16) — ship the fat universal APK.
- Owner asked directly why the game keeps growing; this is the honest,
  structural answer for the sideload channel.
- Install-size is a capture lever: smaller download = higher install
  conversion (Playio ASO 2026 applies to sideloads too — friction is
  friction).

## Shape (CI + release process only — zero app-code change)

1. CI `build-android-release`: add `flutter build apk --release
   --split-per-abi` alongside the existing universal APK and AAB builds.
2. Signer verification loops over EVERY produced APK (universal + splits):
   same permanent-key pin, fail-closed.
3. Upload split APKs as artifacts next to the existing two.
4. Release assets become:
   - `emberdelve-vX-arm64-v8a.apk` (recommended: phones since ~2017)
   - `emberdelve-vX-armeabi-v7a.apk` (older/32-bit phones)
   - `emberdelve-vX.apk` (universal fallback — kept, honestly labeled)
   - `emberdelve-vX.aab` + SHA-256 for all.
5. Release notes lead with a one-line "which file do I download" guide.

## Non-goals (kept out deliberately)

- `--obfuscate/--split-debug-info`: real size win on libapp.so but changes
  crash symbolication; separate improvement with its own symbol-artifact
  plumbing if ever taken.
- Music re-encode: already ~120 kbps Vorbis; a q-drop saves ~3 MB against
  an audible-risk cost and the SFX headroom gate re-measures shipped .oggs.
  Not worth it.

## Versioning note

`--split-per-abi` ABI-suffixes versionCode by default (Flutter adds an ABI
offset ×1000 or similar). GitHub sideloads never cross-grade between ABIs
in practice, but KEEP CODES PREDICTABLE: verify what codes the split APKs
carry and document them in the release notes; the AAB (Play's source of
truth) keeps the plain pubspec code.
