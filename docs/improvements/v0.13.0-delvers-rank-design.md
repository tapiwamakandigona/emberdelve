# v0.13.0 — "The Delver's Rank" (design)

One improvement (DEMAND): a free, meta-only progression rank that scales
without new content — studio lesson 1 from
`docs/improvements/studio-priorities-2026-08-16.md` (meta progression is what
carries players past day 7–14), the only ranked lesson not yet shipped.
GitHub-only release.

## Shape

- **Rank = a pure function of MetaState.** No new counters, no new economy,
  no sim contact. Computed at read time from what the profile already
  banked: total wins across characters, distinct enemies felled
  (`enemyFelled.length`), distinct enemies met, codex entries unsealed,
  trials completed, hard/ascension wins if owned.
- Named tiers in world voice (e.g. Ashfoot → Tinderhand → Kindler → …).
  Tier thresholds tuned so a new player ranks up 2–3 times in the first
  evening (quick-win, lesson 3) and the top tier is a long, honest climb.
- Shown on the Ledger screen header + run summary (one quiet line on rank-up
  during that run: "You delve as a Kindler now."). No badge rain.
- **Ethics check:** nothing expires, nothing resets, no comparison to other
  players, no payment interaction — rank counts hard/ascension wins only as
  "any win". Banned-words sweep over all tier names/copy.

## Why sim-safe

Everything reads existing MetaState fields; zero writes beyond what already
exists. No goldens move, no simVersion bump, no content pools touched.
