# v0.133.0 lead scout — The Six Marks

Trail: v0.132 made rune CHOICE doubly meaningful; the collection
audit says every repeatable choice system should feed a collection
(relics->codex, rules->rotation, delvers->crowns). Runes had a
volume counter (tempersSet) but no variety record — and variety is
what the second mark just bought.

Choices:
- Bank at run end from run state, not at temper time: keeps the
  sim meta-free (the tempersSet precedent exactly).
- Distinct-rune Set, not per-rune counts: the reward is trying
  each rune once, not grinding one; counts add save weight for no
  honor that reads them.
- Considered an epithet ('the Marked') — rejected: the_tempered
  (v0.129) already owns the temper identity at the vista rung;
  two temper titles would cheapen both. Titles mark arrival,
  badges mark accumulation — variety is accumulation.
