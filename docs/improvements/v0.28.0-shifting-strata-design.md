# v0.28.0 — The Shifting Strata (design)

Player ask (first outside review, Aug 23): "change backgrounds in the
update". Retention hook #2 (world freshness — see
docs/research/retention-hooks-2026-08-23.md).

## What ships

**Depth-graded backgrounds**: the rock itself changes as you descend. The
existing painted backdrops (bg_map, bg_combat, bg_boss) are graded by a
ColorFilter driven by `GameController.mapDepth` (0 at the surface, 1 at the
boss layer — the same gameplay-owned signal that already drives the Deep Hum
ambience). Upper floors keep today's warm kiln-brown; the mid-delve cools
toward ash; the deep turns toward wyrm-violet. The boss arena inherits the
deepest grade automatically.

Zero new assets, zero payload delta, one wiring point (game_root's
ScreenBackground). Title screen and pre-run phases grade at depth 0 =
identity: byte-identical rendering for everything outside a run.

## Implementation

- `Art.strataFilter(double depth)` → `ColorFilter?`; null at depth <= 0.
  Smooth lerp of hue/sat/val (reuses the wardrobe's color-matrix builder).
- `ScreenBackground` gains optional `grade` (ColorFilter?); when non-null the
  backdrop Image is wrapped in ColorFiltered. Scrim and children untouched —
  text contrast is preserved because the grade sits under the scrim.
- game_root passes `grade: Art.strataFilter(c.mapDepth)`.

## Tests / gates

- Unit: strataFilter(0) null; deep grades distinct from identity and from
  each other; matrix rows finite; depth clamped.
- Widget: ScreenBackground applies ColorFiltered iff grade non-null.
- Plates: bg_map + bg_combat at depths 0 / ⅓ / ⅔ / 1 side by side, critiqued
  by eye (distinct but recognizably the same place; UI text stays readable).
- Full suite + overflow sweep; sim untouched → anchors byte-identical.
