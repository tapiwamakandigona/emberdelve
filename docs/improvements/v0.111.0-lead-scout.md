# v0.111.0 lead scout — The Doubled Week

Trail: deferred from v0.110.0 scouting. Composed weekly rules are
the standard live-ops depth lever (rotating modifiers compound
engagement without new content cost), and our rotation had exactly
five singles — a cycle with no peak.

Choices:
- WeeklyRuleDef layer over per-mutator plumbing: singles keep
  reading name/blurb from the mutator catalog (anti-lying rule);
  only the composed slot authors its own name, because 'No Quarter +
  Cold Camps' on a button is a list, not a name.
- Pair picked by sweep, not fiat: no_shops+no_rests 102/150,
  all_d4+no_rests 38/150, all_d4+no_shops 36/150. The all_d4 pairs
  fail the fairness bar for a shared challenge pinned to normal.
- Label stays one string ('+'-joined) in saves and meta — the
  weekly_mutator save key is unchanged, old saves parse as the
  1-element case, cloud merge untouched. A list field would have
  forced a save migration for a display concern.
- Rotation shift accepted (cycle 5→6 moves this week's rule), same
  precedent as v0.106.0 appending Cold Camps.
- Title's week is DateTime.now()-gated, so the doubled title card
  can't be plated deterministically; the top-bar badge mid-run CAN
  (startWeeklyRun clock param) and is the surface players live with.
