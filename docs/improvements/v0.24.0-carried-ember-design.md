## What ships

One feature: the whole MetaState travels as a pasteable text code.

- **Export** — Settings → "Copy save code": one compact line,
  `EMBER1.<base64url(gzip(meta json))>.<fnv1a64 hex>`. Clipboard only; no
  file permissions, no share sheet, no server.
- **Import** — Settings → "Paste save code": reads the clipboard, validates
  prefix + checksum + json, then **merges** via the existing
  `mergeMetaStates` (cloud_merge.dart) — the same non-destructive contract
  the cloud path uses. Import can only add or keep progress, never lose it.
  A confirm dialog shows what the code holds (runs, wins, embers banked,
  delvers) before anything is touched.

## Contracts

1. **Pure codec** in `lib/meta/save_transfer.dart` — no I/O, no plugin
   imports (same rule as cloud_merge.dart). `encodeSaveCode(MetaState)` and
   `decodeSaveCode(String)` (returns null on ANY malformation: wrong prefix,
   bad base64, bad gzip, checksum mismatch, non-map json). Whitespace/
   newlines inside a pasted code are tolerated (messengers wrap lines).
2. **The paid unlock does not travel in the code.** `forgeUnlocked` is
   stripped to false on export. A save code is shareable plain text; letting
   it carry the Ember Forge flag would make the one paid unlock a
   copy-paste. Restore stays where it belongs: Play Billing restore
   (StoreService), which re-grants on the new device. Import ORs with local
   (merge contract), so pasting a code never REVOKES a local unlock either.
3. **Merge, never replace.** Import result = `mergeMetaStates(local,
   decoded)`: counters MAX, owned sets UNION, fresher side's spendables.
   Pasting an old code after playing loses nothing (test-pinned).
4. **Zero new deps/permissions/payload.** gzip from dart:io, base64url from
   dart:convert, FNV-1a 64 hand-rolled (checksum against corruption, not
   cryptography — the code only unlocks the player's own progress).
5. Sim untouched — no simVersion bump, anchors byte-identical.

## Ethics check (spec §Ethics)

Honest framing only: "carry your ember to a new device". No urgency, no
account nag, no server. The confirm dialog states facts (what the code
contains, that import merges). Banned-word sweep applies to the new UI copy
and news entry.

## Tests (test/save_transfer_test.dart)

- Round-trip: full-fat MetaState (all counters, sets, 30-run history,
  recaps) encode→decode → field-equal EXCEPT forgeUnlocked forced false.
- Tamper: flipping any payload char, truncation, wrong prefix, empty string,
  random garbage → decode null (never throws).
- Whitespace tolerance: code with injected newlines/spaces decodes.
- forgeUnlocked: exporter with unlock → decoded false; import merge with
  local unlocked → stays true (never revoked).
- Merge non-destruction: decoded OLD snapshot merged into fresher local →
  local counters/sets all preserved.
- Size sanity: full-fat code < 4 KB (fits any clipboard/messenger).
