# v0.80.0 lead scout — The Plumb Line

## Finding

`meta.bestFloor` is banked on every run (controller ~L1304), gates the
Deepshale vista, feeds an achievement, and fires the summary's one-time
deepest-line — but NO surface states the number afterward. The picker's
charted depth is per-delver; the sounding line is relative bars over a
30-run window. The single lifetime mark a player would quote ("I've been
to floor 12") is nowhere to read. The sounding line measures relative;
a plumb line states absolute.

## The improvement (one)

Ledger LIFETIME panel gains one row: "Deepest floor" — `m.bestFloor`,
gated `bestFloor > 0` (a profile that never delved shows nothing). Key
`plumb-line`. Icons.south, ember — depth is the game's own color.

## Rejected

- Per-difficulty deepest floors — three rows of padding for one fact.
- "of N floors" denominator — run length varies by mode; a fixed
  denominator would lie for short/daily runs.
- Restating it on the title screen — the title stays quiet; the Ledger
  is the book of record.
