# v0.93.0 lead scout — The Pictured Satchel

## Field survey
Relics have hand-drawn icons that build recognition in the shop (44px,
since v0.27-era) — but the in-run inventory, the one place a player
reviews everything they own, lists bare text. Recognition earned at the
stall is thrown away in the satchel; the reviewer praised the game's art
while the most-opened dialog shows none of it.

## Decision
Each inventory row leads with its relic icon (36px — dialog rows are
denser than shop panels), vertically centered across name + effect text.
The empty state and everything else stays. Read-only change to
relic_inventory.dart.

## Rejected
- Icon in the top-bar pip — the pip is a count, not a gallery.
- 44px shop-size icons — a 380px-capped dialog list would fit ~4 rows.
- Reordering (alphabetical/by-kind) — pickup order is the run's story.
