# v0.154.0 lead scout — The Keeper's Day

Trail: same coverage audit that found the Marked Day, one shelf
over. The rotation now touches gold, fights, embers, clean
floors, and tempers — but relics, the run's whole build identity,
never had a day.

Choices:
- Goal day over mutator day: a relic mutator would need sim
  knowledge (sealed-sim violation); the relic list already sits
  in the run snapshot.
- goalParam 2, not 1: probe over 80 seeds showed the greedy bot
  ends wins with 0–1 relics — one relic happens by accident, two
  is a decision. Trials invite a playstyle; accident pays nothing
  worth declaring.
- Judge reads `(run['relics'] as List?)?.length` — null-safe like
  every other arm, so a pre-relic save shape degrades to unmet,
  never a throw.
- Rejected this pass: an eleventh delver (roster just hit ten in
  v0.150, let the Mender breathe) and rune tiers (save-format
  risk, needs its own dedicated release).
