# v0.127.0 lead scout — The Full Rotation

Trail: the collection audit. Every repeatable mode feeds a
collection except the Weekly's rules: enemies → codex + verdigris,
provings → the Proven, delvers → Seven Ways Down, tempers → the
forge arc. Collection display is the strongest medium-horizon hook
the genre knows (StS's beaten-with-every-character grid), and the
Weekly's version also nudges players to sit the rotation's HARDER
Mondays instead of skipping to next week — retention on the exact
weeks that churn.

Choices:
- Canonical labels over slot indices: the banked fact is WHAT RULES
  the run was played under, not where the calendar stood — a future
  rotation reshuffle can never re-lock or misattribute a win.
- Legal-set filter derived from the live rotation (not a frozen
  list): a 7th rule added later starts counting the moment it can
  actually be dealt, and full_rotation's live-pinned target moves
  with it (promise wording).
- Tally rides the played-this-week block rather than standing
  alone: it is a fact ABOUT the weekly, and the block already owns
  that register.
