# v0.33.0 — "The Gramophone" (soundtrack collection)

## Why (grounding)

- First outside review (WhatsApp, 2026-08-23, logged in progress.md as
  USER-REPORTED): "the music is 9/10". Strongest praise in the review, and the
  only praised system with zero meta surface. Celebrate what players already
  love.
- Retention research (docs/research/retention-hooks-2026-08-23.md):
  hooks #1–#7 shipped or deprioritized; this is a new entry in the same family
  as #6 (collection pull) — meta-progression that adds *options, not power*
  (bugnet.io 2026-06), and gives one more "visible next action" (locked tracks
  name how to earn them).
- Charter-clean by construction: no purchase, no timer, no FOMO copy. Tracks
  unlock by simply playing; locked rows state plainly how each is heard.

## What

A **Gramophone** section in The Ledger (lifetime-stats home, fits the
"records of your delving" fiction): the 6 music tracks as rows. Unlocked rows
are tappable — tap plays that track (looped) until the screen is left or
another row is tapped; tapping the playing row stops it. Locked rows show the
track as "———" plus an honest earn-hint.

Track keys = `AudioService.musicPaths` keys, with display names + hints:

| key | name | unlock |
|-----|------|--------|
| title_menu | "Hearthside" | always (heard at the hearth) |
| map | "Into the Delve" | start a delve |
| combat | "Steel and Ember" | first combat |
| boss_combat | "The Deep Crowned" | first boss fight |
| victory | "The Climb Home" | first delve won |
| defeat | "Ashes, Gently" | first delve lost |

## How

- `MetaState.heardTracks: Set<String>` (persisted; fromJson defaults empty;
  pre-v0.33 saves: seed with 'title_menu' on load — everyone has heard it).
- Recording: `GameController` computes
  `AudioService.musicKeyForPhase(phase, bossFight: ...)` at the same points it
  already drives phase music, adds the key to `meta.heardTracks`, saves only on
  change. Title screen mount seeds 'title_menu'. No AudioService state change —
  it stays a dumb player.
- Ledger: new section under hearth colors / die skins (same collection
  contract: tap to try, no modal). Playback via existing
  `AudioService.playMusic(key)`; on dispose / row-stop, restore the
  title/ledger phase music (Ledger is reached from title, so restore is
  `playMusic('title_menu')` — verify actual phase behavior before coding).
- No sim change. simVersion 7 untouched. No new assets (reuses shipped .oggs).

## Tests

- Meta round-trip: heardTracks persists; legacy JSON (no field) → {'title_menu'}.
- Controller: starting a run adds 'map' (and 'combat' on first fight phase);
  win adds 'victory'; loss adds 'defeat' (seed 1 easy win / seed 13 easy loss).
- Widget: Ledger shows locked hint before, named row after; ethics sweep on new
  copy (banned-word list, spec §5).
- Plate tool: ledger gramophone section at 360x640 / 412x915 / 800x1280.

## Ethics check

Copy uses no banned words; hints describe play, never purchases; nothing
expires. Locked rows are a promise, not a threat.
