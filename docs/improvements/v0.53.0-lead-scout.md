research both point the same way: players commit harder when the run has a
named destination. `bossForSeed(seed)` (run_layer.dart L63) is a pure read —
the boss is decided the moment the seed exists, so telling the player is
honest, not a spoiler mechanic.

  short-road toggle description uses.

  sweeps, pins untouched by construction.
