# v0.115.0 lead scout — The Delver's Window

Trail: the 8/23 review asked for character customisation and
backgrounds; dyes (v0.27/v0.67), names (v0.72), epithets (v0.66)
and vistas (v0.35) shipped — but vistas stayed the one GLOBAL
wardrobe piece. Per-delver binding is the established idiom
(charDye/charName/charEpithet), so the seam was already proven
three times.

Choices:
- Mirror charDye exactly (map, fallback getter, junk-proof parser,
  fresh-wins merge, picker dress pills) — no new concepts, no save
  migration, fresh profiles render pixel-identical.
- The delve paints the RUN delver's window via one controller
  getter (activeRunVista) instead of scattering charId lookups
  through the UI — one truth, testable without widgets.
- Cards wear the delver's own window under the existing
  "portraiture, not history" doctrine — dyes were never banked per
  run and vistas aren't either.
- Plate critique caught a real framing miss: the first shelf plate
  showed CHOSEN without the dress pills — proof of WHO is dressed
  is the feature; re-aimed to moonveil so pills + CHOSEN share a
  frame.
