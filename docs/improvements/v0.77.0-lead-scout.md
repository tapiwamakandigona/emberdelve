# v0.77.0 lead scout — The Sounding Line

## Lead
Draw the depth of the remembered delves. runHistory (cap 30) banks `floor` per
run, but the Ledger renders only prose rows — the SHAPE of a player's progress
(deeper over time, the dip after a build experiment, the plateau before a
breakthrough) is never visible. Mastery visualization is the retention surface
studios reach for that carries no dark pattern: it states what already
happened, invents nothing, asks for nothing.

- Every bar is a real record (§Ethics honesty; same rule as RECENT DELVES).
- Oldest → newest, left → right: the reading order of progress.
- Wins in ember, losses dim, abandoned dimmer — same information the rows
  already state, now glanceable.
- Gated on runHistory.length >= 2 (one point is not a line).
- Zero new assets, zero sim movement.

## Rejected
- Trend commentary ("you're improving!") — the game never grades the player;
  the line speaks or it doesn't.
- Best-floor goal line overlay — nudge-shaped; deepest-line already announces
  records at the summary.
- Tappable bars opening the run — RECENT DELVES rows sit directly below and
  already do this; duplicated affordance.
- Lifetime chart beyond the 30-run window — would require new persistence and
  invite padding; the window IS the remembered delves.
