# v0.119.0 lead scout — The Seventh Way

Trail: every roster delver has a proving and a win-honor; shipping
the flintwright without theirs would leave the arc visibly
unfinished (the tinker got tinkers_proving + tinker_wins +
six_ways_down in its follow-up). Cheapest possible release — all
three systems already have the delver's seams.

Choices:
- six_ways_down NOT retargeted to 7: an earned badge that re-locks
  when content grows is the hearthgold bug in achievement form.
  The new count is a NEW name (seven_ways_down); the old one stands
  as history. Contrast the_six_handed epithet (v0.118.0), whose
  unlock line says 'every delver' — a PROMISE, not a tally, so it
  moves with the roster and its display name went count-free.
- Proving placed with the character provings (after tinkers_),
  not at the end: the list reads as chapters — characters, rules,
  rungs, summit.
