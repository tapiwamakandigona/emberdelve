# v0.27.0 — The Delver's Wardrobe (versionCode 53)

Player-facing: **delver dyes** — the first outside player review asked for
character customisation, so the Wardrobe answers with eight ember-priced
color washes for your delver.

- New **Wardrobe** rack on the Choose-a-delver screen: Undyed (free),
  Emberwash, Frostveil, Mosscloak, Duskrose, Goldthread, Palewisp,
  Wyrmshade. Tap an owned dye to wear it; tap a locked one to buy it —
  the price is always visible, exactly like hearth colors and dice skins.
- Your dye follows the delver **everywhere they appear**: the title-screen
  campfire idle, the map marker, the character portraits, and the combat
  stage. Enemies are never tinted.
- Pure cosmetics under the same charter as every ember sink (docs/spec.md
  §Ethics): no gameplay effect, no timers, no FOMO. The default Undyed
  applies no filter at all — a profile that never buys anything renders
  pixel-for-pixel as before this release.
- Cloud/save-code merge: dyes bought anywhere stay bought (union); the
  fresher profile keeps its worn dye. Pre-wardrobe saves are byte-identical
  (new fields are omitted at defaults).
- Zero new assets, zero payload delta: a dye is a hue-rotation color
  matrix (with saturation/value trims) over the existing pixel-art sheet,
  so each dye reads unmistakably even on saturated cloak art.

No sim changes: simVersion 7, all golden anchors byte-identical.

Design doc: docs/improvements/v0.27.0-delvers-wardrobe-design.md
Research: docs/research/retention-hooks-2026-08-23.md (hook #1 —
identity/expression).
