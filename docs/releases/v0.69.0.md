# v0.69.0 — The Standing Delver

One improvement: **the run's delver now stands on their own summary.** The
game's most emotional screen — seen after every single run — used to end
with a generic trophy or flame. Three releases built per-delver identity
(worn dyes, worn epithets, earned names announced); this one makes it pay
off where it matters most.

## What changed

- **The delver replaces the trophy/flame icon** above the result headline —
  drawn in the dye that delver actually wears. A win finds them breathing
  (the idle bob); a loss finds them still and dimmed — the dark claimed
  them, but they are still yours.
- **One small line names them with their worn title** under the headline:
  *The Kindler, the Unburnt* — the picker's voice, resolved per delver. No
  epithet worn, no comma: just the name.
- **Nothing else moved.** The sprite takes the icon's exact 56dp slot, so
  vertical rhythm and short-screen scrolling are unchanged.

## Under the hood

- Delver id read from the run record (same source as the delve code);
  dye via `meta.dyeFor`, title via `meta.epithetFor` — the v0.67.0/v0.66.0
  resolvers, so the summary can never disagree with the wardrobe.
- New keys: `summary-delver`, `summary-delver-name`.
- Zero sim movement, zero save-format movement. Suite green, analyze clean
  (fatal-infos).

## Ethics

Recognition only — the sprite and name state what happened, sell nothing,
and tease nothing. A loss keeps the delver on screen with dignity instead
of a burnt-out flame.
