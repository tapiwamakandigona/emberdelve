# v0.24.0 — The Carried Ember

One improvement, as promised: **your progress now travels as one line of
text**, so a new phone or a reinstall no longer means starting cold.

## What's new

Settings has a new panel — **Carry Your Ember**:

- **Copy save code** puts a single compact line on the clipboard. It holds
  your whole ledger: delves, wins, embers banked, delvers, cosmetics,
  codex, achievements, records, run history.
- **Paste save code** on any other device reads that line and **merges** it
  with what's already there. Counters keep the higher mark; anything earned
  on either side stays earned. Merging never takes anything away — pasting
  an old code after weeks of play loses nothing.
- Before anything is touched, a dialog states exactly what the code holds.
  Decline and nothing changes.
- Damaged or wrong clipboard text is stated as a plain fact — it is
  impossible to corrupt a save by pasting garbage.

## Why

These releases install straight from GitHub, and a sideloaded game has no
guaranteed cloud backup. "Your progress is yours" has to include the day
you switch phones. The code needs no account, no server, and no new
permissions — it is just text you own.

## Integrity

- The **Ember Forge purchase does not ride in the code**. A save code is
  shareable text; letting it carry the one paid unlock would make the
  purchase a copy-paste. The Forge restores through your Play account
  instead (Settings → The Ember Forge → Restore). Pasting a code can never
  *revoke* a locally owned Forge either — import only adds.
- Import uses the exact same non-destructive merge contract as the cloud
  save path (counters MAX, owned sets UNION, fresher side's spendables).
- The code format is checksummed: truncated or mangled pastes are rejected
  whole, never half-applied.
- Zero new dependencies, permissions, or payload. The sealed sim is
  untouched — all 8 per-boss golden anchors are byte-identical to v0.23.0.
- New tests: codec round-trip on a full-fat save, tamper/truncation/garbage
  rejection, a hand-built code claiming the Forge cannot grant it, merge
  non-destruction, clipboard-size bound, and the full Settings flow
  (copy → decodable; paste → confirm → merge; decline → untouched).
- Signed with the same certificate as every release
  (pin `031acb42566a51d5b59ffd5deb173f1b0e817a9edff1bb6979f68564d44b7a0d`).
