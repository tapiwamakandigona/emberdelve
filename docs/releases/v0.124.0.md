# v0.124.0 — The Mender's Mark

The first new combat mechanic in the release train since the Face
Forge itself: a fifth temper rune.

- **Mend** — on the tempered die's natural face, assigning it mends
  1 HP, attack or block alike. The rune vocabulary had damage
  (Blade), defense (Aegis), economy (Surge) and tempo (Echo);
  sustain was the missing axis.
- Capped at max HP, counted-heal honesty: a full delver banks
  nothing and no phantom event fires — the blurb says so up front.
- Zero re-anchor BY CONSTRUCTION: the golden replay bot's temper
  policy is off (the v7 rule — 'a bot that suddenly tempers is a
  different bot'), so every published golden, proving, and delve
  code is untouched. This is the gameplay-content lane the anchors
  left open.

## Technical

- Echo precedent: the payoff resolves after the assignment, outside
  the value math (assignment.dart marks the trigger, combat.dart
  pays it). faceRunes set + temper sheet offer list + runeName/
  runeBlurb are the full wiring checklist for rune #6.
- test/mend_rune_test.dart (6): vocabulary, both verbs heal with
  announced trigger, full-HP no-phantom pin, non-matching face pays
  nothing, command-layer acceptance, honesty sweep.
- PLATE-FONT LESSON: the temper plate tool never loaded real fonts
  — Ahem squares inflate text ~2x, which faked a 172px rest-screen
  overflow at 320 and made the old plates unreadable. Verified the
  'overflow' vanishes with real fonts (real 320 rest plates were
  approved in v0.120.0). Every plate tool MUST loadRealFonts.
