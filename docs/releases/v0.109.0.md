# v0.109.0 — The Coming Rule

The weekly rotation is deterministic — next Monday's rule is already
a fact. Now the title screen says so: once this week's Weekly Delve
has been played, a quiet line appears beneath the recap —
`Next Monday: No Quarter`.

An appointment, not a nag:

- Shown **only after this week is played** — a tease for the engaged,
  never a demand on the new.
- No countdown, no "don't miss it" — the line states the rule's name
  and stops (§Ethics; the honesty sweep covers it).
- Pure function of the rotation (`comingRuleLine`), so every player
  sees the same coming rule for the same week.

Appointment mechanics are the retention hook that respects the
player: knowing Flint Week starts Monday is a reason to come back
that costs nothing and pressures no one.
