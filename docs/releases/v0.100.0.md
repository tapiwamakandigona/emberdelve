# v0.100.0 — The Second Cycle

The hearth tales (v0.96.0) run out after ten rests and repeat. A
loyal player hears the same arc for the rest of their delving life.
The fire now knows twenty.

- Ten new tales: the second cycle sits with each of the six delvers
  in turn — who they were before the delve — then returns to the
  forge, the crowned dark, the map that is not a map, and why a story
  keeps. Same charter: one fact per tale, 1–2 sentences, ethics-swept.
- **A design bug caught and fixed**: v0.98.0 gated the Hearthgold on
  `hearthTales.length`, which read as honest but hid a regression —
  growing the tale list would have RE-LOCKED an already-earned vista
  (derived unlocks must never move backward). The milestone is now
  FROZEN at the first cycle (`hearthgoldTales = 10`); the unlock line
  says exactly that ('Hear the fire's first ten tales.'), and a
  regression test pins list-growth against the frozen gate.
- The Coming Vista tease counts against the frozen milestone too, so
  it never asks for more than the vista costs.

## Technical
