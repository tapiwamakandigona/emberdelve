# v0.115.0 — The Delver's Window

The other half of the customization ask, finished: vistas are now
worn per delver, exactly like dyes, names, and epithets.

- **THE VISTA** section gains the dress pills — pick who you're
  dressing, then bind them a light. The warden can keep deepshale
  while the gambler runs hearthgold.
- The delve paints the RUN delver's window; the shareable card wears
  it too (portraiture, not history — same doctrine as dyes).
- Unlocks stay global and derived; the legacy global selection
  survives untouched as the fallback, so nothing already chosen
  moves. Old saves are byte-identical (the binding map is persisted
  only when non-empty).
