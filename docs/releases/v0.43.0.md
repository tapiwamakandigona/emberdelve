# v0.43.0 — The Remembered Delves

Every run remembered in the Ledger's RECENT DELVES list now carries its own
Delve Code. Tap a row to copy it — any remembered run can be shared or
replayed exactly, not just the run that ended last.

## What changed

- **Tap-to-copy history** — each recent-delve row rebuilds its Delve Code
  from the record's own seed, delver, difficulty, and ascension, and puts
  it on the clipboard with one tap (small copy glyph + "tap to copy its
  Delve Code" in the row's meta line).
- Records that cannot encode — a pre-v0.3.4 run whose seed was never
  remembered — show no affordance at all. No code is better than a code
  that would lie (§Ethics honesty).
- The confirmation is spoken to screen readers, same as the summary
  screen's code copy.

## Why

Delve Codes (v0.37.0) made a run shareable at the moment it ended; the
moment passes and the code is gone. The Ledger already remembered the last
30 runs — the seed, delver, difficulty, and ascension were all sitting in
the record. Now that memory is worth something: "you have to try THIS run"
works a week later.
