# v0.75.0 — The Hearth Song

One improvement: **a heard Gramophone track can be pinned as the hearth's
own music.** The soundtrack is the game's best-reviewed craft ("the music
is 9/10"), and every other earned thing — dye, title, name, theme, skin —
can be worn. Now the music can be too.

## What changed

- Each **heard** row in the ledger's Gramophone carries a small hearth
  mark. Tap it to make that track the title music; the mark burns gold.
  Tapping the gold mark gives the song back to Hearthside.
- Preview playback (tap-to-play) now returns to **your** song when it
  stops or when you leave the ledger, not to a hardcoded default.
- **The delve's own themes stay as written** — map, combat, elite, boss,
  victory, and defeat music are authored tension, not wallpaper. Only the
  hearth listens to you.
- **Honesty at read time**: the hearth only plays a song this profile has
  actually heard. A stale cloud value or an unknown key resolves silently
  back to Hearthside — nothing unearned ever sounds.

## Under the hood

- `MetaState.hearthTrack` (cloud-merged fresher-wholesale like other worn
  choices), `GameController.setHearthSong`/`hearthSongKey`, and an
  optional `hearthSong` parameter on the audio phase mapping. Zero new
  assets — the APK gains no size. Zero sim movement. Suite green
  (+5 tests), analyze clean (fatal-infos).

## Ethics

Pins only what playing has already unlocked. No prices, no timers, no
nudges — the locked rows tease nothing new.
