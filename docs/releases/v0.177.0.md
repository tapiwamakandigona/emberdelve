# v0.177.0 — The Banked Coals

A performance-and-smoothness release: sprites now arrive warm, and a
long-standing animation freeze is mended.

## The mended fire (bug fix)

`SpriteView` builds its painter's repaint listenable in `initState` —
but the frame-loop `AnimationController` was created later, inside the
async sheet load, and the listenable was **never rebuilt**. The frame
loop ticked into a painter that never repainted. Anywhere the bob/sway
ticker wasn't running to mask it — the title hearth, map nodes, codex
cards, delver portraits — multi-frame idle animations froze on frame 0.
The driver is now rebuilt the moment the controller exists.

## The banked coals (warm cache)

- **`warmSpriteSheets()`** decodes every bundled sheet (~99 KB of
  pixel-art PNG on disk) into the existing sprite cache, once, right
  after the first frame — the title paints instantly and pays the
  decode cost while nothing moves.
- **Synchronous fast path in `SpriteView`:** when the meta and sheet
  are already cached, the sprite commits in `initState` with no
  setState and no empty-box frame. Picker cards, map marks, and first
  combats draw their sprite on their **first frame** instead of popping
  in a decode later.

## Verification

- New `test/banked_coals_test.dart` (3 tests): warm cache covers
  delvers, regulars, and bosses; a warmed sprite paints on its first
  pumped frame; the frame loop drives the painter with bob/sway off —
  **revert-checked**: the repaint test fails against the pre-fix code.
- Suite green, `flutter analyze` clean.
- No behavior change under reduce-motion: the fix wires repaints, it
  does not add motion; warm decode adds no frames.
