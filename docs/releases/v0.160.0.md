# v0.160.0 — The Second Strike

Deepening (v0.155.0 The Deep Mark) shipped with no teaching outside the
temper sheet itself. This release gives it the standard front door: an
8th contextual tip, fired once, at the first rest fire where the pool
holds a tier-1 marked die, the anvil is live, and the anvil card itself
has been seen.

## The tip

- **Id:** `deep_mark` (persisted in MetaState.tipsSeen, never renamed).
- **Trigger:** `TipDirector.onRestArrival(canTemper:, hasShallowMark:)`.
  The anvil card outranks it — a player who has never tempered cannot
  deepen — and the one-tip rule means a blocked card simply recurs at
  the next marked rest.
- **hasShallowMark derivation (rest_screen):** any `custom_dice` entry
  with `tier` absent or 1 (absent = tier 1, the v0.155.0 contract).
  Custom dice are always in the pool by construction.
- **Copy:** "A marked face can be tempered AGAIN: strike the same rune
  deeper and it pays more on the same roll — a II beside the rune says
  the work is done. Deepening spends a temper like any other mark."
