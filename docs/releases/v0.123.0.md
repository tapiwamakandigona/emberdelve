# v0.123.0 — The Crowned Company

Hard mode had one global number (hardWins) — mastery of the game's
hardest mode was invisible per delver, so the endgame had no roster
arc. Now every hard win is charted to the delver who earned it.

- **charHardWins**: banked at run end alongside charWins, saved
  only when non-empty, cloud-merged per-key MAX. Old saves are
  untouched (crowns start counting from this release — never
  guessed backward from the global number, which cannot be
  attributed honestly).
- **The tallies**: picker card and Ledger roster now read
  '999 wins · 1204 delves · 41 hard · floor 9' — the hard count
  appears only once one exists (the charted-depth no-guessing
  rule).
- **Two honors**: Three Crowns (hard wins with 3 different
  delvers) and The Crowned Company (all of them). The company is
  promise-worded, so its target tracks the live roster; Three
  Crowns is a fixed badge (§Re-pricing doctrine, v0.119.0). 56
  achievements.
