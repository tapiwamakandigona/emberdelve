# v0.91.0 — The Legible Stall

The v0.90.0 screenshot critique caught the shop squeezing its words: title
and description shared ~40% of each panel with the price button, so at
320px widths titles broke mid-word ('FIELD RATION / S') and relic texts
wrapped every two words. A shop is read before it is bought from.

- Slot rows restructured: lead icon · title · price across the top,
  description spanning the full panel width below — relic texts now read
  as sentences, not towers.
- A ware's name never breaks: titles scale down a step to fit one line
  (the same rule player names and stat captions follow since v0.87.0).

## Technical

- shop_screen.dart `_slot` only; no sim movement, no copy changes.
  Verified by plates at 320x568 (scaled one-line title + natural overheal
  cap wording), 360x640, and the 600px tablet clamp
  (tool/legible_stall_visual_test.dart); mechanics remain covered by
  test/ration_preview_test.dart, which pumps this exact layout at both
  test widths.
