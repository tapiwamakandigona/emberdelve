# v0.31.0 — The Growing Codex

The summary now names the collection at the exact moment it grows: any run
that produces a first sighting or first felling ends with one quiet line —
"Their tales wait in the Codex — N of 71 unsealed." Live counts, no button,
no urgency; the Ledger still holds the door.

- New codex pull line on the run summary (key `codex-pull-line`), shown only
  when the run produced a first, on wins and losses alike.
- Counts resolve live from the meta and the codex roster (71 entries: 39
  enemies, 32 relics) — the line can never drift from the truth.
- Design: docs/improvements/v0.31.0-growing-codex-design.md (retention hook
  #6, charter-clean: factual, unhurried, nothing paywalled).
