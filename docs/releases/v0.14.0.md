# v0.14.0 — The Lighter Lantern

**Which file do I download?** Grab `emberdelve-v0.14.0-arm64-v8a.apk` —
it fits basically every Android phone made since ~2017 and is a third the
size of the old download. Nothing else about the game changed.

## What's new

- **Per-ABI downloads.** Until now the sideload APK carried native code
  for three processor families; your phone uses exactly one. Starting with
  this release we ship one APK per family:
  - `emberdelve-v0.14.0-arm64-v8a.apk` — **recommended**; modern 64-bit
    phones (virtually everything since ~2017).
  - `emberdelve-v0.14.0-armeabi-v7a.apk` — older 32-bit phones.
  - `emberdelve-v0.14.0.apk` — universal fallback; every device, biggest
    file. If you're unsure and the arm64 one won't install, take this.
- No gameplay, balance, content, or save-format changes. Your saves carry
  over untouched.

## Why

You asked (fairly) why the download kept growing. Part of the honest
answer: every universal APK carries three copies of the engine. This
release stops charging you for the two your phone throws away, and it's a
structural fix — future releases stay light automatically.

## Under the hood

- CI now builds `--split-per-abi` alongside the universal APK and the
  Play bundle; the signing gate verifies the permanent upload-key
  certificate on **every** produced APK, fail-closed.
- Split APKs carry ABI-offset versionCodes (Flutter's scheme; recorded
  below) so Android never cross-grades between families; the AAB keeps the
  plain versionCode 40 as Play's source of truth.
- Zero app-code change: the sim, goldens, and tests are untouched.
