# v0.34.0 — The Delver's Card

**One improvement:** the run summary can now be pressed into a shareable image card — a small, honest acquisition hook that lets players carry their delves into their group chats.

## The Delver's Card

- New **"Share this delve"** button on the run summary (wins *and* losses — a loss card is first-class, not a consolation).
- Tapping it opens a preview sheet: what you see is exactly the PNG that ships. One tap to share through the system sheet, one to close.
- The card (340×420, exported at 3×) carries the result, delver, mode (difficulty + ascension), the run's trace grid, embers banked, fights won, and the seed — phrased as an invitation (*"Seed N — delve it yourself."*), never a challenge.
- Player-initiated only: no prompt, no reward, no nag. If sharing isn't available on the device, the same facts are quietly copied to the clipboard instead.
- New dependency: `share_plus`.

## Also in this build (landed alongside)

- **One-quiet-ask review prompt** (Android, Play builds only): after a second win or a won daily/weekly, the game may ask once — never after a loss, never during the tour, never again after the first ask.
- **Offline unlock-code redemption**: a Redeem row in Settings accepts signed `EMBR1` unlock codes (Ed25519-verified against an embedded public key) and opens the Ember Forge through the same door as Play billing. Groundwork for selling unlocks outside Play; no codes are in circulation yet.
- New Hearthside Post entry for this release.

## Integrity

- versionName **0.34.0**, versionCodes **60 / 1060 / 2060 / 4060** (universal / armeabi-v7a / arm64-v8a / x86_64).
