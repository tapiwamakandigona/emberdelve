# v0.39.0 — The Waymarks

**One improvement:** the run summary now names what is **within reach** — up to two unearned Ledger marks the player has already started, each with its true banked count ("3 of 7"). The resolver behind it (`nearestAchievements`, tested since v0.5.0) existed for a whole year of versions without ever being shown to a player; this release surfaces it at the moment it matters most.

## What's new

- **A quiet WITHIN REACH panel on the summary** — win or lose — listing up to two unearned achievements sorted by real progress (ties break in authoring order, so the panel is deterministic).
- **Only started goals are shown**: a goal with zero progress is excluded, because a goal you have not begun is not a goal you are near. A profile with everything earned sees nothing at all.
- **Every number is a real banked counter** (§Ethics honesty): the count text is resolved by the same `statValue` the Ledger uses, so the panel can never show a lie.
- **Shows after losses too** — the counters banked either way, so the fact is equally true. This is recognition, not a "do better" prod: the loss summary's voice stays intact.

## Why this hook

Metric achievements are the measured, ethical retention lever this game already bet on (see `data/achievements.dart` design note: D30 retention 33.96% for day-one metric-achievement completers vs 20.46% for none). The classic failure is that players never see how close they are except by opening the Ledger. The summary — the one screen every run ends on — now closes that gap with facts and nothing else: no urgency, no reward, nothing sold, and ignoring it costs nothing.

## Deliberately NOT included

- No progress bars, badges, or animations begging for attention — two text rows.
- No epithets or provings in the panel (both are binary or already surfaced at their own homes); this is the Ledger's vocabulary only.
- No tap-through CTA — the panel states facts and stops. The Ledger remains one tap from the title, as always.
