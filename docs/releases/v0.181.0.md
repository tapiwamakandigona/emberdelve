# v0.181.0 — A Codex you can read

## Codex readability (PR #99)

Lore text in the Codex moves from the 11 px micro style to the 13 px label
style with 1.5 line height and primary text colour; section headers are gold
labels; the lane tabs along the top are real 48 px `TextButton`s with a
selected state (ember fill, `Semantics(selected:)`) instead of 6 px-tall
chips. Every anchor id and the unseal/purchase mechanics are unchanged.

`test/codex_readability_test.dart` pins: 48 px lane targets at 360×800 and
320×568 with 1.3× text, selected semantics flipping between lanes, ≥ 13 px
sealed text, AA contrast for the three text treatments.
`test/codex_visual_capture_test.dart` renders the before/after plates.
