# v0.84.0 — The Song Credit

The music now introduces itself.

The soundtrack is the game's best-reviewed asset — and the one asset the
game never credited at the moment it plays. Track names lived only on the
Gramophone shelf and in the summary's grouped new-song line, minutes after
the hearing. Now, the first time a track ever plays, the flash toast names
it: '"Deeper Still" — first hearing'. The one moment a name can bind to the
music, used for exactly that.

## Honesty rules

- Once per track per profile, ever — hooked on the same heard-tracks growth
  the Gramophone already banks. At most eight toasts in a lifetime.
- The name resolves through the Gramophone catalog; a retired key is never
  credited.
- The summary's grouped line stays: the credit names the song while it
  plays; the summary banks the run's harvest.

## Technical

- Two lines in the heard-track hook + a catalog lookup helper; rides the
  existing flash toast (TalkBack live region included for free). Tests +2
  (`test/song_credit_test.dart`). Zero assets, zero sim movement.
