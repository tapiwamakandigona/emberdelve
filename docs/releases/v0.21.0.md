# Emberdelve v0.21.0 — "The Watchtower"

One improvement: **the game can now tell you when a newer release exists** —
because a sideloaded game has no store, and until today every improvement we
shipped reached only new downloaders.

## What's new

- **Check for updates, in Settings.** One tap asks GitHub for the newest
  release and tells you, inline, as a plain fact: *"v0.22.0 is out — you
  have v0.21.0."* / *"You're on the latest release."* / *"Couldn't reach
  the watchtower. Try again later."* Nothing downloads; a **Copy link**
  button puts the releases page on your clipboard.
- **Optional launch check, OFF by default.** Flip *"Check once at launch"*
  in Settings and the game quietly looks once per launch. If — and only
  if — a newer release exists, ONE small line appears on the title screen
  ("v0.22.0 is available — see Settings"). Tap it once and it's gone for
  that version, forever.

## The quiet parts, said out loud

- **No network call without your say-so.** The launch check runs only after
  you turn the toggle on — and our test suite proves the OFF state performs
  zero network calls. The manual button only ever acts on your tap.
- **Never a nag.** No modal, no badge, no red dot, no reminder. A dismissed
  notice never returns for that version.
- **One endpoint.** The only thing the game ever talks to is GitHub's
  public releases API — no server of ours, no tracking, nothing sent
  beyond the request itself.
- **This choice stays on this device.** Update preferences deliberately do
  NOT ride the cloud save: opting in on one phone will never start network
  calls on another.

## What didn't change

- The sim is untouched — no gameplay, balance, or content changes.
- Offline play: everything works exactly as before with no connection;
  the checker just says it couldn't reach the watchtower.
- No new permissions and no new dependencies.

## Under the hood

- `UpdateService` (lib/meta/update_service.dart): plugin-free, injectable
  fetcher, headless-tested against newer / same / older / garbage / offline
  fixtures — a malformed answer is a quiet inline error, never a crash and
  never a false "update available".
- New gate `test/update_service_test.dart` (17 tests): consent (zero
  fetches while off), per-version dismissal persistence, inline UI states,
  clipboard copy, and a 320×568 overflow guard for the new section.
- Design notes: `docs/improvements/v0.21.0-watchtower-design.md`.

Thank you for delving with us.
