# v0.82.0 — The Farthest Lantern

The map now marks the deepest you have ever delved.

The record had a number in the Ledger (v0.80.0) and a one-time gold line at
the summary (v0.61.0) — but IN the delve, where the record is actually
broken, nothing marked it. Now the map paints one thin gold dashed rule at
the boundary between your lifetime deepest floor and the floor beyond,
captioned 'YOUR DEEPEST · FLOOR N' — a lantern left where you last turned
back. Racing games have known this for decades: the personal best made
visible at the exact moment it matters.

## Honesty rules

- Pure read of the banked record — it holds still all run and moves only
  when a finished run banks deeper. Passing it means walking beyond it.
- A fresh profile has no lantern; a record beyond this map's floors (a
  short road after a nine-floor career) has no line to draw — the whole
  map is charted ground.
- Standing information, not a nudge: no toast, no glow, no sound.

## Technical

- Separate keyed CustomPaint (`plumb-mark`) layered over fog, under nodes;
  repaint-isolated from the scene painter (scene repaints per move, the
  lantern only if the record changes). Same row math as the fog rects.
- Tests +3 (`test/farthest_lantern_test.dart`). Zero assets, zero sim
  movement, controller untouched.
