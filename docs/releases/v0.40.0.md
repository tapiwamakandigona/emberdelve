# v0.40.0 — The Peddler

**One improvement:** a fifth playable delver — **The Peddler**, the economy archetype the roster lacked. A lean pouch (d6 + d6 + d4, 14 pips against the Kindler's 18) and 31 HP, traded for a **Kiln Key**: +8 gold from every won fight, so the shops do the delver's forging. Unlocks for 450 banked embers, the roster's priciest and hardest-won seat.

## What's new

- **The Peddler** (teal, hooded): starts weak and buys its way strong — a build-your-own-delver fantasy no other start offers.
- **The Coin Hook**, a signature weapon: a brass cargo hook with a coin-weighted pommel, drawn and animated like every other signature.
- **Three new ledger marks**: *Fair Trade* (win a run as the Peddler), *Full Company* (unlock all five delvers), *Five Ways Down* (win with all five).
- **Old marks stay honest AND stay earned** (§Ethics): *Full Hearth* and *Four Ways Down* keep their target of 4 with reworded text ("Unlock four delvers", "Win a run with four different delvers") — bumping the target would have un-earned a mark players already hold, and a derived recognition must never be taken back.

Tuning history is in the probe (`tool/peddler_sweep_probe_test.dart`): a 4th die tested wildly overpowered (76% on hard — action economy dominates this sim), so the lean-dice + gold-engine identity was kept and the last points bought with HP (29 → 31).

## Deliberately NOT included

- No sim changes — simVersion stays 7. A character is start parameters the sim already consumes generically; every existing seed, golden replay, and shared Delve Code is untouched (the Peddler appended LAST, so code indexes 0–3 are stable).
- No paid unlock — the Peddler costs banked embers like every delver before. The Ember Forge remains difficulty-only.
- No roster achievement regression (see above).

## Art provenance

`characters/peddler.png` is a palette variant (HSV: hue +160°, sat ×0.90, val ×0.95) of the bundled gambler sheet (0x72 DungeonTilesetII `elf_m`, CC0) — same technique as the v0.5.0 bestiary, recorded in PROVENANCE.md. Teal was chosen because red, grey, copper, and coal are taken, and a gold elf could be counterfeited by a Goldthread-dyed Gambler.
