# v0.106.0 — The Cold Camps

The Weekly Delve had four rules, so its rotation repeated monthly.
A fifth joins: **Cold Camps** — no rests on the map, every camp is
a fight instead. Healing comes only from shops, events, and what
you carry.

- Pure map relabel like its siblings: consumes NO rng, so layout
  and every downstream draw match an unmutated run of the seed —
  only rest nodes change kind, start and boss untouched.
- Composes orthogonally: rest → fight (no_rests) → elite
  (elites_only), same one-loop pass.
- 150-seed autoplay sweep (kindler/normal): plain 97/150 wins,
  no_rests 99/150, 0 invalid — the extra fights' embers roughly
  offset the lost healing for the bot; players who lean on camps
  will feel it more. A mid-ladder week, not a wall.
- Normal/Daily runs untouched (empty mutator set short-circuits);
  since v0.103.0 every record banks its mutators, so ledger rows
  mark 'weekly · Cold Camps' honestly and modded rows still hide
  the un-encodable Delve Code.

## Technical

- data/mutators.dart: 'no_rests' appended to mutatorsOrder (rotation
  is forward-looking; past records bank their own rules).
- sim/run_layer.dart _applyMapMutators: rest→fight pass, first in
  the compose chain.
- test/cold_camps_test.dart (3): exact relabel + no-drift diff over
  20 seeds (with a bite guard), elites_only composition, catalog
  honesty sweep. Existing rotation tests auto-cover the new id.
