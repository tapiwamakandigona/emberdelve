# Emberdelve v0.56.0 — Card from the Ledger

"Let me show you the one that killed me" no longer dies with the summary
screen.

## Card from the Ledger

- Every remembered win or loss in the Ledger's **Recent Delves** now
  carries a share icon: tap it and that run becomes a full Delver's Card,
  days later — epitaph, mode, embers and Delve Code included.
- Honesty budget, per line: everything on a remembered card comes
  straight off the run's record. A win names its boss because the boss is
  a pure function of the seed (proven in v0.53.0 The Rumor); a loss names
  the killer the Ledger banked at the time.
- What a record never banked — the fights count, the floor trace, the
  epithet worn that day — is **omitted, never invented**. A remembered
  card simply says less; it never guesses.
- Walked-away runs offer no card: no ember, no grave, no story.
- Old records degrade gracefully: a pre-v0.51.0 loss keeps its opener and
  floor without naming a killer, and a seed-0 relic record neither names
  a boss nor offers a code that would lie.

## Notes

- Zero gameplay changes — same sim, same seeds, same odds.
- Sharing stays player-initiated, never prompted, never rewarded
  (docs/spec.md §Ethics); loss cards remain first-class.

Thank you for playing — and for every card that travels further than the
run did.
