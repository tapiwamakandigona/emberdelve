# v0.145.0 — The Bearer

The NINTH delver: the giant — the flintwright's exact opposite
pole. Where the swarm rolls four small dice, the bearer carries
TWO, one of them a Molten Core (the biggest die any kit starts
with), plus an Iron Scale and the smith's Echo already worked
into the 12. Few rolls, grand promises. 36 HP — the bearer
carries. 1050 embers.

## Balance (400-seed bot sweeps vs kindler 89.75/67.25/41.50)

Two dice STARVE intent coverage — the naive giant collapses:
- d10+d6, 30 HP: 74.50/14.50/5.75 (unshippable)
- d12+d8, 30 HP: 81.25/33.25/12.75 (still starved)
- d12+d8 + Iron Scale + Echo mark, 34 HP: 90.75/65.00/37.50
- **d12+d8 + Iron Scale + Echo mark, 36 HP: 91.75/67.50/39.50** ✓

The kit buys coverage back with size, steel, and the mark; HP
stays the last knob. New prior recorded: dice-count is worth far
more than pip-count — a lost die costs ~30 winrate points on
normal, an order beyond the ~2-HP-per-advantage rule.
