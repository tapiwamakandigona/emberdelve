# v0.111.0 — The Doubled Week

The Weekly rotation grows its sixth slot: one week per cycle deals a
declared, named PAIR of rules.

- **Cold Quarter** — no shops and no rests. Every camp is a fight,
  gold buys nothing, and healing comes only from events and what you
  carry.
- The pair was chosen by bot sweep, not vibes: Cold Quarter wins
  102/150 on the kindler at normal — a real challenge, still fair.
  Both all_d4 pairs swept at ~37/150 and were rejected.
- Same charter as every weekly: the rule is declared up front, the
  whole player base gets the same seed and the same rule, no
  streaks, no expiry — a missed week is simply a missed week.
- "Next Monday:" (v0.109.0) now names the pair too, so the doubled
  week never ambushes anyone.
- The Ledger already lists both rules on the run's mark (v0.103.0),
  and modded-row rules (no code, no retrace) apply unchanged.

## Technical

- lib/game/weekly.dart: `WeeklyRuleDef` (singles read the mutator
  catalog; the doubled slot authors its name), `weeklyRuleFor`
  (cycle = catalog + 1), `weeklyRuleName` (order-insensitive pair
  match, total on unknown input), comingRuleLine/share rule-aware.
- startWeeklyRun: rule-based; label stores ids '+'-joined — old
  saves (single id) parse identically, no migration. Gains the
  test-only `clock` param (startDailyRun precedent).
- test/doubled_week_test.dart (6): slot legality, display names,
  both-rules-applied map proof, share text, bot-winnability, honesty
  sweep. Plates week_360x640 / week_320x568 approved.
