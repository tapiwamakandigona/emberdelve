# v0.154.0 — The Keeper's Day

The relic shelf — twenty-two relics deep since the early delves —
had no day in the trial rotation. Now it does:

- **The Keeper's Day** (goal day): end the delve carrying two or
  more relics; the day pays 15 embers. Vanilla rules otherwise.
- New goal kind `relics_at_least`, judged from the run's own
  relic list — pure observation, the sim stays sealed (the trials
  charter's core contract).
- Append-LAST on the rotation: the hash changes by one modulus,
  not a reshuffle of authored order.

## Technical

- lib/game/trials.dart: one new switch case over `run['relics']`
  (a missing list is empty, not a crash). lib/data/trials.dart:
  one TrialDef + order entry. trials_test known-goals set updated.
- goalParam 2, not 1: the greedy autoplayer already ends most wins
  with 0–1 relics on pure economy play (probed, 80 seeds), so the
  day asks for a real spending choice a player controls at any
  shop or reward — an invitation, not a treadmill.
- test/keepers_day_test.dart (3): the def, the judge (0/1/2/3/
  missing list), and the forward-compat contract (an unknown goal
  id pays silence, not a crash).
- No new plates: the trial line renders through the same title
  widget as all nine existing trials.
