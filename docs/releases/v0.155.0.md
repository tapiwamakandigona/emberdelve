# v0.155.0 — The Deep Mark

The forge learns a second stroke. Temper the same face of the same die with
the same rune again, and instead of re-writing the mark, it **deepens**.

## Deep marks

- Every rune pays one step more at depth two:
  - **Blade** — attacks on that face hit for **+3** (was +2).
  - **Aegis** — blocks on that face hold **+3** (was +2).
  - **Surge** — the reroll returns **twice** per die each turn (was once).
  - **Echo** — the next opposite action gains **+2** (was +1).
  - **Mend** — mend **2 HP** on that face (was 1). A full delver still mends
    nothing.
  - **Gilt** — the assignment pays **3 gold** (was 2).
- Deepening spends a temper like any other mark, and still banks the rune
  for the Six Marks. Two tempers a delve, unchanged — depth or breadth is
  now a real decision at the rest fire.
- A mark already deep rejects honestly; the temper sheet says so before you
  commit, never after.
- On the die, a deep mark wears a plus — `B4+` — and the spoken description
  says "Blade II".

## Old saves

The mark's depth is a new, optional field. Every die tempered before this
release simply reads as depth one and plays exactly as it always did.
