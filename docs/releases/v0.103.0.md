# v0.103.0 — The Marked Week

Two honesty gaps in one audit. Weekly runs banked no mark — the
record rendered as a plain run. Worse: the row offered a Delve Code
and a retrace that would rebuild the run WITHOUT its weekly rule — a
code that lies, from the same Ledger that gates seed-0 records for
exactly that reason.

- Records now bank 'weekly': true (like the daily's mark) and the
  run's declared mutators — the weekly's rule, or a trial day's.
  short_road stays out of the list: it IS encodable and already banks
  as 'short'. Additive keys; old records render exactly as before.
- The row states the rule by name: 'weekly · Flint Week · normal ·
  2026-08-24 · 7 fights'.
- Modded rows offer NO Delve Code and NO retrace — a code cannot
  carry the rule, so both would rebuild a different run. They stay
  quiet (seed-0 precedent), and the stated rule explains why. The
  Delver's Card is still offered: it states facts, it rebuilds
  nothing.
