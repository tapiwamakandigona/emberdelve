# v0.102.0 — The Painted Trace

The Delver's Card is the one artifact built to leave the game — and
its floor grid was emoji text, rendered with whatever emoji font the
device vendor ships. Samsung's squares are not Google's squares, and
a shared card changed face per platform.

- The card now PAINTS its floor grid: one rounded cell per floor,
  five per row — clean in green, hurt in gold, the fall in red, the
  claimed Ember in ember with a gold ring. Deterministic on every
  platform, and on-brand instead of vendor-styled.
- The share TEXT keeps the emoji grid: text has no painter, and emoji
  is the honest medium there.
- Records bank the emoji string (v0.57.0), so the widget parses it
  back — unknown runes dropped, never guessed (fromCompact precedent).
  Remembered cards from the Ledger repaint identically.
- TalkBack reads 'Floor trace: N floors, the Ember claimed.' — floors
  and outcome only. Per-floor counts are NOT stated: the outcome cell
  replaced its floor's clean/hurt mark in the banked string, so any
  count would be a guess.

## Technical

- share_card.dart: public `traceCells(String)` parser + PaintedTrace
