# v0.19.0 — The Spoken Flame

**Which file do I download?** `emberdelve-v0.19.0-arm64-v8a.apk` for most
phones, as always.

## What's new

- **Emberdelve now works with TalkBack.** Turn on Android's screen reader
  and the whole delve speaks:
  - Every map medallion announces what it is and where it stands:
    *"Elite fight, floor 3, reachable"*, *"Rest site, floor 5, out of
    reach"*, *"you are here"*.
  - The drawn ember toggles in Settings announce their name and state —
    they used to be silent coals.
  - Every toast is spoken the moment it appears: heals, forges, surge
    rerolls, and *why* an invalid move was refused.
  - Phase changes are called out: *"The delve map"*, *"Combat: Ash Thrall
    with 14 HP"*, *"Choose a reward"*, *"Victory. The run is won"*.
  - Buttons, dice (face, value, what they contributed), HP bars and
    enemy intents already spoke — now nothing in the game goes silent.
- **And it stays that way.** A new automated gate walks the entire game
  with semantics on and fails our build if any tappable control has no
  spoken label. The gate also proves it actually audited dozens of
  controls — a check that finds nothing must show it looked.

## Why

A turn-based dice game has no timing pressure — it's a genre a blind
player can genuinely win at, if every piece of information a sighted
player sees is also spoken. That's the same fairness promise the rest of
the game makes, extended to ears.

## Under the hood

- No gameplay changes. Saves, balance, prices, content: untouched.
  Pure presentation layer; the sim is unchanged.
- Uses live regions for toasts and per-view `sendAnnouncement` for phase
  changes (no deprecated APIs).
