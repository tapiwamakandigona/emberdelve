# v0.38.0 — The Provings

**One improvement:** eight named, curated challenge delves — **The Provings** — now live behind a quiet line on the title screen. Each proving is an exact run (seed, delver, difficulty, ascension rung): same floors, same offers, same rolls for everyone who takes it.

## What's new

- **Eight provings, easiest to hardest**: The First Flame, The Shield Oath, The Loaded Dice, The Empty Hand, The Fifth Rung, The Tenth Rung, The High Stakes, The Ash Summit — spanning all four delvers, all three difficulties, and rungs 0–15.
- **Every seed is machine-proven winnable** by the autoplay bot before it earned a name — and the bot plays worse than you do. A test pins this forever: if a future balance change ever made a proving unwinnable, CI would fail.
- **The clear mark is the whole prize** (§Ethics): no ember payouts, no unlocks, no forced order, nothing rotates, nothing expires. Winning the exact run marks it cleared; the title screen states the count as a fact.
- **Each proving shows its Delve Code** (v0.37.0), so a proving is also something you can hand to a friend in any chat.
- A proving you can't start yet states its requirement as a quiet fact — a locked delver, hard mode, or an unearned rung — and never prompts a purchase.

## Deliberately NOT included

- No rewards for clearing — provings are tests of play, not a currency faucet (the Ledger's stance).
- No leaderboards, no completion timers, no "proving of the week".
- No sim changes — simVersion stays 7; a proving is just exact start parameters. Cloud sync merges clear marks by union, same as every other earned set.
