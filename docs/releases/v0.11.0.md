# v0.11.0 — The Delver's Ledger (build 37)

One improvement, shipped on its own (GitHub-only release; no Play submission
per owner directive 2026-08-16): **the game now remembers your fights, and
shows you the record.**

## For players

- **Every enemy in the Codex now carries your record with it.** Under each
  name: how many times you've met it, how many you've felled, how many times
  it has claimed you — `Met 12 · Felled 9 · Deaths 2`, with zero counts
  simply left out. Enemies you haven't faced yet read `Not yet met.` The
  record line is **free for everyone** — knowledge of the dark is never
  paywalled; the Ember Forge lore text stays what it always was.
- **The run summary names your firsts.** When a run produces a first — the
  first time you've ever sighted an enemy, or the first time you've felled
  one — one quiet line on the summary says so: `First sighting: Cinder
  Wisp` / `First felling: Ash Rat`. No badge rain, no confetti; just the
  ledger acknowledging the run that wrote it.

Records start accruing from this build onward. Nothing is retroactive and
nothing is invented — the ledger only writes what it witnessed.

## Under the hood

- Three new profile maps (`enemyMet` / `enemyFelled` / `enemyFellTo`),
  banked from combat events the controller already observes. The sim is
  untouched — zero snapshot changes, all golden hashes unchanged.
- Cloud saves merge each map per-key by max, the same convention as
  character runs/wins. Absent maps read as empty; no migration needed.
- Run-scoped firsts survive kill-and-resume: they persist beside the
  autosave and are restored on boot, so a summary reached after an app
  restart still names the firsts honestly.
- New test file (`test/enemy_record_test.dart`): banking, firsts fire only
  on 0→1, fresh runs clear them, save/cloud round-trips, resume-mid-run,
  plus widget coverage of the summary firsts line and the Codex record line.

## Why this, first

Backlog `docs/improvements/studio-priorities-2026-08-16.md` §4: the loop
should visibly change the player. Roguelites retain when players can see
themselves learning — per-foe records are the genre's proven shape for that
(bestiary familiarity, per-foe tallies). This is the smallest honest version:
no new systems, no new economy, just memory made visible.
