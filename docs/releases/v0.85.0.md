# v0.85.0 — The Narrow Climb

Wins now admit how close they ran.

The game has always known — the low-HP danger rule (HP at or under 30% of
max) has darkened the combat music since v0.23.0 — but the summary never
said it. A won run read identically whether the delver walked out untouched
or crawled out at 1 HP. Now a narrow win closes with one quiet line:

> A narrow climb home — 1 HP standing.

Near-miss memory is the run players retell. The summary states the fact at
the only honest moment, in the same breath as the result.

## Honesty rules

- Same threshold as the danger music — the line and the low-HP bed can
  never disagree about what "close" means. No second definition invented.
- Dim micro text, not gold: perhaps a fifth of wins qualify, and gold stays
  rare. Absent entirely on losses and comfortable wins.
- Nothing persisted — no schema growth; the summary is the moment.

## Technical

- `narrowClimbLine()` helper + one gated Text (key `narrow-climb`) in the
  summary's reflection column. Tests +3 (`test/narrow_climb_test.dart`,
  boundary-inclusive). Plate-critiqued at 360x640 and 320x568. Zero assets,
  zero sim movement.
