# v0.94.0 — The Deep Wardrobe

The first outside review asked for character customisation; the wardrobe
answered with dyes, vistas, and epithets. This release deepens both ends
of that shelf after a plate audit found two hue gaps (no true red — the
Duskrose reads pink — and no teal at all) and a title shelf whose feats a
veteran has long outgrown.

- Two new dyes: **Emberheart** (480 embers), a true crimson, and
  **Glowmere** (560), a still-pool teal. Same charter as every dye —
  bought once with embers, pure cosmetics, real prices up front.
- Three new earned titles: **the Deepdrawn** (reach the ninth floor),
  **the Measured** (end five fights in a row on exactly the damage
  needed), and **the Six-Handed** (win a delve with every delver). Each
  reads a real banked Ledger counter; earned by delving, never sold.
- The Proven remains the last word on the shelf — the new titles slot
  before it.

## Technical

- Data-only content: attire.dart + epithets.dart entries; zero sim
  movement, zero UI logic changes (the wardrobe shelves are data-driven).
- test/deep_wardrobe_test.dart pins order (the_proven last), target
  honesty (the_six_handed target == roster count, junk charWins keys
  ignored), exact unlock thresholds, ascending dye prices, non-identity
  filters, and the one purchase path. Existing ethics/coherence sweeps
  cover the new copy automatically.
- Plate-critiqued at 360x640 and 320x568
  (tool/deep_wardrobe_visual_test.dart): new dye cards with tinted
  sprites and the epithet shelf in worn/unlocked/locked states.
