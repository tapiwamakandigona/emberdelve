# v0.81.0 — The Retraced Page

Any remembered delve now offers the road back.

The Ledger could already SHARE a remembered run — tap-to-copy its Delve
Code (v0.43.0), a Delver's Card (v0.56.0) — but replaying one on your own
device meant copy, back out, open the seed dialog, paste. Three screens of
friction for a run the Ledger remembers completely. Post-loss replay is the
strongest loop the summary has (Delve Again / Retrace the Delve), but it
died with the summary screen.

Now every rememberable row carries a small replay mark: tap it and that
exact delve starts — same seed, same delver, same difficulty, same
ascension, and a short run rebuilds the SAME six-layer road, never one
like it.

## Honesty rules

- Legacy rows that banked no seed stay quiet — same gate as the code; the
  Ledger never offers a road it cannot rebuild.
- Difficulty and ascension ride the same clamp as pasted codes: a record
  is a memory, not a key — retrace never bypasses the Forge gate.
- Retracing a daily record replays the seed as a free run; the daily badge
  belongs to the day, not the seed.

## Technical

- One IconButton per encodable row (key `history-retrace-<seed>-<date>`),
  pops to root and calls `startRun` with the record's params. UI-only;
  controller untouched. Tests +3 (`test/retraced_page_test.dart`).
- Zero new assets, zero sim movement.
