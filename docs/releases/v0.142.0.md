# v0.142.0 — The Written Marks

The Codex gains a seventh kind: **runes**. The temper arc was the
last named system without pages in the book — six entries in the
smith's own words, sitting between the rules and the dice that
wear them.

- Priced at 15 embers like dice: the marks are tools of the trade.
  Codex grows 105 -> 111 entries.
- refIds mirror the live anvil (faceRunes) and names resolve
  through runeName() — a rename can never fork the book (the
  v0.131 mirror-assert idiom).
- Each page doubles as strategy flavor: what the rune is FOR, in
  voice (surge is 'a decision given back'; mend 'wins no fights —
  it keeps you standing').
