# v0.116.0 — The Spoken Dice

The Codex closes on the tools of the trade: **THE DICE**, one story
per base cut, shallow to deep — Flint Shard, Ember Die, Deep Coal,
Forge Core, Molten Core. 15 embers each; 97 entries total.

- The five base cuts only, deliberately: the tempered variants are
  the same cuts re-promised at the forge, so the shapes carry all
  the lore. Full 30-die coverage would be filler; five is a set.
- Names read live from the dice catalog (the anti-lying rule,
  fourth application); a die rename can never leave the book lying.
- Charter held: what a die does stays printed on its face, in play,
  free — the Codex sells only the story.
- Zero sim impact: codex is meta-layer data, so no golden re-anchor
  (the v0.114.0 cost lesson applied — content growth was chosen
  where seeded runs can't feel it).

## Technical

- codex.dart: `_die` helper (cost 15), kind 'die', five entries
  appended after relics; codex_screen THE DICE section, name via

- test/spoken_dice_test.dart (4): exact base-cut coverage in tier
