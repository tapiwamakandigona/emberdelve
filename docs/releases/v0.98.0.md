# v0.98.0 — The Hearthgold

The hearth tales (v0.96.0) drip lore at every rest fire and count each
hollow left — but the counter fed nothing visible. Now it earns the
delve's seventh vista.

- **Hearthgold**: hear every tale the fire tells and the delve wears
  the fire's own color — the first BRIGHTENING vista. Every earlier
  grade tints or drains; this one gilds. Like every vista it is a
  milestone, never a purchase.
- The gate follows the data: `talesHeard >= hearthTales.length`, so if
  the fire ever learns new tales the milestone rises honestly instead
  of lying.
- The Coming Vista line (v0.88.0) now treats rests taken this run as
  movement: a summary can say 'The Hearthgold vista waits — 4 of 10
  tales heard.' with real numbers, only when this run moved the count
  and never once the vista is yours.
