# v0.61.0 — The Deepest Mark

The delve now tells you when you stand deeper than you ever have.

## The one improvement

One quiet line on the run summary — win or loss — the moment this run
stood on a deeper layer than any run before it:

> Floor 7 — the deepest you have delved.

- A **lost** run can set the mark. Falling on floor 7 when you'd never
  passed 6 is still your deepest delve, and the summary says so in gold.
  The record is the dignity.
- Your **first-ever** run announces nothing. "Deepest yet" needs a
  previous record to beat — a trivial record line would be noise.
- The line retires itself: once your record reaches the final layer,
  the game stops talking about it. No streaks, no "next goal", no expiry.
- The record itself (`bestFloor`) has been banked since v0.5.0 and
  already syncs across devices — this release finally gives the moment
  it moves a voice.

## Zero sim movement

No simulation, balance, or save-format change. All pinned seeds, goldens,
provings, and delve codes remain valid.
