# v0.50.0 — The Tinker

**A sixth delver joins the roster: the control archetype.**

The Tinker never rolls scared and never rolls wild. A Steady Ember (never
below 3) under Loaded Pips (nothing ever below 2) gives the best floors of
any delver — traded for the smallest ceiling in the roster. If the Gambler
is the delve's thunderstorm, the Tinker is its metronome.

- **The Tinker** — 30 HP, Steady Ember + Ember Die + Flint Shard, starts
  with Loaded Pips. Unlocks for 600 embers at the Hearth.
- **Pin Wrench** — a new held weapon with a burnished steel head.
- **Two new ledger entries** — *Well Oiled* (win as the Tinker) and *Six
  Ways Down* (win with all six delvers).
- Old Delve Codes are untouched: the roster grew at the end, so every code
  you've shared still names the same delver.

Balance: 400-seed sweeps land the Tinker level with the skill delvers
(58.25% bot winrate on Normal vs the Peddler's 58.7%). Default runs are
byte-identical — this release adds no sim changes.
