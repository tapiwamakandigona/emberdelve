# v0.139.0 — The Shown Anvil

The onboarding audit found the gap: five context tips, all combat
basics — while the game's deepest system (six runes, two marks,
v0.124-0.134) had NO front door before the sheet itself.

- **first_anvil** joins the tip deck: fires at the first rest fire
  where a temper is still available, names all six runes in one
  plain sentence, states the two-mark limit and that resting costs
  nothing. The v0.10.0 rules hold: one card at a time, once ever,
  tap to dismiss, never a wall.
- canTemper is passed by the caller, so a spent anvil never
  teaches a button that is not on screen.
