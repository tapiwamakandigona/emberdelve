# v0.37.0 — The Delve Codes

**One improvement:** every finished run now leaves a **Delve Code** — one short shareable code (`DELVE-XXXXXXXXXX`) that packs the whole challenge: seed, delver, difficulty, and ascension rung. A friend plays *your* run, not one like it.

## What's new

- **The summary's seed row is now a Delve Code** — shown on every finished run, win or loss, tap to copy.
- **Redeem anywhere**: paste a code into "Delve a seed" on the title screen. Lowercase, stray hyphens, spaces, even a missing `DELVE-` prefix all decode; a typo fails politely (checksum) instead of starting the wrong delve.
- **It rides your shares**: the Delver's Card (v0.34.0) and the copyable seed-challenge text now carry the code instead of the bare seed — "Same code, same delve."
- Codes are pure text — they travel anywhere text does (WhatsApp, SMS, Discord), need no account, no internet, no deep-link plumbing.
- Fairness stays guaranteed: redeeming a code with a difficulty or ascension you haven't earned clamps down to your unlocked tiers via the existing Ember Forge guarantee — a friend's code is never a wall, and never a purchase prompt.

## Deliberately NOT included

- No server, no tracking — a code is just parameters; nobody knows who made it or who played it.
- No leaderboards on codes — the same fairness stance as the daily and weekly delves.
- No new dependencies and no sim changes — simVersion stays 7; the codec only feeds the existing run-start parameters. Bare seeds and seed words still work exactly as before (v0.3.4).
