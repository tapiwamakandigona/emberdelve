# v0.161.0 — The Eleventh Fire

The Delver's Rank ladder grows an eleventh tier: **Firstflame**, above
Mountainheart, at **2550 marks** ("Every fire below began with yours.").

## Why

v0.149.0 (The Tenth Fire) added Mountainheart at 1700 so veterans parked at
the old top had a climb again. Twelve releases later the same plateau has
re-formed: the marks formula is monotone and unbounded (wins, shared-rule
delves), so long-haul players sit at Mountainheart with `nextRank == null`.
Rank is one of the game's honest long-term hooks — a name for banked
history, never a currency or a gate — and its promise is that the climb
always has a next fire within honest reach.

## What changed

- `lib/data/ranks.dart` — appended `firstflame` (2550). Threshold gap 850
  keeps the accelerating curve (diffs 280, 400, 600, 850).
- `test/eleventh_fire_test.dart` — pins `rankTiers.length == 11`, `.last`
  id/marks/article, the never-shrinking-gap invariant, Mountainheart →
  Firstflame `nextRank`, and the new top (`nextRank == null` past 2550).
- `test/tenth_fire_test.dart` — count/`.last` pins moved up; now pins the
  tenth rung itself (`rankTiers[9]` = mountainheart @ 1700).
- `test/rank_test.dart` — the veteran-tops-the-ladder profile grew with
  the ladder (750 wins → 2605 marks).
- News entry + `currentAppVersion` 0.161.0; pubspec `0.161.0+187`.

## Ethics

Derived, never stored; monotone under cloud merge; no payment interaction;
no expiry, no comparison to anyone else. Name avoids all delver names so
"You delve as a Firstflame" can never read as a class change.
