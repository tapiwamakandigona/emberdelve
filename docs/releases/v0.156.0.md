# v0.156.0 — The Deep Day

An eleventh trial joins the daily rotation, and it belongs to the Deep Mark.

## The trial

- **The Deep Day** is a goal day: play the daily under vanilla rules and
  **deepen a rune mark at a rest fire** — temper the same face with the same
  rune twice in one delve. Met, it pays **15 embers** through the normal
  banking path; missed, it is silent and costs nothing, like every trial.
- With two tempers a delve, a deep mark takes both. The Deep Day is the one
  date on the calendar where depth is the declared answer to the rest-fire
  question v0.155.0 opened.

## How it is judged

- Pure observation, sealed sim: the judge reads the finished run's own die
  records — a deep mark is a custom die whose tier reached 2. The v0.155.0
  optional-tier save contract holds all the way down: an absent tier reads
  as 1, so a record from an older build counts zero, never a crash.
- New goal kind `deep_marks_at_least` in the trial judge. Old builds handed
  this goal id pay nothing rather than crashing (the standing
  forward-compatibility convention).
- Appended LAST to the trial rotation, per the standing append-only
  contract. The rotation-uniformity test now scales its floor with the
  catalog size instead of pinning one era's histogram.

## Tests

- `test/deep_day_test.dart`: rule pin (goal id, param, flat 15-ember rate,
  vanilla rules, append-LAST), exact judge fixtures including the
  absent-tier contract, and an end-to-end proof that a run the sim itself
  deepened meets the goal.
- Full suite green.
