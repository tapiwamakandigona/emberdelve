# v0.46.0 — The Delvers Before

**One improvement:** the fourth pure content drop — **six new events and four new relics**, all themed on the delvers who walked this road before you: cold camps, cairns, a rival's ledger, a lantern left burning at a fork. The event deck grows 39 → 45 and the relic roster 32 → 36, with four new Codex entries to match.

## What's new

- **Six new happenings**: *The Cold Camp*, *The Delver's Cairn*, *The Old Rope*, *The Rival's Ledger*, *The Left Lantern*, *The First Delver* — appended to the deck end, built entirely from the existing effect vocabulary. Several offer a quiet pay-it-forward option (rebuild the fire ring, leave the lantern burning) that pays embers, never guilt.
- **Four new relics**: *Cairn Stone* (+5 max HP, rests heal +2), *Rival's Compass* (won fights pay +4 gold, shops 5% off), *Keeper's Lantern* (+2 vs elites and bosses, won fights heal 1), *Tally Chain* (max rolls +1 gold, won fights +1 ember) — multi-hook combos of existing lines, per the drop-2/drop-3 precedent.
- **Four new Codex entries** (20 embers each), keeping the Codex's every-enemy-every-relic coverage exact.
- **Why this theme:** v0.43 remembered your runs and v0.44 let you retrace them; this drop plants the same memory in the world itself. The delve remembers everyone.

## Balance — measured, not vibes

- 400-seed sweep per difficulty stays in band: easy **88.5%** (80–90), normal **63.5%** (55–70), hard **39.0%** (30–45).
- 1000-seed hard sweep: **42.3%** vs 41.3% pre-drop — within noise.
- Every proving stays bot-winnable (ash_summit re-seeded 908 → 912 after the deck shift); the A20 ladder is re-proven alive for all four delvers.

## Deliberately NOT included

- No new enemies (no sprite risk; bosses were drop 2's job) and no new hook/effect vocabulary — nothing new to teach, nothing new to break.
- No trade duplicates: the hermit keeps the die-for-relic swap, the gambler's table keeps the wager, the found pack stays found.
- No sim logic change and no simVersion bump: content-as-data additions keep saves valid. Seeded runs re-roll (the deck grew), so the golden anchors were deliberately re-measured — the fifth re-anchor, procedure per v0.22/v0.25.
