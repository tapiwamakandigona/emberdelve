# v0.127.0 — The Full Rotation

The Weekly deals six rules across its cycle, but a win under one
was indistinguishable from a win under any other — no collection,
no reason to sit the rotation's harder Mondays. Now the game
remembers which rules you have actually beaten.

- **weeklyRulesWon**: canonical rule labels (sorted '+'-joined ids)
  banked on a WON weekly, so 'no_shops+no_rests' and its mirror are
  one rule. Junk-proof: only labels the live rotation can deal
  count. Union on cloud merge; never shrinks.
- **The title tally**: 'Rules taken: 4 of 6' under the weekly recap
  — shown only once a rule exists (the waymark-line rule: no
  homework at zero).
- **Two honors** (60 total): Rule Taken (any rule) and The Full
  Rotation (all six). The full honor is promise-worded, so its
  target is pinned to the live rotation's label count (§Re-pricing
  doctrine).
