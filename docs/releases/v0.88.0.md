# v0.88.0 — The Coming Vista

The proximal goal, stated at the only honest moment: when it moved.

Vistas are the game's best-behaved unlock system — real milestones, honest
unlock lines, never a price — but progress toward them was only visible
inside the picker, a screen visited rarely. The moment a counter actually
moves is spent on the run summary, which said nothing. Now, when a run
grows a counter feeding a still-locked vista, the summary names the
nearest one with the real numbers:

- 'The Verdigris vista waits — 12 of 15 different foes felled.'
- 'The Deepshale vista waits — deepest floor 7 of 9.'

## Honesty rules

- Shown ONLY when this run moved the counter (read from existing
  transients); a summary where nothing moved says nothing. A static line
  stops being news and starts being a nag.
- Binary gates (Moonveil 'win a delve', Bloodstone 'win on Hard') are
  excluded — 0-of-1 is a demand, not progress.
- Nearest = highest fraction, ties to vista order. One line, no button,
  no price talk; the picker holds the door.
- Zero persistence — a pure read of live counters, so it can never lie.

## Technical

- `comingVistaLine(GameController)` in the summary; row keyed
  `coming-vista` after the codex pull. Non-breaking spaces keep
  'floor 7 of 9.' from orphan-wrapping. Tests +5
  (`test/coming_vista_test.dart`; new pinned seed: kindler easy 22 = loss,
  2 distinct felled, deepest floor 7). Plate-critiqued at 360x640 (depth
  line) and 320x568 (longest felled wording). Zero assets, zero sim
  movement.
