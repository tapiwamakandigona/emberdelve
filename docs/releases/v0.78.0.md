# v0.78.0 — The Old Foe

The Ledger now names the old foe.

`enemyFellTo` has banked every fall per enemy since v0.3 and the Codex reads
it entry by entry, but nothing ever aggregated it — the game never named the
enemy the player already curses under their breath. Now the LIFETIME panel
carries one more row: the enemy that has ended more of your delves than any
other, named with its tally (`Wick Widow ×5`). Every roguelike player has a
nemesis; naming it is a standing, personal score that regenerates naturally —
and Emberdelve's version states the record flatly and stops.

Two falls make a foe — one is bad luck. Ties resolve to enemies authoring
order so the answer never flickers. Retired ids are skipped, never crashed on.

## Honesty rules

- A statement, not an errand: no taunt copy, no "go get revenge" CTA, no
  reward for felling it. The Ledger states; the grudge is the player's own.
- One name, not a leaderboard — the Codex already carries per-enemy deaths;
  a ranked shame table was rejected.

## Technical

- `oldFoe(MetaState)` pure helper in `lib/ui/ledger_screen.dart`; row keyed
  `old-foe`, gated on the helper returning non-null.
- Zero new assets, zero sim movement. Tests +3 (`test/old_foe_test.dart`).
