# v0.105.0 — The Delver's Line

The Delver's Page (v0.101.0) let you read one delver's remembered
delves. But the remembered list keeps 30 records and forgets the
rest — so the page could show two rows for a delver who has walked
a hundred delves, and nothing on it said so.

- Open one delver's page and a lifetime line now sits under the
  chips: 'Lifetime: 128 delves · 33 won · best floor 9'.
- The line reads the UNCAPPED lifetime counters (charRuns/charWins/
  charBestFloor), never the capped list — a tally of the page itself
  would eventually lie; this cannot.
- 'All delvers' shows no line (whose lifetime would it be?). Best
  floor appears only once one is on record; singular forms spelled
  out ('1 delve · 1 won').

## Technical

- ledger_screen: pure top-level `delverLifetimeLine(MetaState, charId)`
  (NBSP-bound number phrases); Text key 'delver-lifetime' rendered
  only while a single delver's page is open.
- test/delvers_line_test.dart (3): uncapped-counter pin (40 lifetime
  runs vs 30-cap list), singular/no-best-floor shapes, page
  show/hide walk.
- Plates: kindler page at 360 with the line under the chips; 320
  restraint (longest shape, one line).
