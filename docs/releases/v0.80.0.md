# v0.80.0 — The Plumb Line

The Ledger now states the deepest floor ever reached.

`bestFloor` has been banked on every run since the vista gates needed it —
it opens the Deepshale, feeds an achievement, and fires the summary's
one-time deepest-line. But no surface ever STATED the number afterward. The
picker's charted depth is per-delver; the sounding line draws thirty runs
relative to each other. The single lifetime mark a player quotes — "I've
been to floor 12" — was nowhere to read.

Now the LIFETIME panel carries it: "Deepest floor", gated on having delved
at all. The sounding line measures relative; the plumb line states absolute.

## Honesty rules

- Absent until a floor is banked — a fresh profile shows nothing, not a 0.
- No "of N floors" denominator: run length varies by mode, and a fixed
  denominator would lie for short and daily delves.

## Technical

- One gated `_row` in the Ledger LIFETIME panel, key `plumb-line`,
  Icons.south in ember. Tests +2 (`test/plumb_line_test.dart`).
- Zero new assets, zero sim movement.
