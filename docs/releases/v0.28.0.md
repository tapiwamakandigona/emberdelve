# v0.28.0 — The Shifting Strata (versionCode 54)

Player-facing: **the rock changes as you descend** — the second ask from our
first outside review ("change backgrounds").

- Every backdrop in a run is now graded by your true depth (the same
  gameplay-owned signal that drives the Deep Hum ambience): the surface keeps
  its warm kiln-brown, the mid-delve cools to ash-blue, and the deepest
  floors turn wyrm-violet. The boss arena arrives fully deep.
- The ember specks and rock seams shift color with the strata, and a faint
  depth wash breathes over the art — under the scrim, so text contrast never
  changes.
- The title screen and everything outside a run render byte-identical to
  before: depth 0 is a true identity (no filter, no wash, no extra layers).
- Zero new assets, zero payload delta: the existing paintings are graded
  live by a color matrix.

First implementation was rejected by our own plate critique — a polite grade
was invisible on near-black art. The shipped grade swings hue hard and
RAISES saturation with depth so the descent is felt, not implied.

No sim changes: simVersion 7, all golden anchors byte-identical.
