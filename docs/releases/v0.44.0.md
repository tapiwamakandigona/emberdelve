# v0.44.0 — The Retraced Road

**One improvement:** a lost delve can now be **retraced** — one tap on the loss summary restarts the *exact same delve*: same seed, same delver, same difficulty, same ascension rung. The map, the offers, and the rolls all repeat; only the player's choices change.

## What's new

- **A quiet "Retrace this delve" button on the loss summary**, below the fresh-seed "Delve again", with one honest fact line: *same map, same offers, same rolls — only your choices change.*
- **The claim is guaranteed true**: the retrace reuses the lost run's seed through the same `startRun` path a Delve Code takes, so the retraced delve is bit-for-bit the challenge that was just lost.
- **Shared-seed integrity kept**: the Daily and Weekly Delve are one shared attempt each — a lost Daily or Weekly never offers a retrace (spec §Ethics fairness).
- **Won delves stay quiet.** A victory has nothing to relearn; "Delve again" already covers the fresh-seed path.

## Why this hook

The roguelike loop that retains players is *lose → understand the defect → try again with a sharper theory* (Slay the Spire's core lesson; see `docs/improvements/studio-priorities-2026-08-16.md` §6 — "a strong loop changes the player, not the number"). Until now that loop ran on a fresh seed, so a theory about *this* map could never be tested. The retrace makes learning playable: the delve that killed you is one tap away, unchanged, and beating it is pure proof the player got better — no urgency, no reward, nothing sold, and ignoring it costs nothing.

It also completes the seed triangle started earlier: Delve Codes challenge *others* (v0.37), remembered delves reshare *any* run (v0.43), and the retrace challenges *yourself* (v0.44).

## Deliberately NOT included

- No "so close!" framing, no win-percentage bait, no banned-word urgency — one button and one fact.
- No retrace on wins, Dailies, or Weeklies (see above).
- No new sim behavior: seeds already replay deterministically; this release only opens an existing door from the one screen where it matters.
