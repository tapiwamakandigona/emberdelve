# v0.125.0 — The Tempered Hand

The Mender's Mark (v0.124.0) made the temper system the gameplay
lane; this release gives that lane its lifetime arc. Tempering was
invisible in the meta layer — no counter, no honor, nothing for the
Ledger to say about a delver's forge habit.

- **tempersSet**: lifetime faces tempered, banked at run end from
  the run's own tempers_used — wins AND losses (the forge work was
  real either way). Saved only when non-zero; cloud merge MAX.
- **Two honors** (58 total): The Marked Face (first temper) and
  Well Tempered (25 across your delves).

## Technical

- Banking sits with dailiesPlayed, outside the win gate — pinned by
  a bot walk on kindler easy seed 13 (loses AND rests on the pure
  walk). The pin accepts either terminal: a mid-run temper can sway
  the remaining walk (a mend die heals), so demanding the loss
  would pin an accident, not the contract.
- test/tempered_hand_test.dart (4): terminal banking, round-trip +
  MAX merge, honors on the real counter, honesty sweep. Guard-map
  wiring: achievementStats, wired-stat profile, waymarks maxed
  profile.
- Plates tempered_360x640 / tempered_320x568 approved (both honors
  in one frame — profile chosen so the progress sort keeps them
  adjacent, the v0.115.0 framing rule).
