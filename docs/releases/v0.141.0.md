# v0.141.0 — The Honest Ledger

v0.140's find (Hearth Keeper lying since v0.4.3) demanded a full
sweep: every promise-worded honor audited against the catalog it
promises. Two more shipped lies found and fixed:

- **The Whole Bestiary** said 'all six bosses' — the bestiary has
  held EIGHT since v0.112. Target now 8; text count-free ('beat
  every boss in the bestiary'). The id (all_three_bosses) shows it
  had already rotted and been re-priced once before.
- **Full Company** said 'unlock all five delvers' — the fire seats
  eight. Target now 8; text count-free ('unlock every delver').

## The class is now pinned

test/honest_ledger_test.dart asserts EVERY promise-worded honor's
target against its live catalog (bosses, roster x2, themes, rules
x2, runes, epithets) and that promise copy carries no baked-in
count — the exact failure mode both bugs shared. Historical
counted honors (Five/Six/Seven Ways Down, Full Hearth, Four Ways
Down) are pinned frozen, the other half of the doctrine.

Also: waymarks' maxed profile now derives its boss fill from the
live bestiary — the hand-written six-boss list was hiding the
Whole Bestiary lie from the very test meant to catch it.
