# v0.92.0 — The Counted Draught

Third and final station of the counted-heal arc (v0.89 rest, v0.90 shop).
Event options priced their HP costs exactly ('-6 hp, +30 gold') but heals
stayed percentages: 'Bathe (heal 40%)' asked for the same mental
arithmetic the other stations no longer do — and hid the overheal cap, so
at 28/30 a 40% draught quietly delivered 2.

- Every 'heal N%' token in an event option now renders as the counted
  heal: 'Pray quietly (heal 7 HP)'. Combined labels rewrite only the
  token: 'Buy the flask (-12 gold, heal 9 HP)'.
- At full health the option says 'heals nothing' — an informed choice,
  not a removed one (v0.90 precedent).
- There is no percentage left anywhere in the delve's healing UI.

## Honesty rules

- Same single source of truth: the label calls `healPreview` on the sim
  with runEventChoose's own formula (max HP × pct ÷ 100). A parity test
  forces a real Ember Shrine and proves the promised 7 equals the heal
  the event then performs.
- Data files untouched: events.dart stays difficulty-agnostic prose; the
  count is a live read and belongs at render time. A label without the
  token passes through unchanged.
- No '(17 to 24)' ranges here — combined labels would become soup; the
  fixed stations carry the range, the roadside options stay one breath.
