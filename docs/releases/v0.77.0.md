# v0.77.0 — The Sounding Line

The Ledger now draws the depth of the remembered delves.

A sounding line is the mariner's depth measure: knots on a rope, read plainly.
Ours sits above RECENT DELVES — one bar per remembered run, oldest on the
left, newest on the right, each bar's height the floor that run reached
relative to the deepest in the window. Wins stand in ember; losses stay dim;
an abandoned run dimmer still. Old records that never banked a floor draw an
honest stub on the baseline — the delve happened, and the chart does not
invent what it reached.

Two delves make a line; the chart waits until you have them.

## Honesty rules

- Every bar is a real record — the same runHistory the rows below already
  state, drawn rather than duplicated.
- No trend commentary, no goal overlay, no tap affordance: the rows directly
  beneath already open each run. The line speaks or it doesn't.

## Technical

- `lib/ui/sounding_line.dart`: `soundingBars(history)` pure mapping (newest-
  first storage → oldest-first drawing, scaled to the window's deepest floor,
  unknown results read as losses) + `SoundingLine` CustomPainter (width-aware
  sizing inside `paint(size)`).
- Ledger gate: `runHistory.length >= 2`, key `sounding-line`.
- Zero new assets, zero sim movement. Tests +3 (`test/sounding_line_test.dart`).
