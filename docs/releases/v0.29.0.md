# v0.29.0 — The Next Delve (versionCode 55)

Player-facing: **a next step after beating Easy** — our first outside
reviewer finished Easy mode and enjoyed it; the game now tells that player,
at the exact moment of victory, that the delve continues.

- Win a run on Easy and the summary offers one quiet invitation: *"The easy
  delve is tamed. The same halls wait on Normal — sharper teeth, a fuller
  ember pouch."* One tap on **Delve Normal** starts a fresh run on Normal
  with the same delver, boon pick included.
- Taking the invitation also moves the title-screen difficulty selector to
  Normal — the same rule as tapping the selector yourself.
- Honest by construction (docs/spec.md §5): shown only on a WIN, never
  after a death; never a popup; nothing expires; ignoring it costs nothing.
  The ember claim is literal — Easy banks embers at 0.75x, Normal at full
  rate.
- Normal wins and all losses see exactly the summary they saw before —
  this panel does not exist for them.

No sim changes: simVersion 7, all golden anchors byte-identical.
