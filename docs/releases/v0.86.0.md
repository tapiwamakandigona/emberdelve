# v0.86.0 — The Foe's Last Thread

Losses that almost won now say so.

v0.85.0 gave narrow wins their line. This is the mirror: when a delve ends
with the killer itself inside the same 30% rule, the summary states the
fact the game always knew:

> The Soot Hound hung by a thread — 3 HP standing.

"I almost had it" is the strongest one-more-run motive there is — and here
it is a fact, not a nudge. The line sits directly above the loss loop the
summary already offers (Delve Again, Retrace This Delve). Nothing is added
to push; the truth does the pulling.

## Honesty rules

- Same 30% threshold that defines "close" everywhere else (danger music,
  the Narrow Climb). No boss-special second definition.
- The killer's name resolves through the enemy catalog — an unknown or
  retired id is never named.
- Absent when the foe was healthy: most losses stay a plain, dignified
  obituary, and the line keeps its meaning when it does appear.
- Dim micro text; nothing persisted.

## Technical

- `lastThreadLine()` helper + one gated Text (key `last-thread`) beside the
  Narrow Climb's block. Tests +4 (`test/last_thread_test.dart`: boundary
  inclusive, healthy-foe null, win null, ghost-id null). Plate-critiqued at
  360x640 and 320x568 with the longest catalog name. Zero assets, zero sim
  movement.
