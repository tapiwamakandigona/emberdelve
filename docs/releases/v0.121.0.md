# v0.121.0 — The Waymark Line

The game has 54 honors but never pointed at one before a run — the
"so close" resolver only spoke on the summary screen, after intent
was spent. The title screen now carries one quiet line:

    Next waymark: Thrice Down — 2 of 3

- Names the single unearned achievement closest to done, with the
  real counters, clamped. Tapping opens the Ledger.
- Sits with the other out-of-flow micro lines (provings count,
  'Delve a seed') — dim text, no badge, no pulse.
- §Ethics, inherited from nearestAchievements: zero-progress goals
  never show (a goal you have not started is not a goal you are
  close to), and the line does not exist before the first delve —
  a fresh profile technically has progress (the default hearth
  theme counts toward Full Hearth), and pointing a brand-new player
  at an ember-spending goal on first boot is exactly the homework
  this line must never assign.

## Technical

- waymarkLine(m) in lib/meta/achievements.dart: runsPlayed gate →
