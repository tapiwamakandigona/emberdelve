# v0.76.0 — The New Song

One improvement: **the run that first hears a song now gets told.** Every
other thing a delve earns — a record, a name, a vista, a first felling —
is announced at the summary. Newly heard music was the one earn that
still happened silently, right after v0.75.0 made heard tracks pinnable.

## What changed

- When a delve is the first to hear a track, the run summary says so:
  one quiet line beside the other firsts. One song is named; two are
  named together; three or more collapse to *"Into the Delve" and N more
  join the Gramophone* — a first delve can earn five songs at once, and
  five lines would shout down the result.
- The line survives closing the app mid-run: the earned-this-run record
  rides the same save side channel as the enemy firsts.
- Honesty as always: every song the line names is already on the
  Gramophone shelf, ready to play — or to pin at the hearth (v0.75.0).
  No teaser for locked tracks, no call-to-action, no mid-run toast.

## Under the hood

- Run-scoped `runNewTracks` recorded at the same gameplay-owned site that
  banks lifetime `heardTracks`; `'run_new_tracks'` snapshot key (absent
  when empty — an identical run writes identical bytes). Zero new assets,
  zero sim movement. Suite green (+5 tests), analyze clean (fatal-infos).
