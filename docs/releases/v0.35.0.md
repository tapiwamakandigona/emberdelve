# v0.35.0 — The Vistas

**One improvement:** selectable background **vistas** — full-run color grades that re-tint every floor of the delve, earned by playing (never sold). A direct answer to a player review: *"You could add character customisation and change backgrounds in the update."*

## What's new

- **Four vistas**, chosen from a new THE VISTA section on the character screen (right beside the dyes):
  - **Emberlight** — the delve as it has always burned. Always available.
  - **Moonveil** — a cold blue-silver night. *Win a delve.*
  - **Verdigris** — mossy green depths. *Fell 15 different foes.*
  - **Bloodstone** — deep red iron dark. *Win a delve on Hard.*
- Vistas compose with the existing depth strata (v0.28.0) in a single color matrix — one paint pass, no extra cost per frame.
- Your choice syncs with cloud saves (fresher side wins), and unlocks are derived from your lifetime record — earn one anywhere, it's yours everywhere.

## Deliberately NOT included

- No purchasable vistas — expression is earned, not sold (docs/spec.md §Ethics).
- No new background art assets — zero PNGs added, so the install size does not grow.
- No sim changes — simVersion stays 7; runs, seeds, and daily/weekly fairness untouched.
