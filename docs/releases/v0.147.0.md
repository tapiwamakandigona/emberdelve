# v0.147.0 — The Marked Day

The temper arc — the game's signature mechanic since v0.117 —
had no day in the trial rotation. Now it does:

- **The Marked Day** (goal day): temper at least one die face at
  a rest fire; the day pays 15 embers. Vanilla rules otherwise.
- New goal kind `tempers_at_least`, judged from the run's own
  counter — pure observation, the sim stays sealed (the trials
  charter's core contract).
- Append-LAST on the rotation: the hash changes by one modulus,
  not a reshuffle of authored order.

## Technical

- lib/game/trials.dart: one new switch case. lib/data/trials.dart:
  one TrialDef + order entry. trials_test known-goals set updated.
- test/marked_day_test.dart (3): the def, the judge (0/1/2/missing
  counter), and the forward-compat contract proven from this side
  (an unknown goal id pays silence, not a crash).
- No new plates: the trial line renders through the same title
  widget as all eight existing trials, and the plate tool reads
  the real clock (the Marked Day appears on its hashed dates).
