# v0.95.0 — The Known Relic

The Pictured Satchel (v0.93.0) put relic icons in front of the player —
and its own plates supplied the evidence for this release: fourteen of
the thirty-six relics had no icon of their own and all shared the same
fallback lantern, so a Cairn Stone and a Choir Censer led with identical
art in the shop and the satchel alike.

- All 36 relics now carry a deliberate icon. The lantern belongs to the
  Cinder Lantern alone.
- Curated reuse under a hard cap: no icon serves more than two relics,
  and pairs were chosen so the two effects read nothing alike (the
  Wyrmscale Cloak takes the wyrm's tail rather than doubling the Iron
  Scale's shield).
- Zero new assets — the existing game-icons.net set covers the catalog,
  so the install stays exactly the same size.

## Technical

- One map extension in lib/ui/art.dart (relicIcons); zero sim movement.
- test/known_relic_test.dart pins the charter: every shipped relic has an
  explicit entry (the fallback is for future ids mid-build only), no icon
  serves more than two relics, the lantern maps to cinder_lantern alone,
  and no stray keys name relics that do not exist. Asset existence for
  every mapping is already swept by test/assets_test.dart.
- Plate-critiqued via the v0.93.0 satchel plates at 360x640 and 320x568:
  all five rows of the evidence loadout now lead with distinct art.
