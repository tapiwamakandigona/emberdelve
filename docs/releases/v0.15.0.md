# v0.15.0 — The Hearthside Post

## What's new

- **A note by the hearth.** After you update, the title screen now carries
  a short post — what changed, in plain words, right where you'd notice.
  Read it, tap **Noted**, and it steps aside for good. One tap, once per
  release, never a badge, never a nag.
- **Past posts.** Every note is kept in *Settings → Past posts*, newest
  first, re-readable forever. An archive, not an inbox — nothing in it is
  ever marked "unread".
- Fresh installs don't get a note on first launch — nothing has changed
  for you yet. The first post you'll see is the first update you live
  through.

## The fine print, honestly

- The note ships inside the game. No server is contacted, nothing is
  fetched, and it works fully offline like everything else.
- Dismissal syncs with cloud save by keeping the *newest* version seen on
  any device — a merge can never resurrect a post you already read.
- No gameplay, balance, or save-format changes. Your saves carry over
  untouched.

## Under the hood

- `lib/data/news.dart`: one entry per release, content-as-data, with the
  shipped version name pinned to `pubspec.yaml` by test so the panel can
  never claim a version the binary isn't.
- New meta field `lastSeenNewsVersion` ('' = never), merged by
  larger-version in cloud sync; boot stamps brand-new profiles silently.
- 10 new tests (version pinning, ethics-word sweep on all copy, merge
  monotonicity, fresh-install suppression, show-once/dismiss-persist
  widget tests, archive listing); overflow probe green at all five sizes
  including the panel; suite 402/402.
