# v0.83.0 — The Depth Gauge

The map now states your depth while you delve.

Mid-run, the current floor was stated nowhere: the lantern (v0.82.0) marks
the record, the Ledger states it, the summary banks it — but a player
standing in the delve had to count node rows by hand. Now the map hint line
opens with the live reading: 'Floor N of M · Tap a glowing node to descend ·
Pool: X dice · Y relics'. The surveying set is complete: the Sounding Line
draws the chart, the Plumb Line states the record, the Depth Gauge reads
the moment.
