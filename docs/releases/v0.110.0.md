# v0.110.0 — The Named Company

The Codex answered "what is a delve?" in v0.104.0. This release
answers the second question a new delver asks: who are these people
around the fire?

- **THE COMPANY** — a new Codex section between THE WORLD and
  ENEMIES: one story per roster delver, in roster order, 15 embers
  each (priced like common lore).
- Each story is written to the delver's mechanical truth — the
  warden's oath is their guard die, the ascetic's "weight is a debt"
  is their thin kit, the peddler's kiln key opens the shops.
- Flavor only, per the Codex charter: kits, dice, and numbers stay
  on the character picker, free, forever.
- Names are read from the characters catalog, never stored in the
  Codex — a delver rename can never leave the book lying (same rule
  as enemies and relics).

92 Codex entries total.
