# v0.68.0 — The Earned Name

One improvement: **a run that earns an epithet now announces it.** Every
other milestone the Ledger banks speaks on the summary — achievements,
rank-ups, opened rungs, depth records — but earning a *name* was silent. The
player discovered "the Unburnt" only by happening to reopen the wardrobe.
Now the moment speaks: one quiet gold line per earned title, win or loss
alike.

## What changed

- **One line per earned name** on the run summary — `"the Unburnt" is yours
  to wear.` — in the same voice and restraint as the rank-up line. No
  button, no navigation push, no celebration overlay; the wardrobe holds the
  detail.
- **Losses announce too.** Epithet milestones read real Ledger counters, and
  several move on lost runs (ten *ended* runs earns the Thorough). The tenth
  loss deserves its name as much as the tenth win.
- **Never twice.** The diff is computed inside one banking pass — a name
  already held is never re-announced, and the next run clears the moment.

## Under the hood

- `GameController.pendingEpithets` — transient list diffed from an
  `epithetsBefore` snapshot around `_bankRun`'s counter writes, exactly the
  `pendingRankUp` lifecycle (cleared on `startRun`, nothing persisted,
  nothing can double-fire).
- Summary quiet-line inventory grows by one key: `earned-name-<id>`.
- Zero sim movement, zero save-format movement. Suite green, analyze clean
  (fatal-infos).

## Ethics

A fact about a title already earned — never a next-goal teaser. The
"nearest mark" progress-counter variant was scouted and REJECTED: a dangling
almost-there counter is FOMO-shaped, and the v0.61.0 deepest-line precedent
("pure fact, no next-goal teaser") stands.
