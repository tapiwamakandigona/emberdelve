# v0.169.0 — The Steady Flame

A performance-polish release (user directive 2026-08-31: performance
optimisation and smooth animations).

- Rebuild-cost lints enabled permanently in analysis_options.yaml
  (`prefer_const_constructors`, `prefer_const_literals_to_create_immutables`,
  `prefer_const_declarations`, `avoid_unnecessary_containers`,
  `sized_box_for_whitespace`) — CI runs `flutter analyze`, so const
  regressions now fail the build.
- 112 violations auto-fixed across 28 files (`dart fix --apply`):
  const-able widget constructors, literals and declarations across the
  settings, character, ledger, summary, codex, shop, title and combat
  top-bar screens, plus test/tool harnesses.
- Audit notes: sprite animation was already repaint-direct (custom
  painter, no per-frame setState, RepaintBoundary, FilterQuality.none);
  42 RepaintBoundaries in lib/ui; no Timer.periodic-driven animation.
  The const pass trims element rebuild work on every screen build.
