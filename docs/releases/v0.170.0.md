# v0.170.0 — The Thirteenth Way

The cutler's proving and roster honors (the v0.119 pattern, seventh use).

## The proving

- **The Cutler's Proving** — the Cutler on normal floors, seed 14
  (bot-winnable, pinned by test). Blurb teaches the kit's core read:
  two marks on two different dice — the deep eight cuts (blade), the
  ember six shields (aegis) — spend each where it pays.
- Stands directly after the Gilder's Proving: delver provings stay
  together, in roster order. `ash_summit` remains last. 21 provings.

## The honors

- **The First Edge** — win a delve as the Cutler (`char_wins`, param
  `cutler`, target 1).
- **Thirteen Ways Down** — win a run with thirteen different delvers
  (`delvers_cleared`, target 13).
- Frozen predecessors keep their earned prices: Twelve Ways Down stays
  12, Eleven Ways Down stays 11 (pinned).
- **the Proven** moves 20 → 21 with the list, per the target-honesty
  pin (`the_proven.target == provings.length`).
