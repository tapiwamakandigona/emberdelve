# v0.153.0 — The Shared Fire

The daily/weekly — the game's whole social layer — was taught
nowhere: the button sat on the title screen unexplained. The
seventh contextual tip closes that:

- **shared_delve**: fires on TITLE arrival, only after a first
  win (the loop is tasted) and never once a daily has been played
  (a player who found the button alone never sees the card —
  first_anvil's canTemper doctrine, calendar edition).
- Copy states the honest contract: same seed for everyone, Monday
  adds the weekly rule, a skipped day is silent and costs
  nothing.

## Technical

- TipDirector.onTitleArrival (pure, unit-tested at all four
  gate combinations + once-ever).
- TitleScreen is stateless: the card mounts in a StatefulBuilder
  so dismissal (which persists but does not notify) still clears
  the overlay.
- test/shared_fire_test.dart (3): the moment's gates, the full
  show-tap-dismiss-persist widget path, and the ethics charter
  pin on the copy (the one tip that talks about calendars).
- tips_test's last-unseen-tip deck pin grew the new id.
- No plates: same _ContextTip widget as all six shipped tips;
  the existing fit test renders every card at 320x568 @1.3x.
