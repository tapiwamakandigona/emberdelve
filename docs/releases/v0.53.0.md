# Emberdelve v0.53.0 — "The Rumor"

One improvement: every delve opens with a named destination.

## The Rumor

- **The boon pick now carries a rumor.** One line under the run-start
  heading: *"Rumor has it the Ashen Colossus waits at the bottom."* The
  run's boss has always been a pure function of the run seed
  (`bossForSeed`, unchanged since v0.4) — decided the moment the seed
  exists, before a single die is rolled. We just stopped keeping the
  secret.
- **"Delve a seed" previews the rumor live.** Type a seed, a word, or
  paste a Delve Code and the dialog names the boss before you commit. A
  shared code now promises a foe, not just a number — *"seed 131, the
  Tinker's floors, the Cinder King at the bottom"* is a challenge worth
  forwarding.

## Honesty notes

- The rumor is information, not a mechanic: no RNG stream is consumed, no
  odds change, and the run is byte-identical whether or not the line is
  read. It passes the §Ethics test by construction — the line IS the
  explanation of how the system works.
- Zero simulation changes. Golden hashes, difficulty sweeps, and every
  pinned seed are untouched by construction.

## Verification

- `flutter analyze`: clean, fatal-on-warnings.
- Full test suite green, including new pins: the rumor text derives from

- UI plates critiqued at 360×640, 412×915, 800×1280, and 320×570 @ 1.3×
