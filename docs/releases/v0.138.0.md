# v0.138.0 — The Delver's Dice

Die skins were the last GLOBAL cosmetic — dyes (v0.66), epithets
(v0.66), names and vistas (v0.115) are all worn per delver. Now
the dice are too:

- **meta.charSkin** — the charVista shape, third application:
  preference map, activeDieSkin surviving as the fallback and the
  Ledger shelf's global choice, fresh-copy cloud merge (preference
  maps never _maxMap — the v0.123 rule).
- **activeRunSkin** — activeRunVista's twin — feeds every in-run
  DieChip (tray, rest, reward, boons, shop lead, temper sheet).
- The picker gains THE DICE: owned skins as swatch cards, dress
  pills naming who the taps dress, WORN state per delver. Buying
  stays on the Ledger shelf (one purchase path — §Ethics).
