# v0.97.0 — The Counted Forge

The honest-numbers arc (counted rest v0.89.0, counted ration v0.90.0,
counted draught v0.92.0) reaches the forge. Forge rows named the dice —
'Ember Die → Deep Coal' — but never said what actually changes. Modded
dice carry invisible numbers (+1 attack, min 3, block only), and forging
one was a leap of faith.

- Every forge row involving a modded die now prints the die's real
  facts before and after — 'd6 · +1 attack → d8 · +1 attack' — in the
  exact words the reward picker already uses, so the same die never
  reads two different ways.
- Restraint rule: a plain size-only forge (d6 → d8) stays quiet. The
  chips' own labels already count it, and restating one fact three
  times is noise, not honesty.
- One vocabulary everywhere: the private `_dieDesc` helper that the
  reward, shop, and boon pickers quietly shared is promoted to a public
  `dieFacts` beside the die data itself.

## Technical

- `dieFacts(DieDef)` now lives in lib/data/dice.dart; reward, shop,
  and boon screens repointed; forge row facts line keyed
  `forge-facts-<index>`, maxLines 2.
- test/counted_forge_test.dart pins the wording, sweeps every mods key
  in the data against the renderer (a new mod key can never silently
  render nothing), and drives both rendered cases: modded row prints
  the line, all-plain pool shows none.
- Plate-critiqued at 360x800 and 320x568 (longest wording — ward →
  aegis — wraps to two lines, no clipping;
  tool/counted_forge_visual_test.dart).
