# v0.63.0 — The Fitted Name

The wordmark now fits every screen it stands on.

## The one improvement

On 320dp-class phones (the narrowest we support) the EMBERDELVE logotype
ran off both edges of the title screen — it painted at a fixed size and
never asked how much room it had. It now measures the width it is given
and scales itself down in one exact proportional step.

- Screens that already fit render **pixel-identical** — the mark never
  scales up, and the space it reserves is unchanged everywhere, so the
  title's layout does not shift on any device.
- Found by our own release gate: the v0.62.0 review plate at 320×568
  showed the clipped mark. The same plate now shows the full name.

## Zero sim movement

No simulation, balance, or save-format change. All pinned seeds, goldens,
provings, and delve codes remain valid.
