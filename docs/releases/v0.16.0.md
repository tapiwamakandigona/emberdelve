# v0.16.0 — The Still Flame

## What's new

- **Reduce motion.** *Settings → Comfort* now has a three-way switch:
  - **System** (default) — follows your device's accessibility setting.
    If you've asked Android to reduce motion, Emberdelve already obliges
    without you touching anything.
  - **Reduced** — no screen shake on hits, no drifting ember particles,
    damage numbers appear in place and fade instead of popping and
    arcing. The delve reads steady.
  - **Full** — the complete feel, regardless of the system flag.
- Nothing informational is removed: hit flashes, damage numbers, haptics,
  and sound all still land — only *displacement* goes. Screen shake is
  the single most-cited vestibular trigger in games, and it's the
  cheapest thing to respect.

## The fine print, honestly

- No gameplay, balance, or save-format changes. Your saves carry over
  untouched; old settings files load as "System".
- Purely presentation — the simulation never knows the setting exists.

## Under the hood

- One app-wide resolver (`lib/ui/motion.dart`): user setting
  ('system'/'on'/'off') × OS `disableAnimations` flag, notifying only
  when the answer flips so live surfaces (the title hearth) react to a
  mid-session toggle instantly.
- Gates at the three motion leaves: `ShakeBox.shake()` no-ops,
  `EmberDrift` renders nothing and stops its ticker (no repaints for an
  invisible layer), `DamagePop` keeps the number on the same clock
  without transforms.
- 7 new tests (settings round-trip, resolver truth table,
  notify-on-flip-only, shake no-op, drift vanish/return, static pop,
  selector write-through); overflow probe green with the new section.
