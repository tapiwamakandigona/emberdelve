# v0.66.0 — The Dressed Delver

*One improvement: epithets are now worn per delver, not per profile.*

## What changed

- **Each delver wears their own epithet.** Until now a single chosen title
  followed whichever character you played. From this release the Kindler can
  stand as *the Unburnt* while the Warden stays *the Thorough* — every
  delver keeps the title you dressed them in, on the picker card, the run
  story, the epitaph, and the shareable Delver's Card.
- **A chip row above the epithet shelf.** Once a second delver joins the
  hearth, THE EPITHET section gains a small horizontal row of name-chips.
  Pick a delver, then tap a title from the shelf — only that delver is
  dressed. With one delver unlocked the shelf works exactly as before, no
  extra chrome.
- **Old choices survive.** The profile-wide title you had chosen becomes the
  fallback: any delver you have not dressed individually keeps wearing it.
  Nothing is un-earned, nothing resets.
- **The ledger banks the worn title.** Run records continue to note which
  epithet the delver wore into the delve (only when it isn't the bare
  default), now resolved per character.

## Under the hood

- `MetaState.charEpithet` (`Map<String, String>`) with strict
  deserialization: unknown delver ids and unknown epithet ids are dropped on
  load; empty map is omitted from saves.
- Resolver `MetaState.epithetFor(charId)` — own dress first, legacy
  `selectedEpithet` as fallback. `''` per delver explicitly means "no title",
  overriding the fallback.
- `GameController.selectEpithet(id, forChar:)` guards locked delvers and
  locked titles; `selectedEpithet` is never written again (kept as the
  legacy fallback).
- Cloud merge carries the fresher profile's dress map wholesale, matching
  the existing cosmetic-selection convention.
- New suite `test/dressed_delver_test.dart` (8 tests): resolver truth table,
  selection isolation, locked-target refusal, save round-trip with
  unknown-id drops, merge freshness in both argument orders, run-record
  banking, and picker/chip-row widget behavior.

## Ethics

Epithets remain earned by delving and are never sold. No new currencies, no
pressure copy, nothing expires. The news note passes the pressure-language
gate.
