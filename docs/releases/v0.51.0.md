# v0.51.0 — The Obituary

Every finished delve now tells its own story.

## The delve story

- The run summary carries a short, honest epitaph — two or three sentences
  built entirely from the finished run: who delved, how far on which
  difficulty, how many floors were survived without a scratch, and what
  ended it (the felled boss on a win; the foe that struck the final blow
  on a loss).
- Deterministic per run: the same delve always tells the same story. Every
  figure is real — no invention, no mockery on a loss, no bragging on a win
  (§Ethics).
- **Copy delve story** puts the paragraph on the clipboard as plain text
  that pastes anywhere — beside the existing Delver's Card image share.
  Player-initiated, never prompted, never rewarded.

## The Ledger remembers

- Lost runs in **Recent Delves** now name the foe that ended them
  ("fell on floor 7 of 9 to Ash Hound"). New records carry the killer;
  older records render exactly as before.
- The remembered killer rides the same run record as everything else, so
  cloud saves carry it with no migration.

## Under the hood

- New pure `obituaryText()` (lib/game/obituary.dart) with pinned golden
  strings; `killed_by` is an additive run-record key (only combat can kill —
  events clamp HP to 1 by the fair-death pillar, so a loss always knows its
  killer).
- Zero simulation changes: goldens, win-rate bands, and every pinned seed
  are untouched by construction.

## Verification
